# 基线实验：现有步态在实物参数管道场景上的攀爬

日期：2026-09-30 至 10-01。代码提交见仓库 git log（`validation/baseline_experiment.py`）。本实验作为后续论文改进方法的对照基础。

## 1. 目的

用当前代码中的两种步态，在 16 个管外攀爬场景上各做 5 次重复试验，记录通过率、爬升高度和舵机负载。两种步态是：
- 顺应性控制（Takemori 等 2023 式 (23) 的实现）；
- 标准 Yamada 螺旋滚动。

这组结果用于：
1. 给出现有方法的能力边界：哪些管道特征能过，哪些不能；
2. 作为后续改进的对照。

## 3. 步态与流程

两种步态共用以下设置：
- 初始螺旋：螺距 P=220 mm，中心线半径 R=80 mm（贴管半径 84 mm 减 4 mm 夹紧量），相位步长 0.15 rad。
- 方向：每次 Ctrl+H 向上。
- 执行链路：完整走 Python → EXE（v1.4.2，隔离端口）→ MuJoCo。

两种步态的区别：
- **顺应性**：K=(0.01, 0.02)，首尾各 4 节取 0.01、中部取 0.02，即场景 XML 中的 `experiment_compliance_gain`。原默认 0.04/0.12 在 kp=127 下会一直顶在力矩上限（见交接记录）。每步由 EXE 反馈的实测截面曲线构造目标。
- **标准螺旋**：固定 R/P 的 Yamada 螺旋，只推进相位。

每次试验的流程：
1. 机器人预缠在起始管 0.5 m 处。初始姿态与 Ctrl+U 预设的挠率相同、半径略大，所以 Ctrl+U 时只收紧、不反拧。
2. 按 Ctrl+U 应用预设，然后连续按 Ctrl+H，每 10 步读一次 Ctrl+K 状态。
3. 满足以下任一条件即结束：
   - **成功**：最后一个（最靠尾部的）关节的沿管位置超过特征终点，即整条身体越过特征。
   - **跌落**：关节平均高度低于 0.12 m。
   - **停滞**：同一步连续 6 次无法执行，原因都是“反馈不可用：轴无效”，顺应性按规则拒绝执行。
   - **步数上限**：450 步，本次没有试验触到上限。
4. 一步无法执行时间隔 0.5 s 重试，单次等待 8 s。

**重复试验的扰动。** 试验编号即随机种子（1–5，`SNAKE_TRIAL_SEED`）。每次试验做两项扰动：
- 管道滑动摩擦乘以 U(0.8, 1.2)；
- 初始姿态绕起始管轴随机转动 0–360°，改变机器人到达非对称特征（弯头方向、偏心侧、支管）时的相位。

两种步态在同一种子下扰动相同，是配对比较。

## 4. 记录指标

逐次试验的指标见 `trials.csv` 和 `trials/*.json`。分组的均值和标准差见 `summary.csv` / `summary.json`。

| 指标 | 定义 |
|---|---|
| 成功/总数 | 成功判据见第 3 节 |
| 最大沿管上升 `max_rise_m` | 各步结束时 26 个关节沿管位置的均值，取最大值减去 Ctrl+U 后的初值。弯管按管中心线弧长计；竖直管等同高度。**成功的试验在越过特征时停止，所以这一项被截断，不代表能力上限** |
| 到达成功步数 | 第一次满足成功判据的步数 |
| 平均每步上升 | 最大上升 ÷ 达到最大值的步数（mm/步）；理想值为 P·Δφ/2π = 5.3 mm |
| 下滑累计 `slip_back_m` | 平均沿管位置所有下降量之和 |
| 顶到力矩上限的时间 | 运动期间 \|τ\| ≥ 上限的样本占比，按全部关节合计以及最严重关节分别统计。τ = clip(kp·(目标−实际), ±上限)，每 10 ms 一个样本 |
| 最长连续饱和 | 单个关节连续顶在上限的最长仿真时间 |
| 持续堵转次数 | 单个关节连续顶在上限超过 2 s 的次数，参照舵机“保护时间 200×10 ms” |
| 力矩 RMS、发热指标 | 全部关节力矩的均方根；发热指标为 Σ τ²·dt，与铜损成正比 |
| 最大跟踪误差、管道接触数 | 实际角与目标角的最大差；各步结束时与管道的接触点数 |
| 顺应性步占比、重试次数 | 实际以顺应性目标执行的步数比例；无法执行而重试的次数 |

**关于“过载”的口径。** 舵机固件的过载保护阈值是 80%，而 EXE 已把输出限制在 30%，所以仿真里不会出现固件意义上的过载。这里的“过载”指一直顶在 EXE 力矩上限，即堵转电流持续不降。实机上这对应发热，以及转矩限制调高后触发保护卸力的风险。

### 观察

1. **标准螺旋碰到截面变化就掉。**
   - 在 real_s2l、各法兰、偏心异径、taper_bend、三通上全部失败，失败时头部刚越过特征约 0.15–0.2 m。
   - 原因：固定 R/P 的形状被特征顶开后失去夹紧，整机滑落。下滑累计约 0.8 m，即掉到地面。
   - 只有截面不变、只是轴线弯曲的场景能过：bend90 5/5，bend90_tight 5/5，bend45 3/5，incline30 5/5。
   - 在低摩擦带上 0/5。
2. **顺应性能过“变径、缓弯、低凸起、低摩擦”。**
   - 能过的场景：real_s2l、bend45、bend90、offset、taper_bend、flange10、flange25、eccentric、incline30、slip_band，均为 5/5。
   - 负载约为标准螺旋的 60%：顶到上限时间 42% 对 72%，持续堵转次数约为后者的 1/13。
3. **顺应性的失败模式都是“轴估计失效后停滞”，不会跌落。** 下面四类场景失败，日志均为“反馈不可用：轴无效”：
   - **高法兰**：flange40、flange55、flange_pair 均为 0/5。头部越过法兰 0.02–0.15 m 后停滞，身体最后一节停在 0.5 m。
   - **三通**：0/5。
   - **短弯头**：bend90_tight 3/5。
   - **先弯后变径**：bend_taper 3/5。

   这些场景中，身体的一部分被特征撑开或弯折，EXE 按单根直轴拟合时置信度低于 0.42，顺应性按规则拒绝执行。这是现有方法最明确的瓶颈，**也是后续改进的主要切入点**，例如分段或弯曲轴估计、对局部凸起的越障策略。
4. **法兰可越过高度的分界在 25–40 mm 之间**（外壳半径 29 mm）。
5. **弯头的影响。**
   - 缓弯（R=300 mm）对两种步态都可行；标准螺旋在 bend90 上与顺应性相当，但负载高得多。
   - 短弯头（1.5D）上顺应性反而不如标准螺旋（3/5 对 5/5）：弯曲处轴估计失效，固定形状反而能靠管壁引导通过。
6. **倾斜管**两种步态都能过。标准螺旋顶到上限时间 82%，为所有场景最高。

## 6. 局限

- **重复性。** 仿真接近确定性，扰动只有摩擦 ±20% 和初始转角，所以轴对称场景（直管、法兰）的 5 次结果几乎相同（标准差小）。成功/总数主要反映方法在该场景上是否可行，不是统计意义上的成功率。需要更大方差时可加入关节零位误差、kp 误差、管道位置误差等扰动。
- **成功即停止。** 最大上升在成功试验中被截断；比较不同方法的爬升能力时应结合到达成功步数。
- **参数未实测部分。** 摩擦、关节阻尼都是估计值。头部用圆柱代替真实外形。外壳散热格栅和金属轴承盖没有建模。
- **机器人长度。** 26×64.5 mm 绕 110 mm 管，Yamada 离散关节点径向交替偏离约 ±17 mm，这是离散链本身的限制。
- **过载口径。** 只统计到 EXE 力矩上限的饱和；仿真没有温度和固件保护模型。

## 8. 复现

```powershell
python tools/build_real_pipe_scene.py; python tools/build_pipe_network_scenes.py   # 场景（已生成，可省略）
python validation/baseline_experiment.py              # 全部 160 次，已完成的跳过；10 个 EXE 并行，约 1.5 小时
python validation/baseline_experiment.py --analyze    # 只重新汇总、作图
```

运行时会打开 10 个 EXE 窗口（端口 19100–19109）。不访问串口，不驱动实机。新方法的对照实验可以复用同一脚本：加一个步态选项，或在 `--out` 指定新目录。
