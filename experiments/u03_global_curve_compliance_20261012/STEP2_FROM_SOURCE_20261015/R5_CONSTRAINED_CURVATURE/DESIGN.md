# R5：在原边界内求几何修正方向

R1…R4共16次全源端启动全部保留，完整动作通过数为零。R4虽保留了探测命令分量，但仍在接收直管接触前因源侧卷绕条件失效停止，不能评价G更新作用。本版仅修正几何方向求解器，完整初态、物理、源承载判据、粗先验、顺应参数、探测、估计及写回门槛、0.02Hz与235秒均沿用R4。

固定R3末承载边界的非动力学诊断表明，原无约束GN方向可能始终压入一个已有接触，因此所有回溯步都被拒绝；同一个静态几何/接触目标存在误差很小的有界解。简单把接触约束线性化后再缩步仍会因非线性间隙偏移而停滞，故本版用SLSQP计算14个前部曲率积分坐标的受约束方向。

二次目标保持原几何残差的局部GN模型及阻尼。总关节±88°、偏差±90°、12°/s偏差速率、20°/s总命令速率及原扭矩抗积分条件进入变量边界。实际观测接触的精确局部法向间隙、1.5/m/s曲率修正速率、12/m修正上限、24/m总曲率原则上限和每次2mm预测节点变化进入非线性约束。总曲率原参考已更高时仍沿原“不再加重当前峰值”规则；接触允许0.8mm及额外0.1mm/既有不良基线的原规则也不改。最后仍执行原精确非线性检查和回溯，不以求解器成功标志代替边界验证。

求解变量按单次角度速率归一化，约束按自身上限归一化。内部曲率速率和位置步长使用原上限98%的保守数值余量，最终仍按原上限检查。最多60次内部迭代后，即使求解器没有报告最优收敛，也只能采用通过全部原精确边界且目标不增加的候选；求解器状态和迭代数逐帧记录。固定R3末边界的120次更新回归将T/P头误差从162.87/193.73mm降到0.434/1.018mm，此结果不是动力学轨迹。

规范C继续由曲率积分的原20关节命令，在一个实测后部承载边界下私有FK解码。几何投影后叠加外部局部模式，保护14…19关节；Bishop近似单独保存。真实根/qpos不写入，私有控制计算只用运动学和Jacobian，不查询目标网格碰撞/距离；场景标签只用于离线验收。

运行前检查禁用全部积分函数：同初态连续、真实状态不写入、G不替换、原生几何与接触Jacobian、局部模式分离、后部命令保护、步长/角度/曲率边界、检查点回读、旧接触判据回放及负例。固定保存边界的改善只作机制回归，不称动态可达。

通过审计后另冻快照，再从原全源物理t=0运行两先验×冻结/更新G四组。原初态独立复核保留；当前新代码的独立复核尚未通过，不冒称通过。必要修正和继续验证已获用户授权，全部失败及代价保存，仍须完成真实接收直管接触、多位置证据、可靠估计、更新组G写回、新包绕及承载重叠、整身转移和至少50秒继续滚动才可验收。
