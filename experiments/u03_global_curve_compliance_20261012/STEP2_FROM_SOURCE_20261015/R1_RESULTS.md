## 实际原因

R1 起动稳定门槛使用全部源侧合力，释放后的保持门槛却只使用固定材料 M8…20 的竖直合力。已保存实际数据表明：

| 时刻 | S | 源侧总竖直力 | M8…20 竖直力 | 源包络内杆数 |
|---|---:|---:|---:|---:|
| 0 s | 0 | 25.9827 N | 14.3371 N | 21 |
| 2.0 s | 0 | 28.0190 N | 10.6282 N | 21 |
| 2.7 s | 0 | 28.0195 N | 10.4373 N | 21 |
| 3.0 s | 0.04350 | 28.1345 N | 10.8457 N | 21 |

固定后段的 40% 自重门槛为 11.2069 N，它在 S=0 的全源保持期间就已低于门槛。推进后后段承载反而回升；总源承载始终接近自重，目标接触为零。**已证实的是门槛所用支撑集合不一致，不能归因为释放导致新的失接。** M0 仍是源管上的有效承载接触，在完全源管阶段不能因其预先编号属于“前八杆”就当作已释放而排除。

详细逐帧数字、组内精确相同检查、全部视频读回和代价见 `R1_FAILURE_DIAGNOSIS.json`，原始记录仍在四个案例目录中。

## 修正安排

另立 `R2_SUPPLY_CHART/`，保留同一个完整给定初态、原 G/C/关节映射、粗先验、探测、局部反馈、物理和推进规则。只修正源侧支撑集合及与之统一的起动/保持判据：用实际剩余源管图表上的支撑，以及紧邻该图表的连续桥接支撑，而不是固定材料编号。40% 承载门槛不降低；还增加尾侧连续源包络材料数量与源轴绕行检查。新的接收支撑仍单独判定，不能混入源侧承载；真实失去承载/卷绕时仍停止。

修正前先在 R1 保存状态和合成失支撑事件上做非动力学回归，冻结科学参数和代码，再从原全源 t=0 重做四组。该必要修正和继续验证依据用户本轮明确授权；原全源初态独立预检记录保留。R2 当前修改的独立复核不冒称已通过，后续阶段结果仍须监督独立验收。
