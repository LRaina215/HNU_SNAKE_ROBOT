# 从全源管 t=0 开始的 Step2：实现与运行前登记

本目录是当前唯一的起步实现。**新增动力学启动 0 次，积分调用 0 次，独立起点/控制链审阅尚未通过，运行入口关闭。** t30、t90 及以前的接管后试验仅保留作诊断，不作为本轮起点或完整动作证据。原 20 关节、21 杆机器人、原有限 L 管、质量、摩擦、伺服与接触参数保持原样。

## 唯一起点及其局限

`SOURCE_INITIAL.npz` 是由原 U03 t0 螺旋构造的全源管给定状态，不取任何中途动作帧。先沿已知源管 X 轴平移，使最前骨架节点位于 X=0.90 m（距源管末端 50 mm）；再只在这一个全源螺旋上做静态柔性平衡调整。静态求解未调用 `mj_step/step1/step2`。给定全源螺旋不研究从地面缠上源管。

保存状态的直接证据：

|---|---|
| 全部 21 杆中心 | 均在原有限源管包络内 |
| 杆中心 X 范围 | 约 0.5223…0.8843 m |
| 杆中心距源轴半径 | 约 85.13…93.68 mm |

双视角为 `SOURCE_INITIAL_DUAL.png`，逐杆几何/反力为 `SOURCE_INITIAL_21_RODS.csv`，完整证明为 `SOURCE_INITIAL_PROOF.json` 和 `PRE_DYNAMICS_AUDIT.json`。包绕检查还包含沿材料顺序的连续源轴极角绕行、自碰与穿入检查；不只依赖一个宽松半径范围。

**该状态尚不是已验证的稳定平衡。** 静态加速度范数约 2.923，最大分量约 1.203；优化器的终止标志不是稳定性证书。本实现因此把全源保持纳入从 t=0 连续记录的控制过程：S 保持 0，局部反馈运行；21 杆仍在已知源包络、源承载为自重 90%…110%、平移速度分量 <0.03 m/s、基座及关节角速度分量 <0.03 rad/s，连续满足 2 秒后才允许 S 前进。10 秒内不能满足则保存并判为全源稳定失败。**不会把稳定后的帧另取为起点，不裁掉 t=0，不重置时钟，不换中途姿态。** 这一动态稳定性门槛目前未执行、未通过。

## 已实现的完整控制链

| 环节 | 实际代码 |
|---|---|
| 全源起步、保持、开始释放 | `source_controller.py:FromSourceController.command` 从 S=0 开始，按实际源侧承载与速度判定何时释放 |
| 前部释放与沿粗曲线伸出 | `from_source_curve.py:set_nominal_family` 恢复完整 `grow=smooth(S/6)`：源螺旋端点/导数混合、极坐标过渡、中间控制点、X 等待段、75 mm 接收引导段和目标螺旋 |
| G→局部 C→20 关节 | 原 true-arc/Bishop/交替关节曲率积分；初始曲率预加载使 raw_command 与保存 ctrl 一致，按材料坐标在 S=0…0.75 平滑消退。真实运行只写 ctrl |
| 接触后开始试探 | `cylinder_estimator.py` 将前部 M0…7 的原始非源接触与圆柱候选门限分开；不等可靠圆柱才触发探测 |
| 两方向接触证据 | `global_update.py:probe_command`，两曲率分量各一个 4 秒带符号正弦周期，幅值 0.18/m，支持域在前八材料节点内 |
| 几何候选与可信度 | 保留原接触点/法向多样性、至少两材料、空间跨度、拟合残差、内点比例等门槛；不合格时保持可靠旧估计，禁止 G 写回 |
| θ→过渡→入口切向→螺旋 | `global_update.py` 从接触极角与轴向位置的螺旋相位关系构造 θ 候选；几何与 θ 共同进入新的过渡端点/导数和目标螺旋，不再只有固定 θ 时间表 |
| 局部顺应持续运行 | 接收径向模式、前部接触法向曲率卸载、源尾部曲率模式。前部卸载用实际后部接触材料作为支撑锚的静态雅可比；源尾卸载仍要求前部已确认，避免过早松开源支撑 |
| 保留后部支撑并滚动 | S 前进时沿用连续 F/M/χ/材料 gauge；跟踪已知源接触及连续的桥接/未知接触。前部未确认而后部保留承载低于自重 40% 持续 0.25 秒，停止并保存失败，不盲目继续释放 |
| 连续实际运行和验收 | `source_runner.py` 从第一步前的 t=0 开始记录状态、实际视频、未标记接触、候选与写回；`evaluate_chain.py` 逐项检查新接管、整身转移和滚动 |

释放、伸出和滚动使用同一共同材料坐标，不给前部塞入已伸出的姿态。初始全源保持阶段不声称正在滚动；释放后也不以“冻结 S”冒充“后部继续滚动”。若实际承载条件丢失，控制器给出失败并停止。

前部曾经确认不会永久关闭支撑检查：确认后仍须保持前部估计包络，并有当前合格接收接触承担至少 40% 自重；任一条件丢失就重新要求后部保留承载。若后部也不足，0.25 秒后停止。源尾卸载也只在这个当前接收承载条件有效时启用，不能凭历史确认继续松开源侧。

θ 候选具体为接触极角减去 `2π×轴向站位/pitch` 的圆周均值，要求相干度 ≥0.70，偏置限制 ±15°。这是“接触点可由接收螺旋解释”的**待验证假设**，不是物理入口平面可观测性的证明。侧面接触仍不能独立定位真实轴向入口；保留原粗入口平面及 40 mm 名义不确定量，不宣称为校准置信区间。

## 连续性、局部反馈和信息边界

共同 S 从 0 开始，源侧常数只因全源放置平移 X；F/M 与共同 χ 的公式保留。材料编号始终 0…20，观察器从实际 t=0 开始积累历史，目标图表和预测锚点初始未置。未知/不可观测的区间累计为 unknown，不补造目标进度。

G 写回以 0.2 秒为间隔，原位置/轴向/半径速率与增益保留。每次尝试同时检查：

- native 命令变化 ≤0.1°；同材料 G 节点位移 ≤0.4 mm。
- 过渡与接收段的 129 点位置变化 ≤0.4 mm，切向变化 ≤0.1°，世界曲率向量变化 ≤0.02/m。
- 材料参考框架变化 ≤0.1°；θ 速率 ≤0.25°/s。

最多七次回溯；失败则恢复原几何、θ 和有效曲线缓存。冻结 G 组仍做同样的估计、候选构造与回溯，最终不写入 G。两类粗先验、局部反馈、完整给定状态、观测规则、试探触发和物理预算相同，组内唯一开关为 G 写权限。物理轨迹分岔后，观测数值可以不同；不重放一份观测冒充真实闭环。

前部法向卸载曲率幅值上限 0.30/m、速率 0.06/m/s，阈值 12 N；接收径向模式幅值 ±2 mm、速率 0.25 mm/s；源模式幅值 0.4/m、速率 0.08/m/s。局部控制每次命令都执行，观测/支撑不合格时不使用虚构目标接触。物理伺服仍为 20°/s、±88°，原扭矩限幅 2.355 Nm。

在线输入只含已知源管、粗目标先验、机器人位姿/关节和未标记接触点、法向、合力、间隙。新增的未标记世界合力用于承载判别，不带目标/弯角标签。真实目标轴、半径、网格和接触标签只用于独立评价。四类真实管道反力分别记录为源直管/源入口/目标直管/目标出口，以免再把弯角承载误称为目标直管承载。

## 运行前检查结果及未验证项

`audit_before_dynamics.py` 禁止三个积分入口，只做保存状态 forward、纯曲线计算和机制检查。已通过：

- 全源几何与非源零接触；初始无地面接触、无超过门槛的管道/自体穿入。
- 原目标参数仅用于离线数学回归：S=0、1、3、4.5、6、7.5、9、15 八点恢复曲线与原实现命令差 0°，完整早期曲线没有被晚期公式替代。
- 两类粗先验的 75 个静态采样点覆盖 S=0…37；原始命令最大值分别 84.53°、87.48°。这只是采样检查，不是实际动力学可达性证明。
- 组内零时刻 raw_command 相同并与保存 ctrl 匹配至数值精度；未通过源稳定门槛时 S 保持 0；控制器调用没有改写实际 qpos；材料观察量有限。
- 人工构造、基于粗先验的事件/候选检查覆盖：圆柱门限前启动两方向试探、θ 和几何写回、冻结组回滚、各连续性限幅及运行入口阻挡。**这些人工数据不是实际接触证据。**

初始规划 G 与实际同材料杆中心世界 RMS 差约 9.205 mm，未做配准。初始曲率预加载解决命令交接，不表示 G/C 与实际世界构型精确重合。`STATIC_G_RELEASE_PREVIEW.npz` 只是数学曲线预览，不是实际伸出或转移轨迹。

仍未验证：初始保持能否在原物理条件下稳定、实际前部伸出是否可达、试探能否提供足够可观测性、G 写回能否发生在新包绕之前、实际材料交接和整身转移/滚动是否成功。任何一项失败都如实保存，不能用更晚起点补过。

## 首轮登记和完成门槛

登记为两类粗先验 × 冻结 G / 更新 G，共四组；每组从同一个 `SOURCE_INITIAL.npz` 开始。235 秒物理预算包含 t=0 的全源保持；释放后的名义频率 0.02 Hz。新起点下两个探测方向各 4 秒，取代旧晚期起点下的 14 秒；目的是在新接触至包绕的时间窗内取得双向证据，已在任何新动力学前登记，后续不能据结果改参数补跑。

验收必须同时检查：全源 t=0→源侧稳定→曲线驱动释放/伸出→原始前部接触→可靠接触估计→更新组在新包绕前写 G→前部新包绕→源/目标直管同时有实际承载→整身有限目标管内转移→至少 50 秒后续滚动。还要求已有源侧后部在接管期间有实际自转、每杆后续轴向前进 >40 mm、同向轴向自转 ≥90°、末端轴误差 <5°，以及原关节、扭矩、自碰、穿入和地面接触限制。

冻结组是动作对照，不要求写 G；更新组若只在前部包绕后才写 G，其接管因果链不通过。几何误差下降不能替代上述门槛；动作通过也不自动意味着更新组相对对照有收益，仍需看配对差异和代价。

`REGISTERED.json` 的 `dynamics_authorized` 和独立审阅标志均为 false，尚无 `INDEPENDENT_REVIEW.json`。`source_runner.py` 在创建任何案例目录或调用积分前强制检查这些条件。当前没有启动四组案例，没有新增主动搜索，没有新的额度截止安排，也没有宣告完整 Step2 完成。后续审阅必须针对本唯一全源起点、实际代码和完整验收链；当前交付不自行解除运行门禁。
