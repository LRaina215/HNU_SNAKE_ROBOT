# R3：四次实际失败与两项控制层级缺口

四组均由原全源 t=0 开始，源稳定后实际释放伸出，但 T 在31.1秒、P在33.0秒触发支撑观察器停止。没有前部新环境接触、可靠估计或G写回；两对逐值相同，不能评价全局更新收益。累计真实启动12次，完整动作成功0次；全部原始轨迹、视频、末状态和检查点保留。

T/P 饱和关节时间均为0，最大扭矩约2.074/1.664 Nm；源侧最大侵入0.776/0.730 mm，目标/接头、自体、地面侵入均为0。最终同材料G/实际中心RMS约115.0/124.2 mm。连续Bishop重构C的误差约193.9/157.8 mm，不能把该近似曲线称为准确可执行几何。

停止时真实源直管仍承担约28.05/28.09 N，已知源一致法向力约47.44/37.15 N，没有全部物理失接。源包络中仍有15杆，但最后一个连续尾段只有4杆、约94°，因此“必须以末杆结尾”的180°检查失效。后部中间仍存在实际承载的源卷绕段，固定尾后缀不等于全部剩余承载卷绕。下一版保留180°/四材料/真实接触及40%门槛，改选实际带载的连续源图表组件，并保留原尾后缀量作对照。

另经私有代数检查发现，R3投影目标包含外加试探和力卸载后的曲率，却追踪未包含这些局部变形的G。投影自由度能以1.12°/1.27°补偿精确抵消两个0.18/m探测，所需曲率速率约0.233/0.272每米每秒，低于1.5的投影限幅。`LOCAL_MODE_INTERFERENCE_AUDIT.json`证明的是“该控制层级允许精确抵消”，不是声称本轮已经测到100%抵消；本轮尚未触发实际试探。

下一版将几何C投影与外加局部曲率分开：G→含径向顺应的几何C→承载姿态投影→叠加试探/法向/源模式→原生关节积分。投影目标不再把外加模式当误差。真实20铰链FK作为曲率参数化C的几何解码器，记录可执行C与连续Bishop近似两者；不会把实际整身FK回填G，实际根和qpos仍不写入。

本轮结果、代价和两对零差异在`COMPARISON.json`；下一版另立、登记、冻结后从原全源初态继续。估计可信度、多材料/空间/法向条件、G写门槛、原物理和四组对照安排均不降低或替换。
