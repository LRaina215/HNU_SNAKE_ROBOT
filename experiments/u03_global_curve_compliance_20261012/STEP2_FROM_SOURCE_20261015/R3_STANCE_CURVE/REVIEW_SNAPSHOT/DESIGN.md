# R3：实际承载姿态下的 C 曲率映射与新接头支撑

R1 四次、R2 四次真实启动及全部失败数据保留，前两版完整动作成功数为 0。本版继续从同一个、字节不变的全源 `SOURCE_INITIAL.npz` 和物理 t=0 开始，不从 R2 中途状态重启。

## 必要修正的直接依据

R2 已实际完成全源保持、前部释放/伸出和接头接触，未触及接收直管、没有可靠几何拟合和 G 写回。停止时尾部仍绕源轴 315°/359°，接头仍实际承载；原跟踪器只接受已有加载接触的延续，漏掉源图表材料在新接头形成的新持续支撑。

另一个独立缺口是世界几何映射。T 的 40 秒帧关节最大跟踪差仅约 0.401°，实际头端距 G 约 258.6 mm。把原曲率命令送入真实20关节私有 FK，并注册到实际承载姿态，会重现约 259 mm 的头端偏差。原生离散命令还有约 35 mm（S≈5.9）和 135 mm（S=10）的内在形状偏差，不能用“命令已送入伺服”代替世界曲线跟随。上述保存状态只用于诊断，不作为后续初态。

## 修正一：持续的新未知支撑

保留 R2 的尾侧连续源图表、三材料邻接范围、40% 自重门槛、180°/四材料几何检查、0.25 秒持续失效停止。曾经属于源几何图表的材料，若在邻接区形成新的未知接触，经连续 0.10 秒点/法向观测确认，可加入未知桥接支撑。已知源与未知桥接的力分别记录，已合格接收接触不能冒充源侧力；还要求当前已知源一致接触法向力至少 0.5 N。无接触、失去源卷绕或只有接收接触仍不能通过。

R2 的接触记录离线回归中，新判据的最长短暂失效为 T 0.125 s、P 0.025 s，低于原 0.25 秒停止门槛。它不是降低承载阈值，而是补上新接触的确认过程。新实际轨迹仍可能失效，届时以观测器条件失效报告，并用离线真值核对是否真的物理失接。

## 修正二：G→有界 C 曲率→原20关节

`stance_curve.py` 以当前实际后部承载杆的位置、方向作为私有 FK 边界。G 本身仍由粗先验/接触估计和连续 S 生成，材料编号不变，不由机器人 FK 或实际轨迹替代。

局部变量是按材料坐标定义的曲率场模式，其原生关节积分构成精确的归一化基。优化先修改 C 曲率，再经原积分得到20关节命令；真实模型只接收 ctrl。私有数学根只用于 FK 注册，实际 qpos/根不被写入。新映射使用机器人运动学、Jacobian、粗先验及实际未标记接触，不调用私有碰撞、目标网格或距离查询。

投影从全源稳定并出现头端源包络释放后启用，初始命令与 R1/R2 相同。它每次做一个阻尼几何步，追踪 G 的前部材料点，同时尊重观测接触的局部法向间隙及粗接收管中心避让。仅前14关节的积分模式可变，14…19 的原生滚动/已有顺应命令不受该投影修改；共同 S、χ、F/M 和材料历史不重置。

登记的边界为：关节偏差最多 ±90°且总命令仍在 ±88°内；修正速率 ≤12°/s；C 曲率修正 ≤12/m、速率 ≤1.5/m/s；总曲率原则上 ≤24/m，原参考已有更高曲率时不因修正继续增加峰值。固定当前承载姿态时，每次修正的私有 FK 材料点变化 ≤2 mm，合成关节变化仍受20°/s原限制。接触间隙变坏也有回溯约束；扭矩饱和且已有跟踪误差时，不沿同方向继续加大修正。此处2mm限制针对该次曲率修正，不冒称对感知到的真实承载边界运动施加了限制。

既有径向/法向/源尾部顺应和双方向4秒探测继续执行，估计器的材料数量、空间/法向多样性、残差及可信度门槛完全不变。G 仍只在原可靠估计门槛后有界写回，冻结组不写 G。没有用单接触强行宣布圆柱可靠，也没有注入目标标签触发更新。

连续 C 和真实20关节 FK 的可执行预测节点都记录。后者是“由 C 曲率积分得到的候选关节”在单一实际承载边界下的预测，不是实际姿态回放；G、C预测、实际逐杆位置分别保留，世界精确跟踪仍须实际验证。
