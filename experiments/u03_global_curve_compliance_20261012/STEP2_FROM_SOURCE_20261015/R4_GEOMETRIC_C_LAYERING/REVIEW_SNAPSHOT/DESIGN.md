# R4：承载源卷绕段、几何曲率与外部局部模式分层

R1、R2、R3 的十二次全源端真实启动全部保留，完整动作成功数为零。本版仍从字节相同的 SOURCE_INITIAL.npz 和物理 t=0 开始，初始全源保持也包含在连续时间线内。物理模型、两组粗先验、0.02Hz、235秒预算、力顺应参数、两方向各4秒接触探测、拟合可信度及G写回门槛均不改。

R3 停止时源端仍实际承载约28N，中部有连续卷绕；旧判据只检查末杆相连的尾端段，漏掉已加载中部源段。本版从已知源几何和已知源接触的连续材料段中，优先选择已知源法向载荷至少0.5N且绕角最大的段。仍要求至少4材料、180°和40%自重，连续失效0.25秒停止。未知桥接接触仍须源图表材料、与该段相邻不超过3材料、点/法向持续0.10秒，且不属于已合格接收接触。旧尾端段统计继续保存，以便区分判据变化和真实物理脱离。

R3 的几何优化直接优化含探测和力顺应的总曲率。离线审计发现它允许用几何修正抵消外部探测曲率；这证明结构上存在抵消自由度，不代表R3实际发生了完整探测抵消。R4 将几何曲率及几何位置目标在原生映射之后、添加外部模式之前保存。优化只计算几何曲率的残差及Jacobian，再叠加源顺应、探测、前部力释放和初始预载的原生积分贡献。最终总曲率、总关节角、速率及实际接触间隙仍共同受原边界约束。逐帧保存几何原生命令、投影后几何命令、全部局部模式增量、探测单独增量和分解数值残差。

G 继续表示计划世界曲线，不从实际机器人轨迹复制。本版规范的 C 节点由命令曲率积分成原20关节，再在一个实测后部承载杆边界下通过私有FK解码；稠密C仅在这些节点间插值。它是可执行候选的运动学预测，不是实际前体姿态回放，也不保证动态跟踪。原连续Bishop重建另存为 bishop_curve_points/dense/chord_error，不再把这条近似曲线称为原生关节的精确预测。G、C和真实材料节点分开记录；与R3连续Bishop C的误差不能直接当成同一定义的改善。

私有运算只调用机器人运动学及Jacobian，不使用目标网格碰撞/距离查询。实际模型初始加载后只收到ctrl，真实根和qpos不写入。投影仍保护14…19关节，保持原曲率/角度/步长边界；全源稳定且头部释放后启用。实际后部边界变化造成的C变化会单独体现在预测中，2mm/次仅约束本次曲率修正，不约束真实承载杆运动。

运行前审计禁用全部积分函数，回放R2、R3保存接触检查新承载判据，并检查无接触、短卷绕、接收力冒充等负例。另检查几何Jacobian、局部探测分离、原生命令分解、固定后部边界时不复制实际前体、原生杆长、初态连续、G不被替换及检查点读回。静态回归仅证明机制，不能替代完整动态链验收。
