# R4 四次真实启动结果

四组从唯一全源 t=0 连续开始，全部保存失败。T在35.775秒、P在40.375秒触发 supply_observer_invalid_before_capture；累计全源端16次真实启动、完整动作成功0次。

T/P首次前部非源原始接触为34.350/37.425秒；离线真值显示接收直管所有保存帧的法向力仍为零，原始接触不能写成接收直管接触。均无可靠几何和G写回，只有第一探测方向部分执行，两对全部状态/命令/S逐值相同，无法识别G更新效益。

本版局部模式分层按记录保留：最终总命令减去投影几何与外部局部增量的最大数值残差约5.1e-14度，实际发送的探测原生增量峰值约1.28/1.27度。该证据仅证明命令分解，不能代替多位置接触证据或物理探测响应通过。

T/P末保存帧选中源承载段分别为材料5…11/6…13，绕角179.74°/155.40°，已知源法向31.11/57.41N；源直管竖向力31.39/30.75N。仍有物理承载，但原180°卷绕条件失效，不称全部物理失接，也不以有竖向力代替卷绕完整性。旧尾后缀仅1/3杆，换组件修正确实避免R3的早期后缀误停，仍未完成支撑交接。

T/P扭矩饱和暴露0.4/15.5关节秒。源/目标含接头最大侵入分别1.013/0.970mm和0.930/0.500mm，无自体或地面侵入。四场景组件侵入、积分剂量与载荷在NATIVE_AND_COMPONENT_COSTS.json；源直管、源入口、接收直管、接收出口分别统计。

末材料中心G/实际RMS为186.2/149.7mm；规范原生C/实际为5.64/109.12mm，P的动态命令跟随也已变坏，不能一概归因于几何近似。连续Bishop近似另存，不能拿其旧误差与新C误差直接比较。

进一步分开检查伺服两层：P末帧原始命令与已施加ctrl最大差仅0.216°，ctrl与真实关节却相差22.08°；该末段主要是饱和下真实关节失跟随，不能归因于软件20°/s速率器。T全段ctrl/真实关节最大差约1.276°。这些差异已保存到组件分析JSON。

固定R3末承载边界的额外非动力学诊断发现：几何/接触软目标有头误差0.46/0.07mm的静态解，但现有单步无约束方向加回溯会在140/115mm附近停滞。下一版优先把原接触不恶化限制放进求解方向，而非只在事后拒绝方向；全部物理/角度/曲率/推进/探测/拟合门槛保持。静态可行解不代表动态可达，下一版仍需从全源t=0重新验证，R4代码和数据不改。
