# A14：源接口M衰减延长的机制对照

监督审阅A14_DIAGNOSIS.md后授权一次原模型235秒验证。本版只改A13的M规律，不预先称为改进，不追加M参数网格。阶段B不启动。

令x=clip((S−5)/4,0,1)，mu=min(S,5)+4[x−2.5x^4+3x^5−x^6]，M=.054mu。mu=S直到5，5–9将斜率连续降至0，9以后mu=7。A13原来5–7衰减并停在mu=6。S、F、公共材料ψ、曲率输运与交错原生关节映射、75毫米接收弧、目标入口安排及其余曲线构造逐字沿用冻结A13。修改M会同时改变源接口世界位置和材料窗站位；不是单独移动绘图坐标。源半径/螺距、U03初态、原XML/STL、步长、接触/摩擦/质量/重力、2.355Nm、±88°命令及20°每秒派发限速保持。

可检验假设：延长源接口移动会通过交接处形状变化，减小A13在40–54秒的后部位姿倾斜及源弯头约束失配，减轻51.5–52秒材料回退，并给前部稳定获取提供机会。尾部载波基本不变，因此结果可以区分交接形状作用与载波被关闭的解释。此假设不要求离线预先证明动力学改善，也不宣称已锁定唯一原因。

运行前冻结以下比较口径：

1. 固定节点15–21实际世界到世界C配准；同时报告14、16起始的敏感性、残差以及源轴倾角，不比较任意根坐标的原生FK旋转。比较40–54秒倾角的均值/峰值、40/45/50/52/53.8秒样本，并与U03、A13对照。
2. M10源分类接触力/持续采样、实际与C中心差；区分源直段几何和含源弯头的接触。比较名义/实际源材料集合及52秒前后支撑变化。
3. 固定M15–M20在51.5–52秒的平均X变化、极角变化，保留各杆/半径/标准差；比较整个50–54秒回退，不以变动杆集合平均。
4. 原前六判据：六杆半径65–130毫米、Y=.15–1.2米、跨度>180°、前六目标法向力>.2N，同时保持2秒。原整身判据及≥50秒末段、每杆正Y前进>.04米、轴与Y<5°均保持。

离线已知代价须保留：45秒名义材料极角对应变差，48秒原生前部配准误差变大；名义目标窗前六节点首次从53.0推迟至56.4秒，位置+半圈首次从41.8推迟至42.2秒。它们不能当实际结果或被晚期改善覆盖。

判读：若后部倾角/源支撑/回退改善但前六仍失败，报告机制得到部分支持、完整获取仍未实现；若后部与前部都变差，收束这一M延长假设。若实际前六通过但整身失败，继续按原标准报告失败位置。本轮结束后不追着M作网格，不以局部指标取代阶段A成功。

准备只补此变更必需的取点、整杆净空、原88°限幅/20°每秒限速检查；实际仅一次235秒原模型轨迹，保留早停安全规则，保存原始状态与双视角连续视频。所有实际位姿、力及配准均用于诊断和失败停止，没有高层反馈。

必要准备已完成，见A14_PREPARATION.json：初始命令相对A13差0°，采样没有取点异常，整杆保守净空下界7.74179毫米；原始角峰值90.94660°、采样斜率峰值46.33659°/秒、混合间隔保持段末限速差峰值9.86091°。这是名义准备诊断，实际驱动依旧按原限幅/限速执行；混合采样并非完整25毫秒派发历史，不能宣称消除了驱动误差。通过准备不代表机制或物理成功。
