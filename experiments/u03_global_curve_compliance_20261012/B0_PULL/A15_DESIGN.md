# A15：目标接收半径与承载接触假设

A14原条件235秒及完整归档完成，独立判定阶段A失败，但源侧机制指标改善。监督要求保留A14的M及全部源侧/F/公共滚动，选择一项目标接收形状修改，验证接触能力；本版只修改目标螺旋半径以及匹配它的必要C2接收端/75毫米导入弧解析端点导数，阶段B未开始。

## 依据及唯一最终方案

原目标直管是半径56.5毫米的有限圆柱，头壳是半径29毫米、长64.5毫米的原圆柱，其余杆为原H/V网格。源螺旋仍使用A14拟合R=.0991869522236036米、P=.18266863819422827米。原目标也使用同一R/P；64.5毫米首弦对应的最小杆轴半径约94.249毫米，简化表面间隙8.749毫米。A14在53.9秒六杆几何范围全满足且绕角173.673°时前六目标力均0，监督实际简化杆面间隙4.2–16.2毫米。它同时有世界位姿偏差，不能把全部失接归于半径。

90.5毫米直接包络相切方案做过离线准备，没有动力学：名义杆轴最小半径85.153毫米、简化重叠.347毫米。但原生曲率积分命令的FK已比名义C更向内；将前7节点仅作诊断性目标配准后，原mj_forward接触记录出现多毫米重叠。例如53.9秒前部若干杆−5至−8毫米，60秒约−4至−7毫米，160秒头壳约−9毫米。该配准残差约11–12毫米，不能据此证明实际必然侵入，却说明简单“名义杆包络相切”忽略离散映射，会给本次接触假设附加明显过紧代价。准备代码/数据留在A15_radius905_rejected.py/json，不是实际候选轨迹。

唯一最终半径选为**Rt=.0955米**，目标螺距仍P；beta_t=1/sqrt(Rt²+(P/2pi)²)，a_t=P*beta_t/(2pi)。目标曲线=(1.1+Rt*cos(phi),.20+a_t*u,1+Rt*sin(phi))，phi沿原入口相位和名义材料站位推进。名义杆轴最小半径约90.36毫米、简化间隙约4.86–4.89毫米，较A14缩小约3.85毫米。固定导入弧与前缀末端自由点/切向/曲率/三阶导数同步用Rt、beta_t、a_t；源端控制点、X等待、M、F和psi未修改。

采用95.5而非90.5是必要离散/真实几何核对后的修正，没有半径网格或新增动力学。95.5毫米前部诊断配准的原接触记录在50–60秒可出现约.05–2.83毫米接触重叠；70秒头壳诊断重叠约4.43毫米，保留这一不利样本，不能宣传“全部可行”。这些是无动力学的假设位姿，不是实际轨迹；真实原安全停止规则保持。本次目标是检验更小接收半径能否在实际位姿下形成承载接触，不预判成功。

## 距离查询的有效性

mj_geomDistance大阈值查询不能直接解释成真实侵入。同一A14实际53.9秒头壳/直管，无该对接触且前六目标力0，50毫米阈值却返回−58.79毫米，而20/25毫米返回+16.189毫米。监督复现见SUPERVISION/A15_geometry_query_consistency.json；初始大阈值准备保留为A15_wide_distance_rejected.py/json，已被有效结果替代。部分20毫米网格查询也与原无接触记录矛盾。

最终接触核对用原mj_forward生成的contact.dist作为接触重叠依据；无接触时用5毫米小范围正距离辅助，等于阈值只记超出范围，负查询但无原接触的值不采信。保留所有原始查询/状态标识及配准残差。线段简化包络不含有限端/弯头/网格，不替代原碰撞记录。没有用这些查询反推实际控制或修改模型。

## 冻结假设与判据

预计改善事件：50–60秒前六实际几何范围内至少产生可承载目标接触，并与>180°跨度同时保持2秒，而不是只有更多名义节点或几何位置。然后继续原全21杆转移与至少50秒末段/每杆正Y前进/轴方向验收。

源侧代价：更大的目标曲率/关节幅值、导入弧端点变化和相应站位可能增加前中段负载、改变源弯头支撑、抵消A14减轻倾斜/回退的效果。对比40–54秒固定后部配准倾角、M10源力/位置误差、51.5–52秒固定材料X变化；保留真实目标侵入、饱和/跟踪和失接时间。

原XML/STL、U03初态、质量/重力/摩擦/低层伺服、步长、命令±88°与20°每秒、力矩2.355Nm保持。公共psi初始化完全从A14获得，材料锚点和源轴输运也保留A14；全局G与连续曲率仍真正生成命令，共享S无实际位姿/接触反馈。准备通过后仅一次235秒原模型仿真，原安全早停保留。不为距离查询问题新增动力学，也不要求离线证明唯一动力学因果。

最终必要准备见A15_PREPARATION.json：0–100秒每.1秒，25–60秒补.025秒，100–235秒每.5秒，没有取点异常。源R/P/beta/a/phi0/x0、F系数、共享shift比例、gauge、尾站位/材料锚站位及法向量差均0；S=0/5/7/9/20/37的源曲线点/F/M差均0。初始命令因未来样条端点数值影响有约.00000253°差，初始物理状态仍完全冻结。整杆保守下界4.30979毫米，原始角93.27240°、采样斜率48.452°/秒、混合采样保持段末限速差12.76629°，较A14的90.94660°/46.33659°每秒/9.86091°增加；原驱动仍88°/20°每秒。此增幅作为获取/源支撑代价保留，没有放宽驱动。
