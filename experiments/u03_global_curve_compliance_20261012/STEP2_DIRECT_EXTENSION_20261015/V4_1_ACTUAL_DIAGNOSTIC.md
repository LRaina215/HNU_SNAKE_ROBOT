# V4.1 实际单例：源侧保持失败

原始物理t=0的唯一T_UPDATE实际积分至11.125秒，2.1秒开始释放，alpha最大0.356、beta0、S0。停止source_boundary_drift_from_given，最终给定参考位移12.029002mm，稳定参考位移10.944754mm，最终稳定X位移3.792114mm、最大周向变化5.809041度。无接收接触、拟合、G写回、包绕、接管或整身滚动。完整Step2失败，未优于V3.3的15.125秒早停。

alpha>=0.15的有效分配采样中，后段实际力矩相对请求总力矩的RMS误差0.004499Nm、最大0.059628Nm。请求主要已到达后段舵机；但接触力分布未按静力分配实现，源侧继续周向漂移。不能把“力矩请求有界/送达”当“实际保持成功”，也尚不能唯一归因。

当前静态分配缺少源接触点加速度/位姿与浮动基动力学的共同约束，并省略其他接触载荷和接触力矩。下一步应先在少量已保存状态上检查兼容的源接触保持/动力学命令，实际运行仍须同一初态、原物理及12mm保护。所有旧例、启动器未积分错误、连续录像与逐杆数据保留；累计31次实际启动。V4原质量错误版本0次积分，V4.1只有这1次，不重复。
