## Changes relative to frozen V6.1

Only rough_planner.py and direct_controller.py runtime behavior changes. When the ordinary tracking solve and its existing backtracking reject all candidates AND the optimization-start C violates clearance beyond the original50um acceptance, a separate feasibility solve minimizes half the sum of squared negative normalized clearance residuals. It uses the same normalized native coordinates, original joint-step/joint-angle bounds, and hard original per-node motion inequalities. It starts from the current sent C, not a saved offline seed. Maximum iterations and objective tolerance use the existing tracking solver values.

The restored candidate must pass the original nonlinear clearance<=50um, motion<=2mm and finite/joint checks, with existing backtracking. It may increase the tracking objective from an infeasible start; a feasible-start tracking solve keeps its existing non-increasing objective requirement. This is numerical feasibility priority, not a relaxed clearance, an actual pose write, or a claim that the mechanical path exists. Logs distinguish tracking/restoration/hold, initial violation, restoration iterations and primary solver status. If no bounded restoration is found, C holds and all original physical guards remain.

Alpha/beta retain original actual joint tracking and previous common transmission-fraction rate limits. Additionally, the previous candidate must be accepted, its optimization-start C must be within the original50um clearance tolerance, and the actually transmitted geometric head must lie within the existing20mm rough receiver uncertainty of its C head goal. These are NEW uses for phase readiness of already-registered distance values; the20mm value was previously a geometric uncertainty, not an existing task tracking gate. The check prevents phase advancement during an infeasible restoration or a228mm task backlog. Readiness is evaluated for the next command and explicitly logged; current/next readiness and sent head error are distinct. Probe clock gating and estimator criteria do not use this new readiness predicate.

The independent G builder, immutable given pose, coarse priors, V6 source-axis balance, posterior given grip, transmitted native C state, marginal joint-bounded probe attribution, contact/fit/G update/capture chain and postcapture original mapping remain. No source feed/rolling occurs before actual capture. Original physical parameters, source12mm/12degree guards,3mm penetration/self/floor/joint/torque rules, all force thresholds and material/native integrals are unchanged. No full-path offline IK or new initial search is added.
