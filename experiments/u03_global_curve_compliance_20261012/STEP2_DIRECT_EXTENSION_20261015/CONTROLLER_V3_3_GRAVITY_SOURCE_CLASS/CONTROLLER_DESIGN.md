## 实际命令链

1. 源侧保持：保留给定预载，前部卸载和试探均不介入。源侧载荷90–110%重力、速度<0.03并持续2秒后才释放。
2. α：只释放前8关节，M8–M20后段总命令维持给定值。S和滚动相位均为0。第一次当前前部非源接触结束α；α保留实际到达的数值，不重置材料历史。
3. β：前14关节可参与局部包绕，保护M14–M20。接收极角从−165°按正方向增加，先沿下侧包绕。可靠几何前至多120°；置信度丢失时保持当前β，不倒退、不重置。向上首次接触不要求此后继续沿上侧绕行。这个选择使源侧与接收段具有相同物理手性，保留原材料滚动符号+1。
4. 只有原观察器确认新形成的前六杆包绕、可靠几何和当前接收竖向承载≥40%重力后，才启动S及0.02Hz材料滚动。其后才整身送入；保留50秒持续滚动/各杆输送和旋转验收。

G由不可变给定源曲线、已知源管与粗接收圆柱生成。接触时保存的是当时的G。C另外保存上一帧**命令几何C**的私有FK实现，作为阶段切换的连续初值；这不是实际前部FK，更不回填G。源管剩余线圈随β逐步释放。几何链在所有β保持64.5mm材料段，并显式闭合头部目标与保留源端。

所有阶段均使用固定σ=j×64.5mm和256个曲率单元。20维曲率积分模态经原重叠矩阵A生成20个原生关节命令。接管后直接调用Step1的NativeMapping积分得到q，再用A的精确右逆表示同一组原生积分，不另换q积分公式。源虚拟半径99.187mm、接收虚拟半径R+39mm分开保留；真实C节点标定只按管径差平移。C的规范空间实现是登记到一个实测承载杆的原生FK；Bishop重建单独作为近似诊断。接管后的空间路线站位与固定材料坐标分开记录。

控制器只使用粗圆柱、给定源构型、已知源分支、关节回读、一个承载杆的位姿及无目标标签接触点/法向/力。私有模型只保留机器人、已知源直管/入口和粗圆柱；接收真轴/半径/网格及离线轨迹不进入在线规划。实际场景标签只在 `evaluation.py` 和离线审计中使用。
