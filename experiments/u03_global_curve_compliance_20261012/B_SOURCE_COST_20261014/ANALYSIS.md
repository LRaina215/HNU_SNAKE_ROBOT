# 名义 B1 源侧侵入代价定位

2026-10-14。仅使用已保存的A16/B1_NOM_V2状态与原模型，恢复qpos/qvel/ctrl后调用mj_forward核对接触几何；没有mj_step、改参数或新动力学。105–125秒逐采样重建的源侧最大接触深度与原trace差为0。法向力和力矩采用原trace，不把重建的求解力当成当时实际分力。

已确认，两版全程源侵入峰值都发生在末杆M20（body `tail`）与 `pipe_straight_01` 的有限直管端部：B0在113.1秒为1.171毫米，B1在113.7秒为1.904毫米。B1峰值接触点约(0.94807,0.05085,0.97581)米；同时 `pipe_sharp_in_02` 与tail接触0.506毫米。因此不是目标接收区侵入被错误计入源侧，也不是只看无限管轴距得到的“碰撞”。尾杆一端X≈0.94649米仍处于端部接触范围，不能用杆中心X≈0.97315米判为源管已清空。

B1尾杆中心(0.97315,0.07575,0.94979)米，B0为(0.97853,0.06666,0.93076)米；B1中心更接近源轴约5.23毫米。J17/J19在两版此时都达到2.355Nm上限，J20在B1仅约−0.156Nm、没有饱和，跟踪误差反而较小。因此峰值不支持“J20单独跟踪失败”的解释。B1的J17–J20原始角较B0改变约+0.652/+0.813/+0.692/+0.488度；原始角到派发角的差均小于0.24度，不能仅归因命令限速。

此时局部δ=+1.430毫米（向目标管外侧），反馈观测材料只有M13、M14，滤波平均载荷约13.535N。M20实际Y≈0.0758米，既不在实际Y观测门内，其名义中心站位也在目标入口前0.1126米，落于观测窗[−0.075,0.40]米之外；它没有直接参与δ观测。但它处于曲线修正前端渐变支撑[−0.125,0]米内，名义曲线到局部曲线的中心变化约0.195毫米，且邻近关节命令已改变。M20名义中心Y≈0.1695米，而实际仍承载在源端，显示名义材料角色与实际接触仍有滞后。

时间关系也不支持简单单调解释：105–125秒δ一直向外，约107秒达到这段最大值后下降，113.7秒侵入尖峰时并不是δ最大。两版J19的受载跟踪隆起和源端承载都出现在113秒附近；B1源负载尖峰较大、同刻目标总力较低。M20在该段首次/末次>0.1N源接触分别为B0 105.8/121.0秒、B1 105.8/119.7秒，中间并非一直有接触；B1略早离开源侧，但付出了更大的短时端部接触峰值。

合理推测：局部接收调形改变邻近命令及整个受载身体的位置/姿态，受载饱和与材料接管滞后使尾杆在源端形成不同的接触姿态和负载分配。反馈未直接约束仍在源端的M20，不能保证“接收区让开”会同时减小源侧碰撞。现有证据能定位上述耦合现象，不能证明反馈的某一项、某个关节或瞬时δ是唯一原因；没有重置状态的因果干预或固定偏置对照，本轮不增加这些实验。
