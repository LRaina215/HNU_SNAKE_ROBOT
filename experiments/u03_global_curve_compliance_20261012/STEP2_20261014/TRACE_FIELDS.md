# STEP2 R2 记录字段语义

`estimated_material_role`以及绿色/橙色/紫色等角色来自已知源几何和当前目标圆柱候选，不是环境标签真值。0无确认支撑、1已知源一致、2接收圆柱候选一致、3桥/不明、4源与接收双侧、5已确认估计目标图中但无自身直接接收载荷。桥/不明载荷单独保留，材料有多类接触时可同时出现在多个支撑布尔量中。

`sensor_force_by_estimated_role_N`的三个分量依次为已知源一致、接收候选一致、桥/不明。`estimated_receiver_qualified`用于接收观察/反馈；`front_confirmed`要求可靠候选和连续前部支撑几何，是估计确认。冻结记录中沿用的旧字段名`actual_target_support_count`同样只是估计接收候选支撑计数，不能当真值目标杆数。保留冻结数据，不事后改名或改值。

`forces`和`depth`由单独评价器按原环境标签记录，只用于评价/原安全停止：forces为源、目标/出口接头；depth为源、目标、自碰、地面。控制器不读取这两组评价数组。真正的有限目标包络、材料接管、轴向输送和自身滚转由保存真实状态独立评价，不用估计角色代替。

`estimated_entry_m`和`applied_global_entry_m`是螺旋的规划接收站位/轴线点。圆柱侧壁拟合可以修正轴和横向位置，却无法识别物理入口沿轴位置；本轮站位仍沿用先验，约在真实直段开始后50毫米。登记的40毫米是先验标称不确定度，不是保证包含真实端点的界限或统计置信区间。参考站位与真实物理管端分开报告。

`S/chi`是共同参考进度/标架滚动相位，不能当实际材料进展或真实自轴转数。`material_progress_observed_m`保留有效几何图中的真实位移投影，未知段及未观察预测另存，更新估计原点不产生假位移。真实自轴滚转用保存qpos/qvel及本杆方向积分。

同编号世界G/C偏差、限制材料邻域的曲线距离、圆柱轴/横向/半径误差及实际推进分别记录。对应节点很远时，不以任意最近点或每帧重新配准将偏差写小。
