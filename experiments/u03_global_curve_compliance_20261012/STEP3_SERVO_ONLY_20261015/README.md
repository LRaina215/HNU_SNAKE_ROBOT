## 输入边界

控制器唯一的逐帧输入是 `ServoObservation(t, q, sent, load_fraction)`：20个实际角、20个已下发角、20个带符号归一化舵机负载及时间。速度由角度差分得到。控制器不接收仿真对象、机器人世界位姿、管道网格、接触点／法向、接触标签或开发工况标识。

MuJoCo只作为被控对象和独立评价器。`VirtualServoRegisters` 将关节编码器量化为0.01°、舵机力矩除以原限矩再量化为0.005，模拟设备可回读的寄存器。它是理想化虚拟负载通道，**不是实机电流标定，也不是直接测得接触力**。原模型舵机限矩为±2.355 N·m、位置增益127 N·m/rad；物理参数没有修改。实机需要确定符号、零偏、负载与电流／力矩换算及采样延迟。

仿真初态仍是给定的完整源管包绕，用于省去初态形成；控制器只收到当时的20个舵机指令。初态轴向平移不传给控制器。名义源螺旋属于已实现的步态先验，`x0`、源管物理终点和目标位置被曲线模块忽略。虚拟参考图并无世界定位，不能把其点坐标与实际世界轨迹直接相减。

## 已实现的机制与尚未成立的环节

- 源管爬行中的舵机响应变化触发诊断；没有信息时也允许一次有预算的诊断试探，不把时间到达称为发现管口。
- G生成前部开放搜索曲线，局部C的两个曲率自由度提供有界负载顺应，再经弧长／曲率映射形成20关节命令。未逐帧将实际身体复制成G，也未直接手动驱动某几个关节搭管。
- 正反方向试探具有爬升、实际指令稳定后保持、回中与恢复检查。相位、S和局部参数在一对试探内保持；方向评分必须检查映射到关节后的可比性。
- 无可靠交互时撤回前部，再执行源管推进和相位改变。D1暴露出材料滚动相位改变并不等于前部G改变搜索方位；D2另加虚拟源轴周围的前部搜索扇区，后部曲线不随扇区旋转。
- 仅从关节角做相对正运动学，拟合后部身体的圆柱形状。它可辅助拒绝普通源侧包络内的响应，但半径是**身体中心包绕半径**，并非真实管面半径，不能确认实际承载或排除接头与自碰。
- 后续接收形状目前仍使用明确登记的名义螺旋半径。方向评分只产生交互方向候选；它**没有证明准确目标轴线／半径识别**。持续舵机负载形成的接管标志也只是试探状态，实际目标包绕与全身转移须由独立评价器验收。

CMU的方向顺应工作使用关节本体力信息对未知地形做响应，支持采用舵机负载驱动的动作调整，但不直接证明本项目可以从电流唯一恢复管轴。[原论文](https://biorobotics.ri.cmu.edu/papers/paperUploads/Directional_Compliance_ACC2020.pdf)。基于电机电流的外力估计还受摩擦和接触位置假设影响。[DLR研究说明](https://elib.dlr.de/195141/)。

## 运行与记录

`REGISTERED_DEVELOPMENT.json`保存开发例、传感边界、控制限幅及独立验收；每次启动复制代码、登记、原模型和完整初态到独立的`runs/`目录。`RUN_LEDGER.jsonl`计入所有启动，开发失败不会作为正式配对删去。

```powershell
& 'D:/Anaconda/envs/mujoco/python.exe' sim_runner.py --run D2_DEFAULT_ACTIVE
& 'D:/Anaconda/envs/mujoco/python.exe' evaluate_runs.py
```

每次保存舵机原始输入、状态事件、G/C、真实逐杆轨迹、完整积分状态、控制器检查点以及10fps的1倍速连续双视角视频。视频右侧G/C位于独立虚拟图，不伪装成世界空间覆盖。

实际验收分为头部伸出、目标接触、前部包绕、全21杆进入有限目标直段、继续输送与滚动。完整连续成功要求目标区间持续至少50秒、每杆推进至少40毫米且同向净轴转至少90°，并报告失接、耗时、源／目标／接头侵入和饱和代价。控制状态进入`TRANSFER`不能替代这一验收。

正式比较仍为两个初态×自然接近／主动试探四次。第二初态是否确实需要重新定位，要用实际结果确认，不能仅因平移了初态就命名为“需要重定位”。正式冻结后不按测试结果改参数。

用户周额度实际恢复时，保存当前运行并停止；`STOP_REQUESTED.json`每秒检查一次。截止时的中断结果和未完成项必须如实列出，不自动启动下一阶段。

## 开发证据（2026-10-15）

`D1_SOURCE_HOLD` 完成8秒原物理稳定性检查：21杆均从源直管包绕开始，目标接触为0，最大源侧侵入约0.718毫米。这只验证初态及寄存器通道。

`D1_DEFAULT_ACTIVE` 完成300秒连续运行，两次撤回并改变源管推进／材料相位，始终没有接触目标直管，未完成跨管。`EVALUATION.json`、原始舵机记录和1倍速实际视频完整保存。无接触不能表述成“已找到合适出管位置”。

独立读取该运行的16次完整试探，在每次保持平台取3个样本：48个样本中21个电机增量信号不足；其余27个在单点力假设下仍有23.55%–81.68%的相对残差及材料位置歧义。点力、管轴候选均为0。事后真值仅用于核查，显示这48点前8杆均无管道接触。这支持空方向拒绝，尚无接触正例证明。详情见 `runs/D1_DEFAULT_ACTIVE/MOTOR_IDENTIFIABILITY_OFFLINE.json`。

参考映射审查发现，`release=0.7` 是极坐标曲线混合系数，不能解释为前端已到达搜索线或释放了70%的材料。D1伸出后约9个前部节点还在连接段，头部仅进入混合后继段；预想的开放搜索端点未直接成为头部约束。D2保留为独立开发版本；后续修正先检查实际被材料取样的G形状，不能靠调整图上未被取样的远端曲线宣称搜索覆盖改善。
