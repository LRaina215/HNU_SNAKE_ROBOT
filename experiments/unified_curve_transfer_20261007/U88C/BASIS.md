# U88C 动作方案与证据边界

从 CLOSE1B 的完整 INTEGRATION 保存状态直接启动，首条指令保留保存的 ctrl；没有重做静止保持。控制版本在 sources 中冻结，真实轨迹与预测轨迹分开；replay_1x.mp4 只由真实 qpos 生成。

目标：接续现有前部回勾，后续身体依次进入同一个目标螺旋。源管与目标管的旋向独立取自起点，不要求两者左右手性相同；完成判据检查目标段的包绕方向。

步态：冻结起点登记曲线及前后螺旋延伸，采用共同 shift 与两管滚动相位。过渡段逐渐变为外侧拱形，拱高周期变化，配合前后夹紧需求交替变化：前部承接时后部降低夹紧需求并送身；后部恢复承载时前部卷入。曲线窗口按空间参数分区，不固定某个关节做角度补丁。拱形能否实际暂存并交出长度由运动结果判断，不能只凭参考曲线认定。

反馈：编码器跟踪误差限制推进和曲线变形速度；接触压力修改同一执行曲线的局部法向形状；接触数量不足时取消对应侧的减载；实际身体位置观测参考滞后。短时原模型预测用于在相同任务下选择关节指令、维护承载接触。当前使用世界位姿和接触真值作为仿真反馈，未声称这些观测已具备实机实现。

执行保留原模型、摩擦、质量、驱动 2.355 Nm、实际固定杆长及关节限位；只下发 20 个关节位置目标。软件指令限速 10°/s、±88°，保存夹紧偏置逐渐进入对称防积分窗口。不会搬动物理根，也不修改模型参数。

shift、曲线跟踪和拱高都是参考量；实际新增持续目标接触、身体位移、实际末态和完整连续视频才是进展证据。最终成功需整身进入目标管、尾部承载、源管离开，并持续满足完成条件。
