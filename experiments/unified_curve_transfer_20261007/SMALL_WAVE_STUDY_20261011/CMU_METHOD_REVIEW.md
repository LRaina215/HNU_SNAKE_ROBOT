# CMU方法与本机实现差异审阅

2026-10-11。本次CMU审阅只读论文、用户视频前15秒、已有源码及C01/C02记录；没有修改步态源码、没有新增动力学或关节拟合。额外5毫米释放波及其先前离线修补已暂停，草稿不作为本报告结论。

**结论：视频对应的方法，是持续滚动关节波加头尾窗口转换。旧实现已有这两项，后部也确实向前运动，但没有完成主动搭管。问题不能概括为“没有传播波”，也不能靠附加小波掩盖前段构型与接续几何尚未成立。** 论文机制成功与本机这些候选失败是两项不同事实。

## 论文如何让后部接续

已核对本地论文第2–5、7页（印刷2867–2870、2872），式(3)、(8)–(12)、算法2、图5/6/12；[作者项目](https://sites.google.com/andrew.cmu.edu/snake-pipe-network/home)也分别列出windowed rolling helix与spiraling。用户视频约0–3秒标Manual/Rolling Helix，随后标Autonomous/T-shaped Junction Transition，均标5x。画面能支持探头、接上另一管、后段接续的动作顺序，不能读出关节参数或证明叠加了spiraling脉冲。

1. **持续滚动是推进原语。** 式(3)的两个正弦关节波使用同一累计时间相位，侧向与背向相差π/2；并非先摆成一个螺旋，然后只移动头部参考。源管上的尾窗口始终继续滚动，目标管上的头窗口也继续滚动。
2. **两窗相位差形成转接构型。** 式(8)的尾波比头波多Δw，垂直管的式(9)取Δw=−νπ/2；这是头尾波的相位关系，不能直接当成世界坐标中顺/逆时针或目标分支的正负号。
3. **前部先松，再恢复。** 式(12)对弯曲模块的头波幅值乘L(nt)：初始约0.4，分界接近nb时恢复至1，避免悬空前段自己卷紧。它降低幅值，仍控制这些关节。
4. **分界向尾部走，滚动不断。** nt把更多模块从尾波切到头波，直到全部属于头窗。这与正弦相位在关节间传播是两个量。后部先在原管滚动送出，再依次采用目标窗口；既不是固定后部完整位姿只拉头，也不是预置已勾管状态再接管。

算法2还要求先选择面向目标、同时垂直两管的模块；若与经验nb不配，则先用spiraling换位。其额外较大半径脉冲见式(5)–(7)，与上述基础关节波分开。**算法2没有显式的“实际前部已接住才允许窗口继续”条件。** 加这种反馈是本机后续适配，不应写成原文已有而旧代码漏掉。

角度定义为`atan2(Z−1,−Y)`，从尾向+X看右为−Y、上为+Z。这些值表明后部收到持续滚动命令、关节跟随且向前运动；**轴向运动、材料绕管角、关节滚转相位不能混为同一个进度**。这不是独立直管试验，已有前部换窗会影响后部，不能据此给出纯滚动的无滑动效率。C01/C02均失败，也不能据此否定论文方法。

还有一个已确认的几何差异：统一右手绕轴角后，旧C01源管+X有符号螺距为+180毫米；当前保留初态约−182.16毫米；批准路线的最终目标管+Y螺旋为+180毫米。前者来自既有点坐标，当前初态只读`prepared_initial.npz`做静态FK，没有新拟合。源角取`atan2(Z−1,Y)`，目标+Y右手角取`atan2(−(Z−1),X−1.1)`，轴极性均取尾至头方向。

**因此旧CMU波形起点与当前起点的差异包含几何旋向。** 正常刚体配准不能镜像螺旋；式(8)共用A、ws的两个窗口，也不能未经核对就代表源负手性、目标正手性的批准路线。单独改时间速度符号只改行进方向，单独改Δ只改相对相位，不自动解决这项形状兼容性。这里指出的是当前参考与最简同参数两窗模型的差异，并非证明跨越不可行。

## 最小复现方案及边界

建议先恢复并审查CMU基础动作链，不叠加新的释放波。保留当前实际初态，以下是待实现方案，本轮没有改代码或试跑。

1. **先完成坐标和形状映射。** 用真实交替轴、明确头尾顺序和统一右手角，确认基础波的螺距符号、滚动方向、选中释放模块与目标分支。当前起点不等于旧正手性波；不能调用`placed_pose`重新摆根并声称仍是该起点。启动时保留q0，若需过渡到关节波，要单列连续启动过程。论文16关节SEA/4Nm与本机20关节/2.355Nm、T管与L管的差异也要保留。
2. **直接累计驱动两个关节窗口。** 一个持久ψ驱动全体关节，头尾差Δ在本机坐标映射后确定；后部始终滚动。参数从整段真实FK确定，不逐关节拼补，不通过当前承载框架重注册来抹掉累计ψ。最简式(8)基线应保持同A、ws；若为了保留批准路线必须让两窗采用不同旋向/空间参数，明确称“CMU宏观机制的几何适配”，不能称公式原样复现。
3. **联合选择nb、源管释放位置和真实前段路径。** 经验nb=6只是起算值。前段须从全身源管状态实际松开，在内角下部向上形成目标包绕；全部21杆及剩余支撑连续变化，不能固定一根后部杆的完整位姿再仅拉伸前段。无可达路径时不进入动力学。
4. **同时滚动、松开恢复、推进分界。** 按式(12)恢复前部幅值；按修正单位的式(10)给名义nt。源码应分别记录ψ、名义nt、同一材料杆的实际轴向位移/绕行及目标接管，不能用nt单独宣告成功。论文开环版本和后续“接住才继续送”的反馈适配分别记录；后者不能加载人工勾住初态替代主动获取。
5. **只有实态全身目标螺旋才完成。** 全部关节进入头窗不是终点证据。要核对21杆共享目标轴及螺距、源管已清空、目标包绕和承载保持，以及所要求的内侧下向上过程。

这条方案保留“全局曲线＋局部顺应”的研究框架，但不宣称论文两窗波天然等于当前固定曲线逐点材料送身。先查清基础波与几何映射，才有依据接入局部顺应。当前缺的是合格的主动释放—搭管构型和兼容的基础波，不是再多一个波参数。
