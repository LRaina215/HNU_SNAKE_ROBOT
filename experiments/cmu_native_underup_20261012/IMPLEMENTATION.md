# 初态映射与实现边界

原模型：`mujoco_model/Snake_Robot_o20_Pipe_elbow90_horizontal.xml`。源管+X，轴Y=0、Z=1；目标管+Y，轴X=1.1、Z=1。关节目标按原模型原生20关节顺序直接派发。

N10与U01的映射：A不变，ws、phase、polar、f同时取负，delta_map仍为−1。初始节点关于Z=1镜像，最大误差2.54e−11米；奇数编号J1/J3等的指令取负，偶数编号保持，抽样误差约1e−15弧度。N6杆的尾到头切向从近似+Z变为−Z，位置仍在源管面向目标分支的+Y侧。空间手性与时间方向同时反转，保持沿源管+X的名义推进方向。仅几何准备，没有用镜像预设目标包绕。

共有A=1.2150592994538565，|ws|=0.183889173151851，|f|=0.02Hz，nb=6，seam=0.95米，低幅值0.4（U02为0.6），斜率5，20°/秒派发限速、88°命令限幅、0.5秒初始保持。U01/U02窗口倍率2.23，U03为2.8。

累计时间tau=t−0.5秒。nt=pi*DM*abs(f)/LM*rate_scale*tau；DM=.058米，LM=.0645米。论文式10的印刷表达与旁文／量纲不一致，采用旁文每周期名义移动pi*DM的关系，这是名义窗口编号而非实测材料位移。delta=delta_map*(−sign(A*ws)*pi/2)，因此N10为+pi/2，U01–U03为−pi/2。两窗口相位共享累计时钟，头窗相对后窗有固定delta；L=.low+(1−low)*sigmoid(5*(nt−6))，只对已释放的前nb关节降幅。

U03中L的恢复中心nt=6由约48.12秒提前至38.43秒，nt传播也同时加快。因此它是窗口与恢复相对滚动相位的联合调整，不是独立幅值恢复消融。首次下侧进入目标直段附近的实际时刻约30–35秒，是本次提前的依据；没有把名义窗口等同于实际接续。

控制仍是直接关节正弦＋双窗口＋幅值恢复。不使用全局曲线目标、六关节连接拟合、世界位姿在线对齐、移动柔顺区或实际支撑驱动的进度反馈。原位置伺服的被动误差和限力行为不等于曲线层顺应控制。监测仅用于停止、记录，不修改步态。

新增诊断：保存raw_command和实际ctrl，按固定材料身份记录中心、节点、接触法向以及世界接触合力。世界力由接触坐标系旋回并按机器人所属geom确定符号；source/target法向总量不能当作向上支撑量。完整mjSTATE_INTEGRATION最终状态另存，含积分相关状态；本轮各候选均从自身源管初态连续运行，没有状态续跑。

录像：运行中每0.1秒采实际画面、20fps，故原视频2倍速。侧视回放读取同一实际qpos记录，以0.1秒状态重复至20fps，1倍速；不插值新物理、不重跑、不重新配准根位姿。采样帧时间以画面标签为准，`side_050s.png`取整秒附近首帧，可显示49.5秒。

物理整身验收沿用N10已建立的条件：所有杆中心半径70–120毫米、0.15<Y<1.2米、源接触<0.1牛、目标接触>0.2牛，至少稳定2秒；最终连续保持不少于20秒、轴角<5°、每杆沿+Y再前进>40毫米、无触地、实际关节<90.5°、驱动力矩不超原限值。方向必须另审材料路径与实际侧视，lower-first不能独自验收。
