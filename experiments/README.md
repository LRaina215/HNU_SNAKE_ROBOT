# 实验目录与数据保存

远程仓库保存实验说明、方案和阶段总结，以及少量实际使用的实验源码与配置。详细运行数据保存在本地同名目录，不随普通提交上传。

- 主控制与验证代码在项目根目录的 snake_control/、validation/ 等源码目录。
- 本目录的 Markdown 文档保留各轮实验的目的、方法、结果和限制。历史文档中的状态以各任务书顶部的最新说明为准，不能将旧诊断当成当前阶段已完成。
- 当前全局参考曲线与局部顺应研究在 u03_global_curve_compliance_20261012/。保留其阶段入口、Step1/A16成功基础，以及当前Step2源码和构建所需的少量模板。
- 逐杆轨迹、关节命令记录、接触明细、初态和检查点数组、连续视频、逐帧截图、日志、压缩包以及每次运行复制的源码/模型快照只保留在本地。说明文档中指向这些材料的链接用于本地查阅，远程页面可能无法打开。

2026-10-16的仓库整理仅停止Git跟踪上述输出，本地文件不删除，也不改变实验控制代码或正在执行的方案。普通Git历史中仍可能包含旧实验数据；本次未改写已发布的提交历史。

需要运行依赖保存初态或检查点的入口时，须在本地准备相应输入；精简后的远程仓库不包含完整实验数据集。新增稳定源码应放入主源码目录，或在 .gitignore 中明确列为需要跟踪的实验源码，避免将整个运行目录加入Git。
