# 20关节局部螺距实验：阶段0及训练诊断

正式160次主对照：**0次**。`release_gate.json`记录半径反馈验收失败及停止原因。结论与复现命令见 `../../docs/局部螺距自适应/局部螺距自适应_阶段验证报告.md`。

| 目录 | 内容 | 用途 |
| --- | --- | --- |
| stage0 | 35组×73相位、连续几何、FK及量化扰动诊断 | 离线门槛 |
| training | 实现期间8次探索 | 保留探索；版本未完全冻结 |
| matched_pilots_v1 | 8次链路复核 | 包含通信取消未重试的失败，不混入性能对照 |
| matched_pilots_v2 | 四场景A/D、种子1，共8次 | 同版训练配对 |
| estimator_repeats_v2 | 小直管A/D、种子2和3，共4次 | 同版失效重复验证 |

后两批12次的代码、模型和EXE哈希均保存在逐次result.json，分析时核对。它们仍是训练结果，不是正式测试。前16次只作工程探索，最早批次逐次源码哈希不完整，不承诺用最终代码复现该批轨迹。

每个试跑包含：

- `trace.npz`：物理时间、qpos、已执行/请求ctrl、相位、命令标识及10 ms状态；压缩不改变数组。
- `control.json.gz`：每次控制的R/α/P、有效窗口、限幅/退化、目标曲线；物理部分含实际执行器力矩、触地与精确进度。
- `feedback_*.json.gz`：状态检查时的EXE反馈快照。
- `execution.log`：控制与通信执行记录；`result.json`：参数、失败原因及汇总。
- `trace.npz.received.json`：执行端收到的目标，便于回放和对账。

根目录的`*_mechanism.json`记录沿真实直轴的身体分区、方向保留的几何包绕量、接触模块和轴向覆盖。真值只用于离线评分。接触模块长度是代理，不代表可靠支撑。

`pilot_settings.json`是训练配置，不是正式参数冻结文件。隔离EXE工作目录忽略于Git，本机副本仍保留。旧26关节基线数据没有覆盖或混入。
