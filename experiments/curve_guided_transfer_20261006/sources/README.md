# 本轮源码范围

仓库基础提交为 `4e7ff09c`（目录整理完成后的main）。本任务提交增加曲线、共享顺应控制、离线几何与C0实验入口；模型及旧公共依赖没有修改。基础提交记录使用Git版本号，不进行文件SHA校验。

`snake_control/`下两份快照是两次C0共用的实际控制计算，`validation/curve_guided_geometry.py`是最终V1几何构造。`validation/curve_guided_experiment.py`是V2运行时编排快照，包含V1相同的控制/步进/停止逻辑及V2初态选择；没有保存加上该选择开关前的单独V1编排快照，不能宣称每次完整历史文件逐字复现。V1/V2参数、实际输入输出和时间线分别保留于各试验目录。

结果确定后，仓库中的实验入口另加交付约束：仅允许C0，已有记录时先拒绝覆盖，不自动运行尚未完成材料终点评分/停滞停止的B；几何入口也拒绝覆盖已记录构造。此变更未重跑物理，也未改写运行时编排/几何快照。共享控制器及实际C0计算没有改变。

`codes/Curve_Guided_Transfer_Mujoco.py`和`validation/curve_guided_plots.py`是交付入口与离线画图文件；画图读取既有轨迹，不步进物理。`geometry_v0/`保留被几何筛查排除的构造，未用于两次C0。

复现必须保留Python/MuJoCo版本及L模型，使用新的明确登记结果目录；V2另需本包`initial_pose_contact.npz`，不自动采集或搜索初态。当前数据目录拒绝覆盖，复现次数也应计入同一任务预算。
