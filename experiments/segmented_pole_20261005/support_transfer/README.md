# 支撑转移继续验证（2026-10-05）

**当前执行位置：** 第1步的两个搭管存档已通过预声明完整跨越与过程筛选；正在进入第2步的反馈接管判断，整条自主流程尚未完成。

沿用水平step92完整状态、现有重力/摩擦/执行器，全部命令经隔离EXE转发。没有人工改变运行中的姿态、分界或接触。过程门槛保持关节峰值90°/s、模块中心0.5m/s、误差15°、饱和比例29.7%；从恢复后1秒计入至完整验收结束，失败组计至停止。它们是预声明工程筛选，不是实机安全标准。

## 已确认的诊断

- V5摆落前J12的成形修正约−12°，历史预紧约−5°，rolling增量不到1°。数据在 `v5_j12_command_decomposition.json`。因此不能只归因于rolling速度。
- `contact_support_margin.py` 在独立数据副本上求静态平衡力矩下界，包含接触平移、扭转和滚动摩擦，使用真实椭圆摩擦锥的**外包盒放宽**。V5在34.3秒仍有原管接触时下界约0.124；34.5秒仅靠当时已有目标管接触时升到1.196，34.7秒1.244。**这些姿态即使在放宽条件下，也无法以现有力矩上限维持静态平衡。** 这不证明整条路线不可行，不排除动态过渡，更不能把下界小于1当成稳定证明。
- 该静态诊断额外使用质量、接触雅可比和摩擦信息，只用于阶段1定位问题。`support_pose_hold*`据此试验保持后段参考，也属于真值辅助诊断，不能作为未来实机自主方案。
- 单纯把目标领先角从8°压到现有力矩/增益等效的1.062°，虽降低误差和饱和，却导致解缠，240秒未完成。只限制角差无法同时维持包绕和转移。
- 真正保持后段位置参考不同于暂停滚动相位。触发较早后确实延长了原管接触，但如果前部继续累积相位，连接处误差上升到33°并失稳；限制相位领先恢复了功能跨越，仍未解决约1.23m/s摆落。
- `support_pose_hold`的阈值1.0从未触发保持，结果与V5相同；不能算“保持已成功”的证据。
- 连续参考对照最终14/21模块进入目标带却停滞；另发现分界代理量检查关节点，而完整转移检查模块中心，会因个别关节点超出窄半径带低估已转移段。此问题需与承载问题分开处理，不能以修改分界代理量替代完整验收。
- 改用模块中心、将接入领先限制为两连杆后，完整跨越保留，模块峰值降至0.920 m/s，但饱和34.70%。该组42.27秒峰值姿态的静态力矩下界仍为1.176，说明前后相邻姿态可承载并不保证中间接触切换可承载。
- 对已接入关节，将标准形状恢复从0.35平滑减到0.1，保留新关节成形与A–D顺应反馈，模块峰值进一步降到0.881 m/s。峰值39.99秒无原管接触，目标管接触模块仅0、1、4、6（从0编号），后续身体形成较长悬臂；仍未通过过程质量。
- 前后共同按成形领先量减速，完整跨越耗时约222秒，模块峰值1.193 m/s、饱和38.62%，未改善摆落；不继续靠无限降速宣称成功。
- 纯解析螺旋固定相位对照失去支撑；取消提前切换到整身控制后仍失败。转弯轴场可部分减小摆落，但将几何分界连续化后没有进一步收益。当前证据不支持把任何一个标签或相位修正当作唯一解法。

## 位置指令速度修正（实验选项）

外层仍输出包含实测形变、A–D顺应差量、rolling和渐进成形的关节目标。内层从EXE回传的角度差分估计速度，不读取MuJoCo的`qvel`来控制。`qvel`仍用于独立验收。

设插值后的原目标与实测角度之差为 `e`，已有执行器的饱和角差为 `e_sat = torque_limit / position_gain`。对修正权重 `w`：

1. 可选力矩等效参考：`e_eff = e + w * (clip(e, -e_sat, e_sat) - e)`。去除不会继续增加驱动力矩的超额角差，使后续制动修正不被大角差掩盖；不重置实际姿态，也不提高上限。
2. 相邻实测角度差分后，用一阶后向欧拉低通得到 `v_hat`；滤波为零时保留原差分对照。直接差分试验出现相邻周期交替修正，失败数据保留。
3. 位置命令：`q_measured + e_eff - T_v * w * (v_hat - v_nominal)`，再执行原90°/s命令变化率限制与机械角范围限制。`v_nominal`来自外层插值轨迹。

`w=1`对全身作用；`w=1-acquired_weight`只对尚未形成几何承接的部分作用。两者都是独立对照，几何承接标签不能证明有承载。该位置接口扩展改变了闭环动力学，不能写成2023控制律原样不变。实际下发值、差分读数、滤波状态和EXE执行结果均记录并按公式核对。

后续检查发现，成形参考从90°/s限到30°/s虽然降低关节峰值，身体峰值反而增大。`coupled_velocity_diagnosis.json`在保存轨迹上用雅可比区分头部运动和关节相对运动：该组峰值模块速度0.653m/s，其中相对头部约0.604m/s；该时刻参考关节变化对应的模块相对速度约0.802m/s。不能只用最大单关节速度代表整段运动。

`radial_coupled_braking`新增位置接口中的模块速度修正试验：将头部固定在任意单位位姿，仅由实测关节角与机器人几何计算各模块雅可比 `J`；用滤波后的编码角速度得到 `v=J*v_hat`。对相对速度最快的模块，超过0.2m/s时计算 `F=-20*max(0,1-0.2/|v|)*v`，再将 `J.T*F/position_gain`加到位置参考，保留原命令限速与执行器上限。未直接施加外力，未读取实时自由头位姿、qvel或接触力。原始修正相对于滤波角速度做非正功，但限幅、滤波、接触切换和头部自由运动存在，**不据此声称闭环稳定性证明**。该功能也不能观测全身一起滑动。此组已完整跨越，关节59.94°/s、模块0.50602m/s、误差2.732°、饱和22.37%，仍未通过身体速度门槛；末帧区域20/21与已通过完整窗口的全21模块区域验收分别保留。

`coupled_braking_timing.json`显示，头部参考下最大的附加修正落在J3/J5。后续 `radial_front_relative_braking` 保持同样制动强度和阈值，改为后方模块相对模块5坐标系的速度，扣除参考系平移和旋转。初始前5个关节在该相对雅可比中抵消，避免直接对维持前部包绕的关节追加这一制动项；前部仍有既有A–D、rolling和全身角速度反馈。该组已通过水平完整跨越与四项过程门槛；其5760条实际指令的编码器差分、滤波、雅可比力矩修正及EXE执行核对通过，前5关节的附加身体制动力矩抵消到数值精度。水平成功不代表跨场景通过：随后冻结竖直复核失败，见下节。

## 首次水平通过与竖直冻结失败

冻结文件 horizontal_freeze.json 在竖直运行前写入。同一组参数的水平完整验收窗口为76.92–113.27秒，继续rolling 6.825rad、推进228.04mm、最小包绕2.027圈，整个窗口的前后目标接触持续。115.2秒脚本停止帧为20/21区域，和已通过验收的起止21/21区域分别记录，没有改门槛。模块峰值0.483149m/s距0.5门槛仅3.4%，不是稳健性证明。

竖直48.6秒失去支撑，模块峰值3.153m/s。原管接触最后时刻41.68秒，实际前部在20–40秒仅约0.7–0.9圈，成形进度停在约11节而尾部rolling继续；43.4秒控制器因原管清空和越过交叉处进入handoff，这不能证明前部有足够承载。新增身体修正前30秒完全为零，不能把此前成形迟缓归咎于该项。编码器相对速度不包含整身刚体滑落；小角误差也不代表保持支撑。vertical_frozen_diagnosis.json保留事实与待验证解释。

vertical_frozen_elliptic_support_check.json为记录姿态的只读静态诊断。41.8秒存在最大归一化力矩0.556的椭圆锥静力解；44秒优化值1.009已超过执行器能力，不能因数值求解成功就称可承载。静力解存在不保证运行中的控制器会实现它，也不保证动态稳定。

## 冻结失败后的协调对照

共同减速 radial_coordinated_acquisition 按实际接入落后量共同降低前后滚动速率，最低为原速率10%，形变反馈继续。300秒内未完成，最高11/21模块进入目标区，约140秒前部开始解缠，最后仅2/21。没有因未掉落就记为成功，原管接触仍在也不意味着目标管承接有效。关节63.11°/s、模块0.53185m/s、误差2.603°、饱和15.77%；较低饱和比例不能掩盖耗时300秒及未完成。

四节提前成形 radial_four_link_admission 仅将水平成功组 maximum_lead 从2改为4，未加共同减速。137.6秒停止，已完成跨越及后续滚动验收，但关节90.99°/s、尾端0.85281m/s超限。33.39秒峰值时原管已无接触，目标接触模块0/3/4/7，成形13节而实际前缀9；33.4秒完整椭圆锥静态优化最大归一化力矩1.201，超过现有上限。这是该记录姿态的静力不足，不是证明跨越路线不可行。三节范围作为单变量对照继续在水平检验，未因为四节能过去就冻结给竖直。

另存 first_freeze_reference_tracking.json：水平首次通过组的已发目标跟踪误差峰值2.962°是原门槛定义；速度修正前的插值参考与当时实测之差峰值为12.468°。参考重设会减少前者，不能把它描述为所有形状误差都降至3°。竖直对应值为2.893°和11.942°。vertical_rigid_slip_diagnosis.json 显示滑落峰值模块绝对速度3.153m/s，而相对第5模块的形变速度仅0.0077m/s；头部平移3.039m/s，解释相对形变制动不能观测整身滑移。
