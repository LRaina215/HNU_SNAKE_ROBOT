# 第1步：窗口、相位与支撑交接的有界验证

2026-10-05。依据 `docs/顺应性自然搭管与自主跨管_开发规划.md`，本轮只开发第1步。仍使用已知管轴与接触真值、原20关节水平step92存档；不改物理参数、不操作实机、不做SHA检查。

## 待验证机制

原实现共同相位不断推进，成形主要按时间累计；尾部分界暂停也未阻止实际尾部走脱。本轮使前后窗口各自累计材料相位，成形按前段实际滚动增量与形状跟随更新，后段前送和边界释放共用前部实际承接反馈。接入时以实测弯曲场和当前目标保留预紧，中段继续让位。

CMU 2025原文第V节已核对：两个窗口使用独立螺旋波及相对相位，窗口沿身体传播，并对弯曲模块逐渐恢复幅度。本文的±π/2不能直接当作现有Yamada材料标架的偏置；本实现从存档当前形状对应的相位开始，比较前后推进率对连接段和转移的影响。窗口推进比例也不直接抄原文公式。

## 顺序与停止

1. 第一版实现上述窗口协调；与已有8°/20 ms轨迹比较，不重跑旧基线。
2. 根据第一次失败位置，只改变一个明确机制再试：承接反馈/相位关系/连续接管。保留每轮假设和源码，不网格扫参。
3. 水平通过完整跨越及下列过程要求后，冻结参数复核竖直。水平未通过不借竖直成功替代。
4. 本轮最多六个水平运动候选（工程错误修正另记），每次最多180秒物理时间；保留触地或全身无管道接触0.2秒停止条件。若仍无可用候选，报告本轮方法族与现有模型下未通过，不宣称所有分段顺应方法数学上不可能。

## 过程验收（运行前固定的工程筛选条件）

保留既有整身跨越＋继续rolling至少2π的完整门槛。以下从恢复后1秒统计到验收结束，初始存档误差另列；不是实机安全标准：

- 实际关节峰值速度≤90°/s；模块中心差分峰值速度≤0.5m/s；最大跟踪误差≤15°。
- 原管最终退出后，目标管接触持续，无触地；继续记录接触分布、包绕和自由端外张，不用控制分段颜色代表支撑。
- 力矩饱和比例、累计饱和关节时间完整报告；不得通过极慢运动掩盖更长的高负载。候选饱和采样比例超过水平基线29.7%时不认定过程质量通过。
- 整身接管与头部调整同样进入速度/误差评价，不截掉困难片段或更改验收窗口掩盖问题。

交付正常速度视频、轨迹、失败及结论。上述条件若无候选满足，第1步仍未完成，不进入第2步。
