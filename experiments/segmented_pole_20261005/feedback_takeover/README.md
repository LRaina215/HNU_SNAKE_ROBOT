# 第2步：搭管状态的反馈判断（2026-10-05）

第1步的两个指定搭管存档已通过工程筛选，证据见 ../support_transfer/stage1_accepted_pair.json。本目录继续原规划第2步，尚未完成自主接管或未知环境跨越。

## 输入与限制

估计器读取编码角重建的关节点/模块中心、机器人几何与名义缠绕半径。已知管轴仅在离线评分器中使用。当前显式先验是两轴相交且成直角、两管半径接近；这不是任意未知管网识别。

独立单位头部坐标系FK与存档的世界点刚体变换后最大差小于1e-9 mm，排除坐标实现错误。短前段的普通切向协方差轴估计误差约46–56度；自由圆柱拟合甚至可以在错误轴上得到小于1mm的残差，不能把残差小当可观测性证明。

后段十关节跨度的圆柱拟合误差约1度。以其为来源轴，使用相交直角约束拟合前七个模块，初始水平/竖直目标轴误差约1.6/6.9度，接头位置误差约5/4mm。窗口是固定观察跨度，不是人工选择控制分界；控制分界由估计的几何关系计算。

## 已有检查

- initial_geometry_probe.json、initial_cylinder_probe.json：不加直角约束的各窗口诊断，保留误差与退化。
- orthogonal_geometry_probe.json：各前部窗口的约束拟合，不按真值误差挑选运行窗口。
- shadow_geometry.json：三条保存轨迹共126帧。水平/竖直最初8秒各21帧均呈现双轴候选；两个单管终段中，水平0/21、竖直2/21被判为候选。失败竖直终段0/21。误报仍存在，几何候选不能直接当接管许可。
- 推理墙钟中位数约0.110秒、最大0.529秒；不能声称满足20ms。未来它属于慢速几何判断，内层控制继续独立运行。
- horizontal_encoder_initial：闭环单项替换对照正在运行。只将管轴/半径/初始分界换成编码器几何估计，仍保留仿真接触以及固定全局表达坐标。这一步不能标为去掉全部仿真特权。

前后两段的包绕、历史保持/增长和承接能力仍需组合判断。当前位置执行器的仿真力矩由角误差和饱和直接决定，不能把它算作与角误差独立的新传感器。后续按单项替换推进，不把静态拟合通过等同于动态跨越通过。
