## 初始几何判断

估计器读取编码角重建的关节点/模块中心、机器人几何与名义缠绕半径。已知管轴仅在离线评分器中使用。当前显式先验是两轴相交且成直角、两管半径接近；这不是任意未知管网识别。

单位头部坐标系FK与存档世界点经刚体变换后最大差小于1e-9 mm，排除坐标实现错误。短前段的普通切向协方差估计误差约46–56度；自由圆柱拟合甚至可以在错误轴上得到小于1mm的残差，不能将残差小当作可观测性证明。

后段十关节跨度的圆柱拟合误差约1度。使用相交直角约束拟合前七个模块，初始水平/竖直目标轴误差约1.6/6.9度。窗口是观察跨度，不是人工选择控制分界；控制分界由估计几何关系计算。CAD包络修正利用接近外壳及邻关节负载的候选信息，不读取真实接触身份。

shadow_geometry.json 为三条保存轨迹共126帧。两场景最初8秒各21帧均呈双轴候选；单管终段水平0/21、竖直2/21被误判为候选；失败竖直终段0/21。这是开发样本，不是独立分类器验收。几何候选不能直接当接管许可。初始推理中位数0.110秒、最大0.529秒，不能声称满足20ms。

## 接触输入替换

简化圆柱连杆的可能接触位置准确率约44–45%；改用机器人CAD外形与虚拟管道距离后，在已知轴离线对照中约79–81%。再加邻关节0.1Nm负载条件，召回率约94–95%；有误报/漏报，不能把代理量叫作真实接触力或承载裕量。

距离计算只用独立、不步进的模型副本。两根虚拟圆柱的位置和半径完全由输入假设覆盖；机器人姿态只由编码角重建，不读取实时自由基座或物理接触。当前世界坐标到编码器坐标的变换仍来自回传点；完全去特权版本必须使用编码器局部点。

MuJoCo 3.2.7旧独立距离查询对本长圆柱给出错误穿透深度，故几何副本使用Native GJK；原物理模型的enableflags仍为0、尺寸不变。cad_distance_query_check.json保留这项必要核查，不能用旧查询结果作接触证据。

当前位置执行器的负载等于截断后的127倍角误差，两条完整轨迹的等价误差小于3e-14Nm，见 encoder_error_load_equivalence.json。因此当前负载不是独立于角误差的新传感器，也不等于真实舵机电流已标定。

## 持续跟踪与当前问题

encoder_tracking 系列仅使用关节角、历史命令、机器人CAD、名义半径与直角先验，在任意单位头部坐标系跟踪两根管轴。真实自由基座仅在推理完成后用于评分，未用于校正。

第一版允许每帧修改管径，在约50秒后漂到负半径，属于估计器实现缺陷。原始数据及源码保留在 archives/encoder_tracking_unbounded_diagnostic.zip，负半径后的结果不用于方法不可行结论。之后按同径直管实验假设固定首次估计管径，分别检查前部注册、短时关联记忆、前尾局部注册。

固定半径后目标管方向大部分时间可保持在数度内；原管方向在后部解缠时仍可大幅漂移。整身进入目标管后，原接头沿管位置不再由单管包绕充分约束；同时竖直约32秒仍有原管接触时也出现丢失，不能把全部漂移归为正常不可观测。短时关联记忆未解决这点。[跟踪对照曲线](reviews/encoder_tracking_comparison.png)保留失败。

当前分别验证：前后段各自的几何跟踪，以及让转移判据使用目标包绕/承接，减少对旧接头绝对位置的依赖。target_frame 对照仍保留已知几何，单独检验分界规则；完整验收保持不变。仅用前后段间距释放尾部，水平虽跨越但模块峰值2.063m/s。改成前部每实际承接一节才允许尾部多释放一节，水平完整跨越并通过过程门槛（0.47794m/s），但冻结竖直53.2秒失去支撑，不能推广为双场景通过。诊断发现竖直初始仅按目标轴半径带就把前缀算成11节；两轴距离归属判别只有7节，见 target_frame_false_acquisition_diagnosis.json。补回两轴归属判别后，水平完整跨越但0.50736m/s略超限；冻结竖直在80秒确曾整身进入目标管，84.2秒开始切换绝对单轴目标，85.6秒失去支撑。因此补回归属只修正了前段误判，未解决终段切换。自然搭管触发、候选方向试探、不同初态自主流程及实机均未验收。

单位头部坐标下的已知几何命令核查通过：两场景目标角差异小于2e-13度、自动分界一致，见 head_frame_control_audit.json。这仅证明坐标实现一致，不证明几何可观测。新增 encoder-tracking 闭环使用编码角FK、历史命令推得的执行器负载和独立CAD距离；物理自由基座、真实轴和接触标签不进入控制，仍从人工搭管存档开始，首轮水平200秒未完成完整跨越，最多19/21模块进入验收区域。80/90秒目标轴误差0.281/0.313度，100秒升至22.23度，110秒51.76度，目标直线偏移164/277mm；原管约束在解缠后继续作用，是当前单独检验的原因假设。后续只在尾部控制权重全部退出后移除旧轴/接头约束，保留目标管直线与首次管径；这不是使用真实接触决定切换。
