# 三段顺应性：rolling 中渐进延长前部包绕

日期：2026-10-04。

## 运行前方案

目标来自用户确认：已搭管段边 rolling 边保持包绕，紧接其后的关节逐渐形成新的螺旋，新形成部分再带动后续身体。首个有界门槛是两个相邻新模块实际转移并建立接触；完整跨越仍是后续目标。

基线为 `three_segment_front_support_v1/rolling` 的64步/12.8秒，复用完整轨迹，不重复运行。新组使用同一水平T管step92完整状态，MuJoCo 3.2.7，20关节，重力、接触、摩擦、执行器参数、原顺应性K及前尾相位速度不变；经隔离可视化EXE转发。每步0.2秒、相位−0.075 rad，前尾始终rolling。

新增独立 `ProgressiveFrontWindingController`，保留Bishop/Yamada rolling、A–D差量顺应性及前部形状反馈。在前部后缘建立以当前点/切向衔接、同旋向/同螺距的螺旋延长线，按身体弧长采样目标；通过小幅阻尼微分逆运动学引导最后一个已有弯曲及后续形成区，同时软约束连接区出口的位移。这是新增几何引导，**不是纯原论文顺应性，也不声称Yamada积分独自完成空间位置控制**。

形成区初始为模块6、7（模块从0编号，共21个；与关节编号不同）；三个端点目标还包括已有模块5。初始直接修正关节索引4–8（J5–J9）。引导权重0.1，1.6秒渐入，阻尼20 mm/rad，连接出口软权重0.5，单次引导修正各关节≤2°；最终目标仍统一按90°/秒与机械限位裁剪。FK保证实际链长；参考连续曲线的弧长采样不等于交替轴离散机器人能精确到达。

两个新模块同时进入目标区域、并在过去0.6秒各自持续具有>0.1 N目标管法向接触，进一步确认0.6秒后，形成窗口才向后移动一个模块。原三段边界接入仍允许接触前发生；尾段释放原门槛不放宽。形成窗口和前段标签分别记录。

只运行一个固定参数组，最多64步。零引导权重应退化为基线；预运行检查FK与反馈点一致、参考起点/切向/弧长及首次修正方向，记录不可达残差。无SHA或参数扫描。

判据预声明：

- 保留上一轮前部支撑门槛：原前部净包绕最低≥初始80%，无连续0.2秒前部失接触，末0.6秒前尾接触持续，净前进≥64.5 mm，未触地。
- 保留原身体转移门槛：初始不属目标管的相邻两个新模块持续进入目标区域0.6秒，前进一节且前尾接触、未触地，末0.6秒持续满足。
- 额外分别报告模块6、7的目标管接触持续时间；本轮新增接触门槛要求末0.6秒两者各自持续>0.1 N。接触不等于稳定承载，不以标签增长计成功。
- 触地或全身连续0.2秒无管道接触提前终止。门槛失败不自动扩展长程、不做竖直或实机测试；保存失败视频并定位形成区误差/接触/连接区约束。

## 结果

首轮 `progressive_winding_v1` 已完成64步：前部支撑门槛通过，新增转移和接触门槛失败。完整统计与结论在最终整理时补齐，原运行前计划保存在该目录，不覆盖。

## 有因修订v2：执行器饱和下的目标条件化（运行前追加）

v1只读诊断发现：305次>0.05°的形成区实际目标变化中，208次在同一实测qpos/qvel下的MuJoCo驱动力矩完全不变；其中70次引导方向与原驱动力矩相反，仍因位置误差过大而保持原饱和力矩。它是局部单帧反事实，不足以解释全部动力学失败。

因此只增加一种固定修订：已核对当前模型为比例位置执行器（gear=1，无速度偏置项），将形成区基线位置误差向±(力矩上限/kp)内渐入裁剪，再叠加原几何引导。对应模型为±2.355 N·m、kp=127，误差界约1.062°。在给定姿态、未叠加引导时，裁剪超额误差不改变瞬时饱和力矩；不保证后续轨迹不变。仍使用1.6秒渐入和最终18°/步限幅，物理力矩上限不改变。

v2使用新的 `progressive_winding_conditioned_v2` 目录，同一初态、同一64步和原判据；只有这项条件化不同，不调几何增益或接触门槛。v1源码和失败结果保留。若v2也未通过，本轮停止扩展并报告形成区的接触/目标/力矩证据，不能继续盲目加力或宣称渐进跨越成功。
