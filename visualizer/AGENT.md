## 2. 产品定义

本项目是一个 Windows 蛇形机器人运动学可视化程序：

> 通过单个串口读取多个串联舵机的实时关节角，重建三维运动学骨架，并生成沿蛇形机器人螺旋 rolling 轴观察的二维投影。

程序同时提供基础记录回放、模拟数据和独立的手动舵机调试功能。

本项目只负责可视化程序本身，不复现整篇论文。

## 4. 完整功能需求

### 4.1 机器人档案

- 关节数量可配置，当前默认两个。
- 首个完整版本以 28 个关节作为界面和性能验收规模。
- 代码不设置固定的应用层最大关节数量。
- 支持保存、加载和复制多套机器人档案。
- 启动时自动加载上次使用的档案，但不自动打开串口。
- 每个关节需要配置：
  - 关节序号
  - 舵机 ID
  - yaw/pitch 转轴类型
  - 零位
  - 方向
  - 相邻转轴间距
  - 最小安全角度
  - 最大安全角度
- 支持逐关节配置。
- 提供“奇数 yaw、偶数 pitch”一键模板。
- 支持新增、删除、上移和下移关节。
- 支持单关节及整机零位标定。
- 保存标定前显示新旧参数差异并要求确认。
- 支持撤销到本次标定前的配置。
- 首版不要求用户配置完整的 4×4 安装变换矩阵。

### 4.2 串口与多舵机读取

- 电脑只连接一个串口。
- 所有舵机通过通信线串联在同一总线上。
- 不支持也不规划多串口同步。
- 机器人档案保存串口通信参数和关节 ID 列表。
- 连接时优先快速检查档案中的舵机 ID。
- 提供用户主动触发的“扫描总线”功能。
- 总线扫描结果只列出发现的舵机，不自动改变机械关节顺序。
- 新发现的 ID 必须经用户确认后才能导入档案。
- 舵机数据采集目标至少 10 Hz。
- 三维和二维显示只使用最新一帧，禁止排队显示过期数据。
- 单个舵机掉线或超时时：
  - 保持该关节最后一次有效角度
  - 将该关节和状态标红
  - 其他在线关节继续更新
  - 舵机恢复后自动恢复正常状态
  - 将掉线和恢复事件写入记录

### 4.3 通用运动学

- 支持任意数量的串联 yaw/pitch 关节。
- 每个关节独立使用档案中的转轴类型、零位、方向和相邻转轴间距。
- 计算全部关节点的三维位置和姿态。
- 实测姿态和目标姿态分别计算。
- 正确处理编码器跨越 0/4095 时的有符号角度。
- 界面角度以相对机械零位的有符号角度显示。
- 目标角和滑动条范围由各关节最小/最大安全角度决定。
- 若没有实测限制，初始默认范围为 ±90°。

### 4.4 三维主视图

- 采用论文风格的运动学骨架，不制作舵机或支架 CAD 外形。
- 显示彩色连杆和关节点。
- 每段连杆的颜色在不同帧中保持稳定。
- 三维和二维视图都支持浅色与深色主题。
- 默认使用深色论文风格。
- 以下元素分别提供显示开关：
  - 世界坐标轴
  - rolling 轴
  - 各关节局部坐标轴
  - 网格
  - 关节点
  - 关节编号
- 世界坐标轴和 rolling 轴默认显示。
- 局部关节坐标轴默认隐藏。
- 保留固定世界原点和跟随机器人中心观察模式。
- 支持视角旋转、缩放、平移和重置。
- 支持可选的目标姿态叠加，默认只显示实测姿态。
- 实测骨架使用彩色实线。
- 目标骨架使用半透明虚线。

### 4.5 rolling 轴二维投影

- 二维投影不是固定 XY、XZ 或 YZ 平面投影。
- 观察方向沿蛇形机器人的螺旋 rolling 轴。
- 投影平面始终垂直于 rolling 轴。
- 以估计轴线上最接近机器人骨架几何中心的点作为二维原点。
- rolling 轴投影为二维视图中心点。
- 二维视图只显示当前姿态，不提供多帧对比。
- rolling 轴默认自动估计。
- 自动轴以各段局部螺距角方差最小为主要判据，不能只取骨架点云的最大伸展方向。
- 对近似平面圆环，自动轴应垂直于圆环所在平面。
- 对轴向长度小于截面直径的短粗螺旋，仍应正确识别螺旋轴。
- 自动轴采用平滑实时更新。
- 自动处理轴方向连续性，避免正负方向突然翻转。
- 计算并显示轴估计置信度。
- 轴估计低置信度时：
  - 保持上一条有效轴
  - 显示“自动轴置信度不足”
  - 提示用户锁定或切换到手动轴
  - 不允许二维视角突然跳变
- 提供“锁定当前轴”按钮。
- 提供手动 rolling 轴后备模式。
- 用户可采用当前自动估计轴作为手动轴初值。
- 支持微调轴方向和中心位置。
- 高级区域允许填写轴上一点 `(x,y,z)` 和方向向量 `(dx,dy,dz)`。

### 4.6 静态管道轮廓

- 只作为 rolling 轴二维视图中的可选参考背景。
- 首版只支持圆形和椭圆形参数。
- 可设置轮廓中心位置和尺寸。
- 不支持 CSV 或任意不规则轮廓导入。
- 不进行接触、碰撞或顺应性计算。

### 4.7 界面布局

- 支持三种显示模式：
  - 三维视图
  - rolling 轴二维视图
  - 三维与二维分屏
- 默认三维视图占主要空间。
- 二维投影作为右侧可折叠面板。
- 左侧显示机器人档案、连接状态和关节列表。
- 舵机调试区域独立且默认折叠。
- 主关节列表每行显示：
  - 关节序号
  - 舵机 ID
  - yaw/pitch 类型
  - 在线状态
  - 原始编码器值
  - 实测角度
  - 目标角度
- 首版不额外读取或显示温度、电压和负载。
- 用户界面只需要中文。
- 配置和日志内部可使用稳定的英文键名。

### 4.8 舵机调试

- 调试功能保留，但不发展为自动运动控制系统。
- 用户从关节列表中选中一个关节。
- 调试区域显示所选关节的：
  - 目标角滑动条
  - 目标角数值输入框
  - 发送目标按钮
  - 扭矩上限
  - 速度
  - 加速度
- 滑动条和数值输入框双向同步。
- 默认拖动滑动条只修改目标值。
- 默认点击“发送目标”后才向舵机下发。
- 勾选“滑动时实时发送”后，舵机随滑动立即运动。
- 实时发送必须限频。
- 所有发送继续受以下条件保护：
  - 关节安全角度范围
  - 手动安全解锁
  - 扭矩上限
  - 速度和加速度限制
  - 紧急释放扭矩
- Python 接口不能自行使能扭矩。

### 4.9 模拟模式

- 提供手动模拟和自动模拟两种方式。
- 手动模拟：从关节列表选择关节，用滑动条改变模拟角度。
- 自动模拟：用周期函数连续改变全部或选定关节。
- 模拟模式不访问或搜索串口。
- 模拟模式不能使能舵机扭矩。
- 模拟模式同样支持三维和 rolling 轴二维投影。
- 使用 28 个模拟关节验证界面和渲染性能。

### 4.10 数据记录

- 连接与记录相互独立。
- 默认不自动开始记录。
- 用户点击“开始记录”后输入实验名称。
- 界面显示当前记录时长和已保存帧数。
- 停止记录、断开连接或关闭程序时安全完成文件写入。
- 每次实验生成一个独立文件夹。
- CSV 至少保存：
  - 时间戳
  - 各关节原始编码器值
  - 实测角
  - 目标角
  - 通信状态
  - 当时的 rolling 轴
  - rolling 轴置信度
  - rolling 轴锁定状态
- JSON 至少保存：
  - 机器人档案
  - 标定参数
  - 显示设置
  - 实验基本信息
- 首版不使用数据库。

### 4.11 离线回放

- 回放使用与实时模式相同的三维和二维视图。
- 支持：
  - 播放
  - 暂停
  - 停止
  - 时间轴拖动
  - 单帧前进
  - 单帧后退
  - 0.25×、0.5×、1×、2×速度
- 回放默认使用实验时记录的 rolling 轴，保证与现场显示一致。
- 提供“重新计算 rolling 轴”调试选项。
- 回放模式明显显示“离线回放”。
- 回放模式完全禁止舵机输出。

### 4.12 软件形式与渲染技术

- 使用独立的中文 Windows EXE 作为主程序。
- 主程序统一管理串口、运动学重建、三维/二维显示、记录回放和调试控制。
- Python 只保留为可选的本机控制接口。
- 采用便携式文件夹交付，双击 EXE 或启动脚本即可运行。
- 不要求用户配置 Python 环境。
- 串口、运动学、渲染、记录和控制逻辑相互分离。
- 初期继续使用优化后的现有绘图实现。
- 如果 28 关节实测无法保持目标刷新率，只替换渲染层为 OpenGL，不重写串口和业务逻辑。
- 不需要程序内截图或视频导出。

## 8. 验收方法

### 数值验证

- 给定一组已知关节角。
- 使用独立正运动学结果逐节点比较。
- 验证关节顺序、yaw/pitch 类型、方向、零位和跨圈处理。

### 直观验证

- 实物摆出若干典型姿态。
- 对比实物与三维骨架的弯曲方向、关节顺序和相对形状。
- 首版不要求使用外部定位系统进行毫米级测量。

### 性能验证

- 使用 28 个模拟关节连续运行。
- 同时验证三维、二维和分屏模式。
- 目标显示频率约 10 Hz。
- UI 不得出现数据积压或无响应。

### 安全验证

- 模拟和回放模式不得打开串口或使能扭矩。
- 滑动实时发送必须显式勾选。
- 目标角不得超出档案安全范围。
- 串口错误、控制错误和程序关闭时应尝试安全释放扭矩。
