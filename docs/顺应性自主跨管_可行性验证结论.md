# 顺应性自主跨管：可行性验证结论

日期：2026-10-05。执行依据为[已确认的四步规划](顺应性自然搭管与自主跨管_开发规划.md)。

**执行状态：持续进行中。本文是第1–3步的阶段性验收记录，不是任务终止报告。** 用户要求持续执行至四步全部完成，或有充分证据否决当前方向；单个实现失败不满足后一条件。当前冻结水平完整流程候选，验证竖直与不同初态，不在每轮失败后重新请求技术方向。

## 结论与边界

**第1步已通过；第2步的响应标定闭环已在两个指定搭管存档通过；第3步已出现水平及竖直自然搭管完整流程通过例。第4步首轮六初态全部跑完，只有两例通过全部门槛，正在修复共性的转移协调问题，四步自主流程尚未完成。** 控制不读真实管轴、接触标签或自由位姿。

这一结论支持保留“前部顺应性rolling与渐进包绕、中部让位、尾部逐渐退出”的运动机制。当前不能将“从选定搭管存档出发能过去”推广为未知环境中的自主跨越，也不能把第2步失败解释成分段顺应性原理不成立。

工程判断：被动几何拟合、CAD近接与负载阈值的旧实现未通过；改用同轮小幅探测、关节响应标定和私有动力学观测后，出现了统一双场景通过的候选。仍依赖名义动力学、直角与水平/竖直重力先验，标定期间仿真时间暂停，不能据此宣称未知环境或实机自主跨越已完成。

## 已定位的缺陷及对照

1. **接近目标轴不等于已转移。** 竖直初态仅用目标半径带会算成前11节已承接，两轴距离归属判断只有7节。前者过早允许尾部释放。补回两轴归属改善了已知几何对照，但编码角闭环还会受两根估计轴漂移影响。
2. **原管解缠后，原管约束可能变成错误信息。** 水平失败对照40秒目标轴误差约0.13°，60秒约26.3°，80秒约46.1°；真实原管接触约41.26秒消失，而旧管方向仍参与几何推断。中部接近旧接头的模块也可能被CAD近接当作支持旧轴的证据。
3. **前部自由端的形变会污染坐标配准。** 尾部控制退出后只用前八点配准，在同一记录中出现最高约55°目标轴误差；整段点集配准降到约7.2°。随后水平闭环完成一次跨越。但这项修正没有自动解决转移中段的双轴跟踪和质量门槛。
4. **小拟合残差不是方向正确或支撑可靠的证明。** 直接从推断已承接段重拟合圆柱，水平41秒径向RMS约1.25 mm，方向误差却约37.1°；竖直47秒RMS约0.97 mm，方向误差约35.5°。随着已承接前缀扩大坐标配准窗口，离线最大误差仍未改善。没有因此启用新的闭环分界。
5. **移除低可信旧轴约束尚不足够。** 另一个只读对照仅统计仍由尾段控制的候选接触，连续0.6秒不足三个时改成目标线单独拟合。水平记录的直线偏移最大值由约482降至65 mm，但目标方向仍可错约52.7°；竖直仍可错约76.9°。这是反例重放，不是新的物理成功，未接入默认实验控制。
6. **终段控制切换和管道末端必须分开分析。** 已知几何的竖直归属对照，在84.4秒切换期间最前点仍为1069 mm，未到1200 mm管端，随后接触卸载并快速滑落；保持增量控制的对照避免了这次失稳，但饱和和速度仍超限。不能只看最终落地点认定是管端造成。

上述信息支持“当前估计/承接实现不可靠”，不能证明只靠关节角与逐关节负载在理论上永远不可辨识。主动扰动与历史反作用正在追加验证，见下节；不能把被动拟合失败写成主动探测也失败。

## 第2步继续执行：主动约束辨识

从两个已有编码角闭环轨迹抽取状态，进行同初态、有/无目标管碰撞的诊断配对。仅负对照的独立模型副本关闭目标管碰撞；有管组保持原物理参数。三组互不重叠关节同时进行不同频率、幅值0.6°的小扰动，每次含保持和返回共1.2秒。特征仅由指令和实测关节角计算；真实接触、自由基座位姿只供评分。没有接入跨越控制或实机。

水平四个时刻有/无管共8个样本定阈值，竖直另四个时刻8个样本冻结复核，本组16/16区分正确。阈值为三组谐波响应幅值最小值0.486525。有管组峰值关节速度7.9–31.6°/s、头部净移动1.7–8.2 mm，目标接触采样比例96.7%–100%。小样本来自同两条轨迹，**只说明试探能感知额外机械约束，不能证明足够支撑、正确方向或可靠释放尾部**。其他障碍也可产生同类信号。早期单方向试探的未稳定区分结果保留。

多帧CAD拟合、法向反力一致性、局部螺距角约束、固定半径拟合及候选接触速度约束均未稳定消除方向误差，未替换运动控制。两组已知信息对照进一步限制尾部释放，模块峰值仍为0.620/0.571m/s，没有改善为全部门槛通过。动态观测通过限制内部修正/协方差及比较接头形状假设，已在保存轨迹上消除数值发散。首轮水平同轮EXE试探→标定→私有模型闭环完成跨越，但0.557m/s超限。保留探测前名义运动参考的单变量对照降至0.450m/s，全部过程门槛通过，该首轮后续进行竖直冻结复核（结果见下文）。标定期间仿真时间暂停，仍依赖直角、水平/竖直重力先验和准确名义动力学。数据、无效实现诊断与信息边界见[主动试探说明](../experiments/segmented_pole_20261005/active_takeover_multisine/README.md)。此处为第2步早期过程记录，当前状态以文首和下文为准。

## 竖直编码角候选的管端限制

该候选约127.87秒满足严格全身半径带，之后仍能在目标管上保持约两圈包绕。149.96秒最前点越过1200 mm物理管端；有限管长内可用的严格周期首尾只覆盖约3.94 rad，未达到2π。178.2秒最终失去支撑包含驶出管端的影响，不能据此单独断言转移后螺旋在直管中必然崩溃。

但65秒发生的2.047 m/s尾端摆动早于管端问题，已经违反原过程门槛。因此不通过仍然成立。没有加长管道后冒充原场景通过，也没有放宽周期或速度门槛。

证据：[有限管长逐条件诊断](../experiments/segmented_pole_20261005/feedback_takeover/vertical_encoder_finite_pipe_diagnosis.json)、[其他失败的管端排查](../experiments/segmented_pole_20261005/feedback_takeover/finite_pipe_failure_screen.json)。

## 当前通过结果与下一项工作

响应标定候选已在水平/竖直指定存档全部通过：模块峰值0.45042/0.43412m/s、关节59.95/52.54°/s、误差2.772/2.636°、饱和18.94/20.21%。两组完整跨越并继续rolling，控制不读取物理管轴、接触标签或全局位姿。[配对指标](../experiments/segmented_pole_20261005/feedback_takeover/response_control_accepted_pair.json)。

后续已连接自然接近，水平 `horizontal_natural_local_acquisition/transfer_supported_finish` 全流程通过：92.6s自动接入，223.56s达到完整验收；模块0.31184m/s、关节54.13°/s、误差2.584°、全程饱和20.51%。11191条EXE命令及接管边界核验通过，全程只排除最初1秒。独立验收周期继续rolling 6.6rad、沿目标管实际前进210.17mm。头部一度仍在原管交汇处，后部先深入目标管；这不是全程头部领先的理想运动，正常速度视频保留全过程。

这轮修复了整身A–D与首尾参考挠率符号不一致的问题，并将内部身体已形成分散支撑时的整身重构，与所有自由端完全离开接头的跨越验收分开。后者仍严格要求整身离开原管、持续包绕支撑及继续前进。原规则单纯延长同样能跨越，但全程饱和31.69%不通过；新规则在84.20s前物理轨迹和指令完全相同，之后避免长时间抵住接头。详见[自然流程与同前缀对照](../experiments/segmented_pole_20261005/natural_takeover/README.md)。

当前依照冻结的六初态协议验收竖直与相位/接近位置变化，尚不报告第4步通过。接管判据的有限正负样本仅为开发证据：移除目标管反例中，拟合模型仍预测两管接触，但留出误差与源管单独预测对照拒绝了它，说明不能单独用模型接触当作承接证明。

目前仍依赖名义接触动力学与直角/重力方向先验，标定需数分钟，期间暂停仿真时间。未证明实机实时可用，原实机入口不变，不把指定存档通过当作完整自主流程完成。
