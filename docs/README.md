# 项目文档索引

**接手入口：** 先读[研究路线](实验记录/蛇形机器人统一顺应运动研究路线_v1.0.md)了解长期目标和方法，再读[实验进度与接手说明](实验记录/统一顺应跨管_实验进度与接手说明.md)顶部了解当前结果、任务重点和接手 prompt。第一阶段通过共享shift让全身最终接入同一条目标螺旋，尾部不能另起反向绕形；不要求两根管上的螺旋左右手性相同。已有回勾为可用基础，用户允许另选起点。研究路线不追加实验日志；运行进度统一在后者维护，历史实验中的旧续派不代表当前任务。
