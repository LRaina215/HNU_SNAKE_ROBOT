# 弯曲轴顺应性：方法说明

这是对 2023 论文（Takemori 等，*Adaptive Helical Rolling of a Snake Robot to a Straight Pipe With Irregular Cross-Sectional Shape*，IEEE T-RO 39(1)）顺应性控制的扩展。论文第 V 节写明：“A future task is to handle the directional change of the axis of the pipe… it is considered necessary to extend the axis of the helix from a straight line to a curve.” 本方法就是把螺旋轴从直线扩展为曲线，只用关节角，在线完成。

原方法（论文复现，`snake_control/pole_compliance.py`）与可视化程序都没有修改，新方法放在单独的文件里。

| 文件 | 内容 |
|---|---|
| `snake_control/curved_axis_compliance.py` | 算法：局部轴、局部截面、螺距角调制、控制器 `CurvedAxisComplianceController` |
| `codes/Adaptive_Pole_Climbing_CurvedAxis_Mujoco.py` | MuJoCo 入口：键位、场景、EXE 转发与原入口相同，只替换控制器 |
| `validation/curved_axis_unit.py` | 离线检查：直管退化为原方法、合成弯管的形状重建 |
| `validation/curved_axis_experiment.py` | 与基线相同条件的对比实验 |

## 1. 原方法在弯管上的问题

论文把螺旋分解为三个组成部分：

| | 论文 | 本方法 |
|---|---|---|
| 轴 | 全身一根直线（最小化全身螺距角方差） | 沿身体变化的轴方向场 d(s) |
| 截面 | 全身投影到一个平面，按关节分组的直线/圆弧，逐关节 K_i 变形 | 每个关节投影到自己的局部法平面，其余相同 |
| 螺距角 | 全身一个设计值 α | 沿身体变化的 β(s)，均值为 α |

在弯管上，全身各处不可能同时垂直于一根直轴。投影截面会被拉扁，螺距角方差变大，EXE 的轴置信度跌破 0.42，顺应性按规则停止。基线中短弯头（弯曲半径 165 mm）3/5、先弯后变径 3/5 的停滞都是这个原因。

还有一个更根本的限制。原方法的目标是 κ = cos²α·k、τ = sinα cosα·k，其中 α 恒定，所以 τ/κ = tan α 处处相等。由 Lancret 定理，这样的曲线一定是绕**一根固定直线**的广义螺旋。所以，即使截面估计正确，原方法生成的目标轴也永远是直的。

## 2. 方法

### 2.1 局部轴（第 1 层）

对每个连杆 j，取以它为中心、约一圈（9 节）的连杆窗口，求切向 t 的协方差矩阵的最小特征向量。这就是在窗口内最小化螺距角方差，与论文的判据相同，只是局部化了。方向取头 → 尾的前进方向。

窗口平整度 = 最小特征值 / 中间特征值，表示窗口内切向是否张开成锥面。超过 0.3 时，窗口逐级加大到 13、17、27 节（全身）；全身仍超过 0.5 才拒绝本步。最后做 ±2 节平均。

### 2.2 局部截面（第 2 层）

关节 i 的局部轴取前后连杆轴的平均 d_i。把前后连杆投影到垂直于 d_i 的平面，得到投影半长 a、b，以及绕 d_i 的有向转角 γ。之后按论文式 (11)–(22) 的 A–D 情形生成直线和圆弧（与 EXE `CrossSectionCurve` 相同，圆弧阈值 1.8°），逐关节按 (r/K̂, K̂φ) 变形，再按式 (25)–(30) 归一化长度。这部分与 `pole_compliance.build_backbone` 完全相同，只有投影平面是逐关节的。

**退化性：** 如果所有局部轴都取同一根直轴，并且不调制螺距角，新方法与原方法的目标关节角逐位一致（最大差 3×10⁻¹⁵ rad，见 `validation/curved_axis_unit.py`）。

### 2.3 螺距角调制（第 3 层）

对任意曲线，定义 Darboux 轴方向 D = (τT + κB)/√(κ²+τ²)，并令 β = atan(τ/κ)。可以推出：

  D′ = β′·u，  u = cosβ·T − sinβ·B（截面切向）

而且对任意 β(s)，以下两式仍然精确成立：

  κ = cos²β·k，  τ = sinβ·cosβ·k

其中 k 是 D 的法平面内的截面曲率。所以，论文的局部公式不用改，只要让 β 沿身体变化，目标的轴就会转动；β 恒定则 D 不变，回到 Lancret 直轴。

调制规则如下：

  Δβ_i = 2λ·(d_{i+1} − d_i)·ū_i

- **系数 2 的来源：** D 只能沿 u 转动，而 u 一圈内绕轴转一周，平均只有一半的分量落在需要的方向上。用解析环面螺旋验证：短弯头上真实的 β 振幅为 ±21.6°，系数取 2 的预测为 ±24.3°，取 1 的预测只有 ±12.2°。
- **λ = axis_gain = 0.5：** λ=1 时，目标轴完全跟随实测轴，轴弯曲没有回到直线的趋势。闭环中会越弯越大，身体被撑开后轴不可辨识，bend90 / bend90_tight 上 6 次中 5 次停滞。λ=0.5 时只复现一半弯曲，保留回到直线的趋势，6/6 通过。
- **正则化：**
  - 调制只使用高斯平滑（σ=3 节）后的轴方向场；
  - 全身轴弯曲小于 10° 时不调制，因为直管上轴估计的噪声约 3–7°；
  - |β − α| ≤ 15°；
  - 最后去掉均值，使平均螺距角仍为设计值 α。

其余部分与原方法相同：Yamada 式 (32)(33) 积分、首次接管时的相位对齐、按关节限幅，以及只读关节角、不需要力或力矩信息。

## 3. 验证

### 3.1 合成弯管上的形状重建（`validation/curved_axis_unit.py`，λ=1）

合成场景：关节点取自绕“直管 → 90° 弯 → 直管”中心线的理想螺旋（中心线半径 84 mm，螺距 220 mm，26 关节、64.5 mm），机器人中点位于弯头中点。K=0，即只重建形状，不收紧。对比重建目标与真实形状，看两项：一是关节点误差（刚体对齐后），二是目标曲线到真实管轴的距离（理想情况下恒为 84 mm）。

| 弯曲半径 | 只用局部轴与局部截面（目标仍为直轴） | 加螺距角调制 |
|---|---|---|
| 直管 | 4.3 mm；82.5±0.5 mm | 4.3 mm；82.5±0.5 mm（相同） |
| 300 mm | 63.2 mm；85.7±32.3 mm | **9.9 mm；83.2±3.0 mm** |
| 165 mm | 81.3 mm；88.1±30.9 mm | **16.2 mm；82.5±7.9 mm** |

调制后目标沿弯曲管轴缠绕；不调制时，目标仍按直轴缠绕。

### 3.2 闭环对比

与基线完全相同的场景、种子和判据（16 个场景 × 5 次），详见 [弯曲轴对比实验说明](../../experiments/curved_axis_20261001/实验说明.md)。

| 步态 | 成功/总数 | 跌落 | 顶到力矩上限的时间 |
|---|---|---|---|
| 原方法（直轴顺应性） | 56/80 | 0 | 42.6% |
| 标准 Yamada 螺旋 | 18/80 | 62 | 71.5% |
| 局部轴+局部截面（第 1、2 层） | 58/80 | 0 | 46.5% |
| 弯曲轴（完整，第 1–3 层） | **60/80** | 0 | 45.5% |

- 短弯头（1.5D）和先弯后变径：原方法 3/5，完整方法 5/5。
- 其余能通过的场景保持 5/5。
- 高法兰（≥40 mm）、三通仍然 0/5。
- 代价是负载比原方法高约 3 个百分点。

设计中试过的几种参数取舍（λ=1、不门控、直管切回原方法）及其结果，也记录在实验说明里。

## 4. 使用

```powershell
python .\codes\Adaptive_Pole_Climbing_CurvedAxis_Mujoco.py --scene pipe_bend90_tight             # 完整方法
python .\codes\Adaptive_Pole_Climbing_CurvedAxis_Mujoco.py --scene pipe_bend90_tight --variant local  # 消融：不调制螺距角
python .\validation\curved_axis_unit.py
python .\validation\curved_axis_experiment.py   # 对比实验，约 1.5 小时
```

- 键位与原入口相同。Ctrl+E 关掉顺应性后是标准螺旋。
- Ctrl+K 会额外打印一行 `CURVED`，内容包括：估计的轴弯曲角、β 范围、窗口平整度，以及仿真中局部轴相对真实管轴的平均/最大角度误差。
- 参数在 `CurvedAxisOptions` 中修改。
- 实机版尚未接入。做法与 MuJoCo 入口相同：把实机入口使用的控制器替换掉即可。

## 5. 局限与后续

- 局部轴估计依赖身体在窗口内张成锥面。身体被法兰、三通撑开时，窗口会退化为全身估计，这时与原方法相当。
- 调制只复现了一半的实测弯曲（λ=0.5），这是为了闭环稳定性所做的折中。更好的做法可能是：用接触信息或管道先验给出轴弯曲的“回复目标”，或者在多个时间步上滤波轴方向场。
- 闭环结果只来自仿真。仿真摩擦、关节阻尼都是估计值。
