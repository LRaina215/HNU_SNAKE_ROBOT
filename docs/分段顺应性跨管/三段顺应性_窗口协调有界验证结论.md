# 三段顺应性：窗口协调有界验证结论

2026-10-05。对应[原开发规划](顺应性自然搭管与自主跨管_开发规划.md)第1步。本轮只使用水平step92搭管存档；没有修改摩擦、重力、执行器增益或力矩上限，没有操作实机。

后续状态说明：下文是六组对照的历史批次结论，不是总任务结束或方案不可行证明。用户指出不能自行停止后，已恢复原规划第1步，继续实际支撑交接验证；新记录位于`experiments/segmented_pole_20261005/support_transfer/`。

## 结论与决策

**六个水平候选中，两个完成整身跨越并继续rolling一个周期，但零个同时通过本轮预先声明的过程质量要求。第1步仍未完成。** 因此未进入竖直冻结复核、去除管轴/接触真值或自主搭管识别。

已确认的进展是：将成形与实际跟随、材料相位联系后，采用共同滚动速率的候选仍能完成跨越；关节峰值速度由上一轮110.45°/s降到82.13°/s或79.54°/s。未解决的问题是：原管第一次失去支撑时，尾端仍以约1.2 m/s摆落，再由前部拉上目标管。**这是“最终能过去”的证据，尚不是“平顺地转移支撑”的证据。**

本轮到预定六组停止继续调参，保留V5作为较好的功能候选，不替换日常控制器。不能据此证明所有分段顺应性方法都不可行，也不能宣称该方案已具备实机或未知环境可行性。

## 本轮实际改了什么

新增独立控制器 `snake_control/window_coordinated_winding.py`，保留实测Bishop弯曲场、Yamada关节积分、2023截面A–D顺应差量和渐进形状恢复。它是已有顺应性控制的扩展，不能称为未修改的2023控制律。

| 原规划中的内容 | 本轮实现与检查 |
|---|---|
| 成形与rolling联动 | 成形增量为前部滚动增量绝对值 × 2.133关节/rad × 实际跟随系数，并受实际转移前缀加2或4关节的提前接入范围限制。跟随系数比较上一轮目标变化与本轮实测变化，避免直接把静态预紧误差当成未跟随。 |
| 前后段相位协调 | 前、后窗口各累计材料相位，比较支撑驱动分速、限制相位差及共同速率。新接入关节从当前目标与实测弯曲场差量接管，没有直接复制CMU的正负π/2到Yamada式中。 |
| 尾部释放与前部承接 | 接触分布与前部包绕形成承接代理量，V1–V4共同调节后段滚动和释放计时；V5–V6为共同速率对照，仍保留原几何/接触释放条件。后者不能被写成承接反馈已成功解决。 |
| 中段连续让位 | 中段位置参考指数跟随实测角，成员权重至少0.8秒过渡；V6仅将参考跟随时间从0.06改为0.2秒。没有改变硬件或仿真执行器刚度、阻尼。 |

目标仍限制相对实测领先8°、变化90°/s，每0.2秒更新，经隔离EXE按20 ms仿真时间插值转发执行。单次试验开始后只有自动前进请求，没有人工改分界、扶持、拖动或修正姿态；阶段接管由控制器自动触发。回放中的qpos写入只用于绘制已记录状态。

核对了本地CMU 2025论文 [*Novel Gaits for Snake Robot Navigation in Complex External Pipe Networks*](../../references/2025_Novel_Gaits_for_Snake_Robot_Navigation_in_Complex_External_Pipe_Networks.pdf) 第V节及窗口图。这里借鉴窗口协调问题，不是整篇论文的复现；论文机器人、步态表达与本模型不同，本轮没有验证其相位参数在Yamada标架下的等价映射。

## 预声明验收与范围

运行前写入[PLAN.md](../../experiments/segmented_pole_20261005/window_coordination/PLAN.md)：最多六个水平候选，每次最多180秒物理时间；触地或全身无管道接触0.2秒停止。每轮根据上一轮失败位置改变一个机制，不做网格搜索。

保留原“整身在有限长度目标管上、脱离其他管、分布支撑、至少1.5圈、继续rolling至少2π并推进一节”的完整验收。额外过程筛选从恢复后1秒到验收结束，失败组则到停止：

- 实际关节峰值≤90°/s，模块中心峰值≤0.5 m/s，跟踪误差≤15°。
- 饱和关节采样比例≤29.7%，并同时报告累计饱和关节秒。
- 不排除原管退出、整身接管或自由端调整的困难片段。

这些是本轮运行前设定的工程筛选值，**不是实机安全标准，也不是用户指定的硬件极限**。初始存档最大误差35.85°保留，含初态指标另存。六组是同一存档上的有因对照，不能作为统计成功率。

|---|---|---:|---:|---:|---:|---:|---|
| V1 support_windows | 支撑反馈分速；前部继续滚动、后部等待承接 | 否 | 123.08 | 2.241 | 15.16 | 27.03% | 120秒未完成；前部包绕减弱、相对相位持续累积 |
| V2 bounded_phase | 限制前部相位领先约π/4，保留1/4后部前送 | 否 | 107.78 | 2.843 | 10.20 | 31.86% | 80.4秒全身失去管道支撑 |
| V3 formation_lead4 | 提前成形范围2→4关节 | 否 | 317.62 | 4.813 | 10.86 | 33.75% | 97.4秒触地；大峰值包含落地冲击 |

V5饱和比例仅比29.7%门槛高约0.009个百分点，不能把这点差异夸大成主要失败原因。明确未解决的是模块速度超标及回放可见的尾部摆落。V5/V6累计饱和分别572.91/593.45关节秒，上一轮候选564.59关节秒；V6没有实现全面改善。

V5完整验收窗口63.97–97.41秒，继续推进211.07 mm，最少2.027圈；V6为63.17–96.61秒、208.29 mm、2.035圈。两者窗口内前后半身目标管接触比例均为100%。这里的“半身”是固定模块范围，不是控制器颜色分段。

V5原始试验99.2秒结束时有19/21模块落在旧严格半径带，末帧旧半径判据为false；完整周期验收早在97.41秒通过。差异和完整原始轨迹均保留，不用裁剪后的回放末帧替代原始末帧。

## 原因：哪些已经确认，哪些仍是推测

**已确认：控制标签并不能保存物理支撑。** V5在34.69秒尾模块20达到1.237 m/s，原管接触已为零，但控制分段仍为前13/中至15/后5关节；目标管当时只有模块0、2、4、5、6、7接触，目标区域为11/21模块。V6在33.58秒尾端达到1.161 m/s，仍有6个关节被标为后段，原管同样已无接触。这排除了“只要不移动尾部分界就能保持原管支撑”的假设。

**已确认：这是第一次脱离原管附近的摆落，而非全程失去目标管。** V5/V6目标管接触在统计窗口内始终存在；尾部稍后又接触原管，最后一次原管接触分别为59.34/60.03秒。二者最终确实在目标管形成完整螺旋，但不能把后续成功倒推为前面的支撑交接已受控。

**已确认：较小关节误差不保证身体平顺。** V5/V6误差约12°、关节峰值小于90°/s，尾端空间速度仍超过1 m/s。V3的317.6°/s则发生在触地附近，不能当成正常rolling中的同类峰值。

**合理推测：当前中段主要让位，缺少对尾部退出路径的主动约束，是剩余瓶颈之一。** 前后段分别追随本地形状，不会自动给出全身相容、持续承载的空间过渡。V6延长参考跟随只能小幅降峰，并增加饱和，支持“单改让位时间不足”的判断；尚未通过力/能量分解证明唯一原因。

**相位结论有限。** V1–V4失败而V5恢复跨越，支持本轮优先保留共同速率；但分速同时改变了推进时间与成形过程，不能单独证明π/4相位差就是唯一致因。V5启动时后段速率有0.6秒滤波，最终保留约0.095 rad相位差，不能写成全程严格同相。

**控制器支撑判据有局限。** 当前转移前缀最低保留初始5关节，并非逐帧确认头部全部转移；包绕角与接触角覆盖也不是力闭合或承载裕量。这些真值辅助代理量已经不足以保证交接，直接换成关节电流估计不会自动解决当前动力学问题。完整跨越审核独立使用全部21模块，不依赖这个前缀，因此V5/V6功能通过不由分段标签产生。

## 对下一方向的建议

本轮停止继续在同一结构上微调速率、门槛和让位时间。**建议保留2023截面顺应性与自然搭管主线，改变过渡段的运动生成方式：前后螺旋之间加入连续、可执行的空间过渡参考，再允许其随反馈让位。** 这与此前“曲线段拼接＋顺应性”的想法一致；关键检验应是尾部第一次退出原管时的路径与承载，而不是再展示一段最终过去的视频。

这只是由本轮证据支持的下一研究方向，尚未实现或证明成功。可用CMU名义窗口/连续上管过程作为独立对照，明确其输入与本方法不同，不能声称已复现CMU。本轮没有另起接头识别、方向识别或数学框架任务。

因此，对“要不要换方向”的具体判断是：**当前六组实现不足以进入后续自主阶段；应调整跨管控制结构，尚没有证据要求放弃顺应性控制整个方向。**
