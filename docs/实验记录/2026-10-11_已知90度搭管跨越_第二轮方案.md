## 1. 目标与上一轮材料

从全身包绕原管、前部尚未搭管的合适人工初态开始，从尾沿原管看向头部实际逆时针滚动，前部从夹角内侧左下方向上搭管；随后连续送身，最终全身在目标管上形成一条连贯螺旋。初态允许选好出管位置、相位和可释放长度，搭管后的状态必须由本次动作得到。

沿用“全局参考曲线＋共享shift＋局部顺应”的[研究路线](蛇形机器人统一顺应运动研究路线_v1.0.md)。本轮管道几何为已知90°，先研究怎样走过去。后续根据接触修正估错的目标管方向，是长期目标，本轮不加入未知夹角识别。

上一轮[baseline v1.1](2026-10-11_逆时针内侧向上搭管与统一顺应跨越_参考方案.md)及[失败结果](../../experiments/unified_curve_transfer_20261007/INNER_CCW_COMPLIANCE_20261011/RESULT.md)原样保留。B01_RUN/B02/B03三次均未主动搭稳，旧次数3/3已结束，本轮是用户新授权的独立改进轮次。

已知问题：B01关节跟随良好，实际前部仍向外下方偏离；B03早期尾部散开时后部刚度未降低，半径指令反而收紧。不能把失败全部归因于半径放大或原Yamada控制器。本轮同时改进曲线到实际动作的对应关系与局部支撑配合。

## 2. 全局引导怎样改

- 保留原管螺旋→内侧向上过渡→延伸目标螺旋的整条路线，最终身体接入同一条目标螺旋，不要求两根管上的螺旋具有相同左右手性。
- 把原管滚动状态、实际离管位置和伸出方向纳入曲线到关节的计算。过渡起端随必要的出管调整连续衔接，目标螺旋仍沿真实目标管；不能只旋转参考图、让实际头部继续朝外。
- 前部沿开放的上绕弧接近，再逐渐进入目标螺旋。可释放长度同时覆盖过渡和包绕所需长度，原管保留承载身体。开放弧与目标螺旋连续连接，不提前形成悬空小螺旋。
- 全身共享shift，局部形状可以变化，但不能各段各走一条路。关节映射使用一致的位姿和滚动约定，不能靠逐关节指定补角完成动作。

**本轮明确提供身体定位：** 允许MuJoCo实际身体位姿用于定位、路线对应和实际进展判断，关节角与驱动负载用于局部顺应。停止依赖上一轮不可靠的源管支撑配准及冻结里程猜测。位姿只读，动作仍通过原有驱动执行；初始化后不改写物理根、qpos或qvel。

这是本轮相对v1.1的观测条件变化，报告与对照必须明确标注。它检验已知位姿条件下的运动控制，不能据此声称实机定位已经解决。准确接触身份和接触力保留作评估、停止判断，除非另行说明并获得授权，不加入局部调形算法。

## 3. 局部顺应怎样改

| 区域 | 本轮控制作用 |
| --- | --- |
| 原管承载段 | 以有效包绕形状为基准，暂不持续自由调整整段管径；允许滚动和送身，主要从离管端释放身体。负载异常先协调推进与过渡段，不把整段放松作为默认反应。保持包绕不是锁死关节。 |
| 伸出与跨接头的过渡段 | 先开放上下弯曲、向内侧偏移两类曲线调整，保持前后接点位置和方向连续。根据受阻和运动响应调整；必要时降低相关区域刚度，而非一开始把整个名义过渡区都设软。 |
| 目标管接收段 | 未围住管道时跟随开放上绕弧；形成包绕后，再局部调整截面贴合，继续接续后面的身体。不能用高负载单独判定抱稳，也不能高负载就径向外推。 |

分区随身体实际转移更新，不固定绑定模块，也不只因参考进度越过边界就提前解除支撑。局部反馈主要改变过渡形状、已包绕前部的贴合程度和整体推进速度；由统一执行曲线生成关节目标。暂不同时开放全部半径、螺距、轴向方向和控制点。

曲线调整须对应负载变化、跟随偏差及实际响应；不能把下垂形状直接抄成新目标。全局路线、局部执行曲线、实际身体分别记录。后续有几何证据时允许修正相关目标路线，这一原则不等于当前每帧重建整条全局曲线。

搭管前允许释放计划所需长度。前部没有继续接近或围住目标管时，减慢或暂停shift，仍可局部调形；承接后逐渐增加送身。实际进展决定是否继续，名义目标模块数和shift数值不代替身体已到达。

## 4. 运行顺序与停止条件

先完成一个实现上述改进的完整候选，做必要的关节范围、指令连续性和明显实体干涉检查后直接运行动作。I01/J03/L04及原有代码可以复用，不重跑其已验收动作，也不插入静止保持作为新前置任务。

| 项目 | 本轮上限 | 条件 |
| --- | ---: | --- |
| 完整方法候选 | 3次实际运行 | 首候选及最多两次有证据的曲线、映射或配合改进 |
| 局部调形关闭对照 | 1次实际运行 | 完整方法已实际连续完成整身跨越 |
| 合计 | 最多4次 | 不为用满次数而运行；所有新增物理试跑含调试早停均登记 |

完整方法成功即停止继续增加候选，保留同初态、同路线、相同定位输入、阶段配合、基础伺服及驱动限制，只关闭依据负载/误差修改局部曲线的部分，补一次对照。列清开关项；这只比较局部调形贡献，不把其他动作规则同时改掉。成功前不做对照，本轮不做半径误差或未知夹角试验。

停止条件：

1. 每次最多600秒仿真时间；从动作开始或最近一次有效实际进展起，连续30秒无进一步沿入管路线接近、增加有效包绕或输送身体，则结束。局部调整、参考shift增加或重复抖动本身不重置计时。实际进展的量测口径和去抖阈值在首跑前写入plan，不能看结果后降低。
2. 原管支撑明显丢失且目标侧尚未承接、不可恢复的掉管、触地、即将下发越界指令或数值发散时提前停。正常将支撑从原管交给目标管不是失败；探头阶段目标尚未接触也不是掉管。
3. 连续两次出现同一主要失败且无实际动作改善，又没有新的具体曲线或配合改法时，提前结束本轮，不以微调权重或延长时间消耗第三次。
4. 从执行方接到本任务起45分钟内交第一份实际动作结果；若被实现问题阻断，交明确卡点。实现与试跑总计最多90分钟，到时保存材料并交付，不自行延长或另开分支重算。

保留原模型重力、摩擦、质量、关节与驱动限制。仅修复直接阻断本轮动作的程序问题；不围绕仿真接触细节反复调参，不做SHA、全仓测试或自动连接实机。
