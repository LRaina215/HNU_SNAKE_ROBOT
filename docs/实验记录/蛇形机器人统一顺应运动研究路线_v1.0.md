# 蛇形机器人统一顺应运动研究路线

确认日期：2026 年 10 月 7 日。用户经逐项讨论，确认本页完整表达研究路线。本页是研究方向的现行版本；[当前任务](../完整跨管动作_当前任务.md)记录执行范围和状态。

## 要完成什么

让机器人从正常爬管开始，发现管道变化，了解下一段管道的大致情况，自动形成跨管路线，再根据实际反馈持续调整身体，完成跨越后继续爬行。最终希望同一套方法用于多种管道，而不是每换一种管道就重写一套动作。

当前先解决其中最核心的一步：**给出合理的初始路线以后，机器人怎样通过反馈调整，真正完成整身跨越。** 自动探测和自动生成初始曲线是后续明确要研究的能力，不是从总路线中删除。

研究以 [2023 年顺应运动方法](https://doi.org/10.1109/TRO.2022.3189224)为基础，延伸到管道转向及前后支撑变化的问题。

## 已确认的统一控制框架

### 连续曲线与整体推进

在当前 L 形接头上，把原管螺旋、过渡段、目标管螺旋接成一条连续参考曲线。目标螺旋沿目标管延伸，留出容纳最终整条身体的长度。

通过 shift 推进，身体模块依次经历原管螺旋、过渡段、目标管螺旋。原管上的身体逐渐减少，目标管上的身体增加，最后整条蛇进入目标螺旋段。三段不是永远绑定某几节关节的三个固定块。

**曲线拼接与顺应协调是同一框架的组成部分，不再分为互相替代的主、备方案。**

拼接曲线是“路”，整体推进量是全身共同的“行程进度”，局部调形是根据实际情况修改局部路线。三段共享一个整体推进量，同时允许分别调形；调整后仍须保持整身衔接。

参考进度增加不等于身体已经完成对应移动。shift 如何与螺旋滚动及实际接触配合、产生身体输送，是实现必须回答的问题，不能用直接移动仿真中的整条身体代替。

### 顺应调整主要作用在曲线层

主要机制是：**实际反馈 → 修改各段曲线与整体推进 → 生成关节目标 → 执行后再次读取反馈。**

前部可以调整包绕形状，过渡段改变弯曲，后部调整螺旋形状提供余量。关节层负责执行和必要的柔顺。曲线参数、反馈更新公式及参数间的协调关系，需要形成有依据的具体方法。

正常推进时就安排三段配合，不等卡住或掉管后才协调。并非每次都要改变全部三段：调整妨碍运动的部分，同时维护其他部分的支撑。前部推进需要后部配合；后部暂时送不出来时，前部也应减小推进。

### 允许反馈触发的动作切换

接受“推进—局部调整—继续推进”，必要时退回重试。整体推进暂缓时，局部调形仍可继续。

- 前部接不住：调整前部包绕、减少本次推进，并保留后部支撑。
- 后部拖住：调整后部与过渡段，为前部继续推进提供余量。
- 当前形状无法继续：改变相关曲线，或退回再调整。
- 找不到可行调整：明确报告当前方法在该条件下过不去。

切换依据实际反馈，不是按时间表让尾部持续解旋。统一方法允许不同动作重点，统一的是身体表示、整体推进和反馈调整机制。

## 三个研究阶段

| 阶段 | 已知条件与人工帮助 | 主要研究问题与成果 |
| --- | --- | --- |
| 第一阶段：给出路线以后怎样走过去 | 管道几何已知，人工给定合理初始曲线；前部已搭稳目标管，后部仍抱原管 | 共享推进与三段顺应调形怎样配合；完成实际整身跨越，并说明反馈改变了什么、解决了什么问题 |
| 第二阶段：自动生成初始路线 | 提供管道几何和当前身体姿态，不再人工逐段设计初始曲线 | 根据两管相对位置、方向、粗略管径及身体姿态生成曲线，接入同一套顺应跨管控制并在执行中修正 |
| 第三阶段：自动发现、探测并跨越 | 从正常爬管开始，不再人工提供新管准确几何；分支选择仍可由人指定 | 检测接触变化、短暂主动探测、逐步估计新管几何；完成“爬管—发现变化—探测—跨越—继续爬管” |

三个阶段逐步减少人工帮助，沿用共同控制框架。不同管型的适用范围随研究推进逐步检验，不把一个 L 形场景成功写成所有管道都已通过。

### 当前第一阶段的边界

使用现有机器人和当前水平 L 形接头，从已搭稳状态出发。重点是把抓持与移动放在同一动作中解决，让整条身体经过接头，最终进入目标管。

先在 MuJoCo 实际运行完整动作并保留连续视频，再由用户做实机验证。第一阶段还要论证反馈是否确实参与调形与推进、是否解决实际问题；反馈作用不是留到后续自动感知阶段才研究。

先争取完整动作，再针对实际卡点完善方法与必要证据。不把重复静止保持、接触模型微调或报告整理变成主任务。仿真与实机差异如实记录，明确阻断动作的程序错误应修正。

第一阶段不承担未知管道识别、主动探测和自动初始曲线生成。局部运动和参考动画可以作为基础，但不能代替整身跨越结果。

## 自动探测与几何估计怎样进入长期路线

用户接受全流程加入短暂主动探测。发现异常接触后，可以用小幅试探动作，结合关节角度、可获得的负载及动作响应，逐步形成对新管道的粗略认识；开始跨越后仍继续更新。

扭矩变化是接触或受阻的线索，不直接等于识别出非连续管道，也不直接给出新管方向、位置和管径。需要研究如何区分前部碰管、后部拖拽等情况，以及现有反馈能提供哪些信息。

顺应地贴合管道与明确估计管径是两个相关但不同的问题。蛇身螺旋半径还受身体厚度、贴合状态等影响，不能直接当作管道半径。粗略几何先服务于初始曲线，接触后的形状和反馈再帮助修正，不要求首次接触就准确知道全部几何。

优先使用现有关节角度和可获得的驱动负载等反馈；如果证据表明缺少不可替代的信息，再增加必要传感。仿真真值可辅助诊断，但不能冒充实机已经具备的感知能力。

## 值得争取的核心创新

候选核心是：**在一条持续引导整身转移的曲线上，利用实际抓持与运动反馈，同时调整局部形状和整体推进，让前后身体相互配合完成管道转向。**

需要落实到具体方法：

1. **反馈改变下一步形状。** 相同初始曲线下，前部承接不足、后部拖拽或过渡段受阻，应产生有理由的不同调整。
2. **局部调整帮助整身输送。** 改善抓持不能只让机器人更紧地停在原处；后部送身也不能以失去支撑为代价。需说明形状调整怎样帮助身体继续经过接头。
3. **自主能力接入共同框架。** 后续增加曲线自动生成和主动探测，保留已形成的身体表示和顺应控制。
4. **不同管型共用控制原则。** 可以因几何不同产生不同曲线，但不能依赖每个场景各自编写的人工动作时序，再统称为统一方法。

已有工作涉及曲线拼接、顺应控制及复杂管道运动，使用这些工具本身不足以证明创新。需要与最接近的方法比较，说明新计算或控制机制带来了什么作用。完整动作、反馈贡献和跨场景适用性分别举证。

当前确定的是研究问题与方法框架；具体控制规律、有效性和创新程度仍待论证。几何上能画出动作，不保证现有机器人一定能执行完成。强化学习不是必选项，当前不为加入学习算法而另开方向。

## 研究范围与已有基础

长期关注彼此连接的直管、变径管、连续弯、急弯、U 形管和选定的 T 形分支。“非连续”在当前课题中指方向或截面的突然变化，暂不包含两根真正断开管道间的腾空跨越。

三段曲线是当前 L 形场景的表示。U 形等场景能否用相同原则处理更多弯曲区域，需要后续验证，不能预设固定三段结构覆盖所有情况。

已有直管顺应运动和钩挂回拉等局部工作可复用。已审阅的 A 轮、B 轮尚未完成整身跨越；具体原型失败不等于本框架已被完整验证后否定。结果与误读更正见[首轮审阅](../完整跨管动作_首轮审阅.md)、[第二轮审阅](../完整跨管动作_第二轮与成形方向审阅.md)。

还需纠正一个概念：顺应性不要求必须用扭矩触发或在线改变增益。项目现有[顺应模块](../../snake_control/pole_compliance.py)根据测得的身体形状重建参考。是否形成有效反馈，应看输入怎样改变动作，而不能只看参数是否固定或函数是否名为 compliance。
