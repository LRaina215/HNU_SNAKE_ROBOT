## 0. 当前baseline的定位与改进原则

**本实验是当前baseline的建立与记录，不代表方法已经完善。** 已确认的是研究目标和“全局参考曲线＋共享推进＋局部顺应”的框架；当前全局曲线的生成方法、局部控制规律及二者配合方式仍是候选实现，现有截面顺应控制器也未被证明是最合适的选择。

“固定方案”指保留本轮明确、可追溯的出发点，不是把具体算法固定为最终答案。记录这一实现能完成什么、在哪里失败、反馈起了什么作用，作为后续改进全局曲线生成、局部顺应控制设计和前后配合方法的依据。失败可作为基线材料保存，但不能写成已经成立的跨越方法；单次成功也不等于方法完善或适用于所有场景。

后续依据实验问题改进具体方法时，要说清：旧实现在哪一步出现什么现象，为什么修改全局路线或局部控制，以及实际动作是否改善。不能默认所有失败都靠调局部参数解决。改进允许提出新的曲线和控制机制，沿用本轮登记的次数和停止条件；用于对照的每个版本保留其曲线、控制设置和原始结果。

## 1. 本轮要回答什么

在现有机器人和L型管道场景中，使用**全局参考曲线＋共享shift推进＋局部顺应调整**，能否连续完成：

**全身包绕原管 → 主动伸出并向上搭管 → 前后配合跨越 → 全身形成一条目标管螺旋。**

同时回答局部反馈具体改变了什么、帮助了哪一步。仅有动作成功，不能自动证明局部反馈有额外作用；固定曲线也能完成时，应如实区分两者。

## 2. 已确认的方向和起点

### 方向

- 观察方向固定为：**从蛇尾沿原管看向蛇头**。
- “逆时针”指机器人**绕原管的实际滚动方向**，不是沿身体读出的空间螺旋绕向，也不是任意视频镜头下的旋转方向。
- 前部从两管夹角内侧、目标管的左下方伸出，再向上包绕。图和视频须标明观察方向、头尾、内侧区域及入管箭头。
- 实际滚动方向和身体螺旋绕向分别记录；不能用改变相机视角或只翻转曲线符号代替所要求的动作。
- 最终前后身体接入目标管上的同一条连贯螺旋，不要求原管和目标管具有相同左右手性。

### 起点

管道几何已知。机器人初始全身包绕原管，人工放在接头附近适合开始动作的位置；前部尚未挂住目标管。

选择初态时同时满足：

1. 身体能够从两管夹角内侧离开原管。
2. 可以释放足够长的前部，完成跨过间距和向上包绕。
3. 后部仍有足够身体留在原管承担支撑。

不能用“蛇头在内侧”代替上述条件。本轮允许人工选择出管位置和初始相位，暂不研究自动寻找位置，也不增加远距离接近接头的过程。

## 3. 全局路线与完整动作

全局路线为：**原管螺旋 → 内侧向上弯起的连续过渡段 → 沿目标管延伸的螺旋**。

借鉴[I01内侧跨管](2026-10-09_夹角内侧反勾整身跨管.md)的入管位置和过渡形状，重新构造从全身在原管上开始的动作。I01从人工预勾起点完成过整身转移，可作为后半程的基础；不能加载其预勾姿态充当本轮主动搭管成功。

从所需包绕形状反推前部释放长度，长度应包含离开原管到目标管的过渡，以及绕住目标管需要的部分，不能只计算两管之间的直线距离。检查真实关节结构、连杆长度、关节范围及实体干涉后实施动作。

全身沿同一条路线共享shift推进：前部逐渐进入目标螺旋，后部逐渐离开原管，最终整条蛇进入同一条目标螺旋。三段随身体转移改变覆盖的模块，不永久绑定固定关节。搭管和跨越连续运行，中途不重新摆放机器人。

具体曲线和前后配合允许根据失败证据改进，改进重点是宏观步态，不以指定某个关节补多少角度作为方法。

## 4. 局部顺应怎样进入控制

**局部调整不能覆盖整条全局参考曲线，尽量只修改相关局部曲线的位姿与形状。** 明确区分：全局参考曲线规定经过哪里、最终进入怎样的目标螺旋；局部执行曲线是在反馈作用下眼下要求执行的形状；实际身体形状用于定位偏差和提供反馈。三者分别保存。

局部修正可包括位置、朝向、半径、螺距和弯曲形状，并与相邻区域平滑连接。实际下垂或回弯不能被自动登记为新的全局目标。若证据表明原路线无法执行，可以有依据地重新规划相关部分，记录原因与前后版本，同时保留最终目标和已有实际进展；不能每次身体变形就重建整条全局路线。

执行链为：**反馈 → 修改局部曲线与整体推进 → 由整条执行曲线生成一组关节目标 → 执行后再次读取反馈**。

当前baseline拟复用现有截面顺应方法的局部贴合机制，把修正限制在相关曲线区域，再统一生成关节目标。这是本轮的起始实现选择，并非已经确定的最佳控制器；可依据实验暴露的问题改进或替换具体局部控制规律。避免多个控制器分别生成互相抵消的关节动作。仅降低刚度或设置柔顺区，不能代替本轮要验证的反馈调形机制。

| 身体区域 | 局部顺应要解决的问题 |
| --- | --- |
| 原管上的后部 | 保持支撑，同时通过改变螺旋形状和释放位置，为前部提供可用长度 |
| 过渡段 | 根据受阻和跟随情况改变弯曲形状，必要时降低局部刚度，让前后运动能传递过去 |
| 正在接管的前部 | 先沿路线绕住管道，再根据实际截面形状调整贴合程度，持续卷入后续身体 |

关键要求：

- 前部还没围住目标管时，不能提前收成悬空小螺旋。
- 前部推进受阻时，先让过渡段和后部提供余量；不能一看到负载高就扩大前部包绕半径。
- 局部反馈可以改变执行曲线，但不能用下垂、回弯后的实际身体形状覆盖全局目标。
- 前部承接不足时，后部不能继续无条件解旋；推进暂缓时仍可继续局部调形。

反馈优先采用关节角度、跟随误差和已有驱动负载。负载上升本身不能证明搭稳，需结合包绕形状和后续动作响应判断。MuJoCo的准确接触力、世界姿态用于诊断和结果评估，与控制器实际使用的信息分开记录。实机反馈尚不能提供的信息，不默认当作实机已经具备。

## 5. 试跑和对照顺序

### 第一步：完整方法

开启全局引导和局部顺应，从原管初态连续完成主动搭管、整身跨越。先争取实际完整动作，再开展反馈贡献对照。

首轮最多3次完整方法实际试跑，每次可使用针对问题改进的候选。每次修改都要说明看到什么问题、改变了哪种曲线或前后配合方式；不为每个候选另开一轮次数。

### 第二步：关闭局部调形的对照

完整方法成功后，用同一初态、同一全局路线和相同驱动设置，只关闭根据反馈修改曲线和推进的部分，保留基础伺服和必要保护。其他动作规则保持可比，不故意削弱对照控制器。

对照最多1次。若两组都成功，应报告当前场景尚未证明局部反馈有额外价值，不能直接宣称反馈不可缺少。

### 第三步：有条件的适应性对照

仅当上述两组都顺利完成时，保持实际L型管道不变，预先把给定的目标螺旋半径设大10%，分别运行开启、关闭局部反馈的版本，观察反馈能否修正这项偏差。

两组采用相同误差条件，最多2次。10%误差提前固定，不根据运行结果反复挑选有利条件。

| 项目 | 实际运行上限 | 开始条件 |
| --- | ---: | --- |
| 完整方法候选 | 3次 | 准备好本轮初态、路线和控制 |
| 标称路线关闭局部调形对照 | 1次 | 完整方法已成功 |
| 半径设大10%的开启/关闭反馈对照 | 共2次 | 标称路线两组都成功 |
| 本轮合计 | 最多6次 | 不为用满次数而运行 |

完整方法没有成功时，不继续开展反馈对照。每次实际运行都计入本轮记录，不用更换实验名称重新计算次数。

## 6. 成功标准与停止条件

### 成功标准

1. 前部确实从要求的内侧下方主动向上搭住目标管，原管实际滚动方向符合已确认定义。
2. 同一次、同一控制版本的连续运行中，后续身体依次被卷入，尾部最终离开原管。
3. 全身在目标管上形成一条连贯螺旋，没有尾部另绕一套或靠落地完成转移。
4. 保存反馈修改曲线的过程及对应实际响应，说明帮助了哪一步；对照不支持额外贡献时如实报告。
5. 同时报告全局路线、局部执行曲线与实际身体之间的偏差。参考推进完毕不等于实际跨越；最终上管也不能掩盖明显的路线偏离。

主动搭管、持续卷入、整身接续分别记录完成到哪一步，不能把预摆初态、参考动画或短时触管算成全流程成功。

### 停止条件

- 单次最多600秒仿真时间。
- 完成一次局部调整后，连续30秒仍没有进一步接近目标、增加包绕或输送身体，则提前结束。
- 明显掉管、触地或驱动超限时结束。
- 同类失败反复出现且没有实际改善，结束该候选并重新判断曲线或配合方式；不靠无依据调参延长试跑。

沿用现有场景的物理和驱动设置，不通过降低重力、改变摩擦或放宽限制完成动作。只做与本次动作直接相关的必要检查，不重复静止保持或开展无关测试。

## 7. 交付内容

- 同版本从原管起步到最终状态的连续实际视频，失败也保存到停止时。
- 标明观察方向、逆时针滚动、头尾和入管方向的俯视与侧视图。
- 完整全局参考曲线，以及初始、搭管、中途、结束时的全局路线、局部执行曲线和实际身体对照。
- 独立步态入口、控制器位置、对应源码快照和原始记录，能对应到具体实验。
- 简明结果：动作是否完成；局部反馈帮助了什么；若失败，卡在主动搭管、持续卷入还是整身接续。
