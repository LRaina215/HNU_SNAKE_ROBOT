# CMU直接双窗口与统一曲线控制的方法对照

2026-10-12。用户要求：尝试作者下侧向上跨管后，无论是否成功，都比较N10与现有规划控制方法并总结经验。**本轮U01/U02失败，U03完成下侧出头、向上承接及整身转移。独立审阅支持成功；这仍是直接双窗口在原模型上的参数适配，没有实现统一曲线反馈控制，也不能据此判定两种方法优劣。**

这里的“当前规划”指[统一研究路线](蛇形机器人统一顺应运动研究路线_v1.0.md)：全局引导曲线＋共享shift＋曲线层局部顺应。另将[10月12日继续方案](2026-10-12_CMU运动机制复现_继续方案.md)中建议的相位/窗口协调单列；后者是复现过渡方案，不等于长期框架已完成实现。

## 已确认的控制差异

|比较项|N10实际实现|统一曲线规划|区别的含义|
|---|---|---|---|
|主表示|直接给每关节正弦目标角；前后窗相差π/2|一条原管螺旋—过渡—延伸目标螺旋曲线，局部形状可调|N10没有预先规定每杆的世界空间路径；规划要显式约束路线|
|推进变量|累计滚动相位ψ、按时间向尾部移动的窗口nt|一个共同shift决定身体在曲线上的取点，并协调滚动|nt单位为模块、shift为沿曲线进度，均不能直接当实际身体移动量|
|关节目标生成|波形公式＋前部幅值因子＋指令限速限幅|由局部执行曲线与材料对应关系求关节目标；可用曲率/挠率积分或离散链求解，具体实现需明确|曲线层必须额外处理离散杆长、姿态连续性、滚动与接触可执行性；不是画出曲线便等于执行成功|
|前后协调|同一时钟驱动ψ、nt和松开恢复L；窗口逐关节切换|共享shift，加上前/过渡/后段反馈调形与推进调速|N10协调简单明确；规划更可调，但容易出现各变量推进不一致|
|松开与恢复|前nb个关节进入头窗后乘L，由0.4趋向1；Kp仍127|根据承接/拖拽等反馈改变形状；移动柔顺区、降刚度另列备选|降低角度幅值不等于降低刚度，N10成功没有验证移动柔顺区或Yamada曲线顺应|
|反馈位置|高层波形与窗口开环；关节位置伺服闭环，接触用于记录和失败停止|实际反馈修改局部曲线与推进，再生成关节目标|不能说N10完全没有反馈，也不能把停止保护写成连续自适应控制|
|已知信息和起点|已知原L管，人工源管包绕与触发选位，无初始目标包绕|长期阶段一原本从前部已搭稳、后部仍抱原管开始；后续逐步加入主动搭管/规划/探测|两者起点、方向、任务范围不同，成败不能直接作控制方法优劣排名|
|已验证范围|一组人工参数的上侧绕入完整实际仿真；方向映射、速度系数为适配|目标是多管路统一反馈方法；各历史原型仅证明各自已做的动作|N10不能证明泛化；历史某个拟合器失败也不能否定整个曲线框架|

N10实际控制链是：人工选位和参数 → 双窗口关节波 → 原位置伺服 → 接触动力学。末态圆柱/螺旋拟合只用于验收，不参与生成命令。

规划控制链是：持续全局引导曲线 → 反馈修改局部执行曲线与共享推进 → 求关节目标 → 位置伺服与实际接触 → 新反馈。现有`unified_curve_transfer.py`原型还用到仿真世界位姿/接触信息，不能将其全部观测能力写成实机已有。`pole_compliance.py`包含曲率/挠率积分生成关节角的实现，统一框架本身不必绑定某一种高维逆解器。

两者并非数学上完全无关：恒定曲率/挠率的螺旋，经滚动相位和交替关节积分，同样能得到正弦型关节目标。主要差别在转接过程中如何选取参考族、连接前后姿态、组织材料推进，以及反馈改什么。不能反过来假定双窗口的相位切换天然等价于我们任意设计的一条平滑空间过渡曲线。

## 与10月12日继续方案的区别

该方案建议用同一累计周期χ组织ψ、窗口nt和L，必要时根据实际接续/支撑同步减速。这与N10已有“同一时间参数驱动”的骨架接近，但N10固定f与rate_scale，没有按承接反馈在线调整χ。N10的2.23速度倍数来自一次局部实际运动估计，不是闭环实测材料进度，也不是可迁移到所有形态的常数。

旧R01/R02曾把窗口边界冻结在前部、后部相位继续累计，并叠加六关节连接拟合；这是一种历史实现的差异，不能代表统一曲线规划的必然行为。N10证明在所列条件下，直接双窗口可以完成转移，尚不能从中分离“删除连接拟合”“选位”“相位”“速度”等因素的各自贡献。

已有一个较干净的局部对照：N09与N10的保存参数除case名外，仅`delta_map`不同（+1与−1）。两者均完整转移，但N09全身完成205.9秒、N10为153.5秒，且N09有90.09°短暂关节软限位超调与自碰，N10没有这些现象。这支持“窗间相位选择在这组初态与物理条件下明显影响承接过程”，不能推广为−1普适更优，也不能用它解释全部历史失败。

## 可借鉴的经验及证据强度

1. **先建立可执行的运动对应，再增加调形自由度。** N10显示实际送身、目标包绕与持续滚动可以由少量有关系的波形参数组织。对统一框架的可行建议是把这种可执行波形作为曲线生成与关节映射的校核对象，避免全局曲线要求与底层滚动相互抵消；不是直接把已成功关节波覆盖在另一套曲线目标上。
2. **释放与恢复需要随身体角色移动。** N10前部幅值与窗口相关，后部逐渐转入目标波形；这个协调机制已有单次完整动作证据。若改成反馈调节，应明确调整幅值、曲线几何还是刚度，分别验证，不能把三者混为一项。
3. **推进必须有实际材料证据。** nt到20、shift到终点均不构成成功。窗口速度2.23只是本机适配的候选值；可借鉴的是同步组织滚动、释放和接续，以及用固定模块过接头的事件校核，而不是照搬这个系数。
4. **先减少控制目标之间的冲突，再论证复杂反馈的收益。** 可把稳定的直接双窗保留为基线，在相同初态和物理条件下引入一项有明确作用的反馈，检查接续进展和支撑是否改善。尚未作该受控比较，不能声称反馈一定更优或没有必要。
5. **方向与触发几何是控制适用条件。** N10的镜像初态/指令在U01失败，提高最低幅值的U02仍失败；U03改变窗口与滚动的相对节奏后才成功。几何镜像和关节波形对应不保证重力下接触过程镜像。本轮成功也不证明“上侧优于下侧”或相反。

## 下侧向上试次及最终判断

|试次|相对基线的变化|实际结果|
|---|---|---|
|N10|已成功上侧基线，rate_scale2.23、low0.4|先抬高前部，再上侧向下绕入；153.5秒全身转移，继续81.4秒、平均前进352.2毫米|
|U01|N10的初态中心线与关节波关于Z=1镜像；ws、初相位、polar与f反号，重力及物理条件不变|下侧展开、向上接近成立，但约50–65秒未形成持续上绕；130.601秒触地，失败|
|U02|仅相对U01将low从0.4增至0.6|下垂减少仍未完成承接，130.601秒触地，失败|
|U03|相对U01仅将rate_scale从2.23改为2.8，low保留0.4|下侧向上承接后完整跨管；133.2秒起全21杆在目标直段，继续101.7秒、平均前进430.9毫米|

U03方向按同一材料连续核对：头杆M0在35秒位于目标直段附近Y=0.230米、Z=0.779米；36–39秒持续抬升并接近管侧；39.701秒首次记录头杆目标接触，中心Z=1.023米、径距约92毫米。40–50秒头杆沿管侧继续上绕，前6杆在53.8秒起形成持续包绕，随后后身接续。它从下方抬到管侧获取支撑，没有先在目标上方绕远再下降获取。仅“先到过下方”的自动标签不是方向验收依据。

U03原XML与仓库原模型逐字一致，原2.355Nm驱动与Kp127未改；实际关节峰值70.18°，源/目标管软接触深度峰值1.934/0.835毫米，无自碰或触地。99.2秒为最后源管接触记录；全身在目标管的持续末段为133.2–234.9秒，末态21杆Y=0.579–0.947米，落在原直段0.15–1.2米内，径距84.80–94.98毫米。首次成功、人工起点及参数范围有限，未验证重复性、扰动或实机。

**本轮最明确的经验是滚动相位、窗口传播与恢复包绕的配合会改变承接路径。** U01与U03保存参数除名称外只有rate_scale不同，这是比N10直接对照U03更明确的局部证据。倍率从2.23升到2.8，使nt=6、L=0.7的时刻从约48.1秒变为38.4秒；滚动频率不变，所以恢复发生时的滚动相位也变了。与此同时，更多关节更早进入头窗。因此能确认这项耦合改动使本轮由失败转为成功，尚不能把效果单独归因于“恢复提前”、单独归因于“窗口更快”，更不能将2.8当普适最优值。

**先接触不等于先建立可继续包绕的承接。** U01头杆首次目标接触约50.601秒，中心在轴下约48.5毫米；U02约50.401秒，在轴下约58.7毫米；两者此后未持续上绕。U03先在自由空间完成更多抬升，再在侧面略高于轴处接触并继续包绕。这里应借鉴的是接近形状、接触部位与后续运动的兼容性，不能概括成“碰得越早越好”或“只要加大力矩”。

**较小关节跟踪误差也不保证任务完成。** 在统一40–65秒采样区间，U01前6关节最大派发目标误差约8.08°，N10约43.22°；U01却未获取目标，N10完成跨管。两者动作阶段不完全相同，此对照不用于排名控制精度；它说明只优化角度误差不能替代对实际承接与送身的判断。U03成功同样不是全程精确跟踪证明。

## 对现有规划的具体建议

保留全局曲线、共享shift和局部反馈的研究框架，将已成功的U03作为可执行动作基线。下一步优先解决**曲线推进、材料滚动和释放恢复的一致映射**，再讨论增加反馈自由度。可先对照U03的实际关节波和模块通道，检查规划生成的关节命令是否支持同样的滚动与接续；实际轨迹用于校核可执行性，不在运行中反复覆盖全局目标。

反馈首先应回答具体问题：接管时刻与名义窗口是否脱节、前部接触是否能继续包绕、后部是否仍能送出。若据这些量调速，应协调滚动相位、窗口和释放，而不是只冻结一个边界、让其他动作继续。若需要改变它们的相对速度，应明确作为有意的协调策略，不能默认所有情况永远锁死一个比例。

N10/U03并未使用曲线层顺应或移动柔顺区，因而不能把成功归功于这些尚未加入的机制。要证明规划中的反馈有价值，应在同一可行起点及物理条件下，针对已知扰动或失配，只加入一项清楚的反馈并与直接双窗比较，衡量实际承接、接续和支撑。这个后续验证方向由本轮证据支持，但本轮不自动实施或改写研究路线。
