## 2026-10-14 参考含义和后续实施建议（规划，尚未执行）

2. 若需要修正名义几何或映射，另存新版本并建立新的无高层反馈基线，验证其下侧动作或既有搭稳状态的接续、过渡通道和最终连贯螺旋。A16保留为已完成动作的工程参照；新反馈只能与同一新基线比较，不能跨版本归因。若只新增观测而命令链保持，则明确证明原基线仍可复用。

## 3. 名义参考：曲线必须同时表达路线和滚动

### 3.1 分开存储三个对象

1. **全局引导`G`**：原管螺旋—下侧过渡—向上接入目标螺旋。保存管轴、有限管段范围、出管区域、接入切线、目标绕形和沿目标管延伸的路线。规划范围覆盖全身及验收后的继续移动。不能复用旧代码中固定外侧桥或强制两管同手性的假设。
2. **局部执行曲线`C(s; S, a)`**：由全局引导、名义滚动/释放规律和少数局部修正参数`a`生成。转接点位置与切线随名义滚动协调变化；两端保持连续，所有身体属于同一条执行曲线。
3. **实际身体与观测状态`X, q, qdot, contacts`**：用于估计材料进展、偏差和载荷。它们不覆盖`G`，也不在每帧重选一个“最像当前身体”的全局终点。

这里保留的是持续的全局几何意图；执行曲线本身是随滚动和释放变化的一族曲线。强迫机器人永远沿一条静止空间线逐点滑行，可能与U03的滚动机制冲突。若这一参考族仍不能形成有效共同输送，应修正名义几何和映射，不能把每帧实际身体拟合回去冒充实现。

U03实际轨迹用于选定可行的下侧通道、接近方向和观察范围；U03关节目标的FK用于校核交替关节映射。两者不是同一个对象，尤其U03存在较大瞬态跟踪误差，不能把命令FK当成真实接触路径。也不采用逐帧播放U03实际姿态来证明曲线方法有效。

### 3.2 共享shift与材料对应

原设计将`S`设想为米制路线坐标；实际通过的A16采用无量纲名义弯曲单元数S，与供料F、源相位M、公共滚动chi分别有明确映射，不能把S直接当实际位移。后续B保留该已验证约定。头部参考位置由`S`决定；其余参考节点按材料顺序、真实杆长和连续分支确定，不能让前、中、后各自积累一个shift。弯曲区的固定杆长约束是相邻节点的弦长，不是简单假定所有曲线弧长间隔等于64.5毫米。离散身体允许与光滑引导有有限偏差，不新增整条世界路线精确IK作为前置任务。

另存实际进展估计`S_hat`及可信度。用固定模块在源管/目标管局部坐标中的连续位移和过接头事件估计，保留累计历史；多圈螺旋采用有序连续配准，不逐帧跳到最近一圈。源侧退出后，估计从有效目标材料延续，不能因切换有效侧而凭空增加进展。

U03的名义协调可用累计滚动周期`chi`表达：

```text
psi(chi) = psi_start - 2*pi*sign(f)*chi
nt(chi)  = pi*DM/LM * 2.8 * chi
L(nt)    = 0.4 + 0.6 / (1 + exp(-5*(nt - 6)))
chi      = g_inverse(S)
```

`psi_start`包含原两窗相位偏置，符号按冻结U03源码确定；`DM=0.058 m`，`LM=0.0645 m`。唯一累计推进状态是`S`，`chi`只是其确定映射，不另设一个可以漂移的时钟。

**`g`是本轮必须解决的映射，不能直接令`S=LM*nt`。** 根据名义曲线的材料取点确定推进与滚动关系，再用U03固定模块交接事件校核。先验证单侧螺旋上的相位、轴向运动和材料对应，再检查跨接头时该关系能否连续延伸。若不能连续或单值表示，应明确报告失配并修改执行曲线族；不能用重新登记材料原点把矛盾消掉。

共同减速只改变动作快慢，不改变`nt`相对`psi`的比例。因此它不能保证修复U01那种相对时序不合适的问题。第一版先保留U03协调，用局部形状修正应对小偏差；只有对照明确显示需要改变相对节奏时，才另加有界的恢复位置/相位修正，并将其列为新的协调反馈，单独消融。

### 3.3 从曲线生成关节目标

优先复用`SpatialBishopBackbone`或现有曲率/挠率积分的几何工具：保存连续材料标架，沿材料区间积分弯曲分量，投影到本机交替关节轴，再经过原20°/s指令限速和±88°指令限幅、原关节伺服。曲线修改必须经过这条链改变命令，不再叠加一套独立的U03关节波去覆盖它。

初始相位只配准一次，之后连续运输；不在每帧重新用实际关节角寻找一个能消掉相位误差的共同角。FK用于检查轴符号、连续性和离散几何偏差，不要求任意光滑曲线都能精确实现。先检查实际投递的限速后命令，不能只比较限速前参考。

旧`SpatialShapeController.feedback_field`包含“当前观测形状＋修正＋初始预载”的构造，不能原样当成持久全局引导；旧`global_transfer_route.py`也有CLOSE1B外侧桥与绕形假设。复用几何工具，重新明确名义参考和更新权限，不把历史控制器所有分支一起启用。

## 4. 局部顺应：先开放三个能解释的几何自由度

以下三个标量模式是首版候选，可根据两窗或其他分区简化、合并或替换。局部修正须保持整身衔接；不要求控制器恰好有三个分段或三个自由度：

|模式|修改的曲线|具体触发与作用|
|---|---|---|
|`a_h`：过渡抬升/弯曲|从源侧出口到目标接近段，在引导法平面内调整桥形|前端比同材料参考下垂、接近方向不利且后部仍有支撑时，逐渐修正抬升和接入切线；不独立给蛇头一个上移位置命令|
|`a_T`：目标接收包绕|已到目标附近的连续前部曲线，改变局部半径/弯曲|间隙过大且不能继续包绕时适度收拢；接触负载过高、运动受阻时适度让开。不能一见失触便无限收紧|
|`a_S`：源侧出口松紧|紧邻出管处的短段，后方主要锚定区保持|目标已能持续接续而源侧拖住时适度放松出口；若后部半径偏大并出现下滑，优先维持抓持。不能将整段后身同时解旋|

可将曲线修正写成`C = C_nominal + B_h*a_h + B_T*a_T + B_S*a_S`。基函数由管轴、局部标架及当前材料角色定义，随后重新检查衔接、杆长和关节可执行性。它们随角色交接移动；`nb=6`是初次前部释放的名义长度，不是永远指定这六个关节负责所有顺应。

首轮建议只允许小范围修正：桥形法向偏移不超过10毫米、目标半径修正不超过3毫米、源出口半径修正不超过2毫米；统一限制变化速率。这些是**待标定的初始搜索边界**，不是已验证有效值。与管体/关节约束冲突时取更小范围；有限范围内无法改善就记录失败，不能自动扩大到另一条跨管路线。

### 4.1 一个可实现的更新律

采用低维、带回归项的曲线导纳/误差校正，而不是20个任意关节偏置：

```text
D * a_dot = -K * a + J_e^T * W * (y_ref - y_hat) + k_f * Q_ext
Q_ext     = (partial q_ref / partial a)^T * tau_ext_hat
```

`y`只取本阶段能观测的桥形高度/切向、接收半径等几何量；`J_e`是这些量对局部模式的几何敏感度，经过单位归一化。`D,K`为正的阻尼与回归系数，使误差消失后回到名义曲线；导纳项使曲线对估计外载产生有界让步。更新后投影到幅度、速率、连接连续性和管体可接受间隙范围。该式是拟议控制律，没有稳定性或收益保证。

触发门控必须区分抓持和让步：源侧尚承担主要支撑时，不因载荷大就放松；目标已稳定接续且源侧几何没有滑落时，才开放源出口释放模式。几何误差项负责保持向目标演化的方向，外载项不能单独决定“受力越大越退让”。无可靠外载估计时，先明确做几何闭环，不把关节伺服输出直接当外力矩。

如接回已有截面顺应计算，先仅在可靠的源/目标局部直管截面上计算修正，再投影到上述少数模式；接头自由过渡区不能硬套单圆柱截面。原截面方法到三维桥形的扩展属于新实现，需要验证，不能因为调用了原文件就宣称原论文方法已完整接回。

### 4.2 共同推进反馈

设置名义速度`v0(S)`，反馈仅通过一个比例`alpha`调节：

```text
S_dot = alpha * v0(S),  0 <= alpha <= 1
```

`alpha`依据三类证据平滑降低：参考推进超前于实际材料进展的预算；本应形成的目标连续包绕明显滞后；持续高驱动负载同时伴随材料输送停滞。预算取曲线开环基线的正常包络，不能要求所有接触阶段的`S-S_hat`或关节误差趋于零。

减速/暂停同时作用于`psi(S), nt(S), L(S)`。局部`a`仍可缓慢调整，恢复条件有滞回和持续时间，避免接触抖动导致反复开关。恢复到正常包络后逐步恢复名义速度。首次起步尚无目标接触是正常情况，不能要求“已经搭稳才允许前部继续伸出”。停止或有限整形超时必须报告，不让静止保住姿态被算作成功。

第一版不允许反馈加速超过名义速度，也不加入自动退回/多次重试；若这些确有需要，作为下一版明确的控制变量处理。

## 5. 反馈观测必须与验收真值分开

|量|用于什么|避免的误判|
|---|---|---|
|固定模块的位置、连续极角、目标半径、局部切向|是否从下侧接近、是否能继续包绕、是否真实送身|单次接触不等于承接；只看头部不足以判断整身|
|连续材料段的包绕角、接触持续性与实际运动|判断目标接收能力和源侧抓持状态|正常滚动可以间歇失触，不能要求每个模块一直接触|
|接触力方向、支撑分布、身体下滑/下垂|检查承载转移和局部顺应是否损失支撑|所有接触法向力的标量和不是竖直支撑力，也不是稳定性证明|
|实际驱动力矩、饱和持续时间、关节运动|识别过载并辅助判断受阻|高力矩可能是承载、夹紧或碰撞，单一阈值不能区分|
|`S, S_hat`与模块交接事件|区分参考推进、实际输送及估计可信度|窗口走到尾端、参考到终点不表示任务完成|

第一阶段可明确使用MuJoCo世界位姿/接触真值，研究“有这些信息时反馈能否改善动作”。同时将控制观测接口与验收接口分开，后者保留完整真值作独立评估。下一步再用估计值替代控制真值并测试噪声/延迟。

关节编码器和驱动电流本身不能唯一给出自由浮动蛇身的世界位姿、管轴位置或逐杆接触力；低层伺服力矩还混合重力、惯性和接触。现有硬件哪些量可用必须实测核对，必要时增加姿态/视觉等观测。真值反馈成功只能支持仿真控制假设，不能直接声称可上实机。

## 6. 分三步实施，每步只有一个需要回答的问题

### 步骤A：曲线表示是否保留U03的有效运动

先以已有数据进行必要的离线核对：单侧螺旋的轴/相位、材料顺序、原命令限速、少数关键阶段的曲线与关节映射。交付名义全局路线、局部参考族、`S→psi/nt/L`映射和与U03的偏差说明。离线图或FK通过不等于动力学成功。

随后才运行**曲线＋共享shift、局部修正a=0、推进反馈关闭**的完整动作。它须完成同样的下侧获取、整身转移和继续滚动。无需逐点重合U03；若基础行为失败，先修正映射/参考，不用顺应掩盖名义控制尚未成立。

### 步骤B：反馈是否针对具体失配产生作用

在名义基线能成功之后，先选择两个预先定义的诊断工况，分别考察接收偏差与后部拖拽/送身失配。做下面的必要消融，所有版本用同一全局路线、初态、原物理参数和执行限制：

|版本|控制内容|回答的问题|
|---|---|---|
|A0|冻结U03直接双窗|参照既有可行动作；它与曲线版有表示差异，不单独用于归因反馈|
|B0|曲线＋共享shift，无高层反馈|表示转换后的真正对照基线|
|B1|B0＋共同推进反馈|仅协调减速能解决多少失配|
|B2|B0＋局部曲线顺应，名义推进不变|局部调形本身有无贡献|
|B3|B0＋推进反馈＋局部曲线顺应|两类反馈是否互补，是否反而冲突|

若B3优于B0但与B1无差别，当前证据只支持调速，不能把收益归给局部顺应。若B3改善了某段承接但最终仍失败，只报告该局部作用。新表示的改动若尚未冻结，不能用不同版本B0/B3作消融。

### 步骤C：在未用于调参的工况中检验改善

诊断阶段有正面证据后，再固定路线生成规则、增益、阈值、停止条件和评分，做一小组配对留出测试，首轮建议8个独立工况，优先比较B0与B3，并按需要加入A0。名义情况成功一次以后不为增加“成功次数”重复完全相同的确定性仿真。

扰动保持原模型和管道不变，可用小的起步轴向偏差、起步周向/相位偏差，以及短暂已知外力。候选量级为轴向5–10毫米、周向3–5度、总量约0.1倍机器人重力且持续1秒的外力；这些是需在开发工况校准的量级，不是现成有效基准。外力明确施加杆号、方向、时间和总力，不能对每杆重复施加一份“总力”。

测试清单在看测试结果前锁定，正负偏差都保留；不挑只有开环失败的点，不为每个测试工况单独改参数。起点必须物理有效且仍属于同一个下侧获取任务；初始放置失效与控制失败分别记录。各控制器接受相同实际起点、扰动和观测条件。初态偏差不默认为规划器获知新的理想路线。

若反馈主要表现为减速，再加一个开发集上调好的固定慢速开环对照，检查“知道实际情况才减速”是否比“一直慢一些”更有价值。若收益主要来自一套固定变形时序，可把开发工况学到的时序冻结后用于其他工况，检查在线适应的必要性；不在同一个确定性工况回放它自身的闭环命令来宣称反馈无用。

不直接做全参数大网格。先完成表示转换和两个诊断工况；没有改善依据就定位问题，不扩展留出测试。

## 7. 如何判定“确实改善了跨管”

### 7.1 主指标是完成任务，不能用更容易的替代指标

统一保留U03的原机器人、有限目标管和物理验收口径，并额外保存实际整体绕形核查。必须看到：

- 固定前部材料从下侧向上获取目标，随后材料有序接续；方向由连续轨迹和视频判定。
- 原管真正清空，全21杆处于目标有限直段，接成一条连续目标螺旋，不能存在尾部反向回折。
- 全身转移后继续滚动并沿目标轴输送。首轮建议统一235秒预算，要求至少50秒的完成后观察；因此过晚才勉强进入目标也不会自动判成功。具体几何容差与继续移动量先用已有U03轨迹核对并冻结，不能看新控制器结果再放宽。
- 关节、驱动、软接触深度、触地、自碰撞等用同一规则记录和判断。参考曲线预测侵入与实际碰撞深度分开。

若共同减速确实需要更长预算，下一组可以对所有版本统一修改，但必须另报为新测试设置，不仅延长反馈组。

### 7.2 次指标解释为什么改善或退化

报告成功数/总工况数、每对工况的成败变化、完整转移时间、完成后的逐杆轴向位移；再报告获取到持续包绕的时间、源侧丢失早于目标有效承接的区间、无材料进展持续时间、持续饱和占比和下垂/滑落。平均指标须包含失败的数量和原因，不能只比较各自成功子集。

相位、窗口、实际材料事件、局部参数、几何/载荷误差放在同一时轴上。每个改善例须能回答：

```text
检测到什么偏差 → 改了哪段曲线/共同速度 → 实际接近或承接怎样变化
→ 哪些固定模块随后通过接头 → 最终有没有完成
```

这一事件链只能解释作用，因果归因仍依靠B0/B1/B2/B3对照。瞬时力峰变小、轨迹更好看、关节误差降低都不是独立的任务改善证据。

首轮最有说服力的结果是：名义成功保留；同一组未调参扰动下B3的失败减少；局部顺应消融出现相应退化；没有以增加碰撞/过载或无上限延时换取成功。若仅速度、载荷或成功率之一改善，明确报告其余代价。8个工况只能支持这组条件的结论，不能据此声称普遍鲁棒或统计显著。

### 7.3 与长期第一阶段衔接

U03全原管起步包含主动获取，比长期第一阶段的“前部已经搭稳”范围更宽。本轮以全程任务作主要验收；若要隔离接管之后的顺应作用，可在新实验首次通过承接事件时保存**完整仿真与控制器检查点**，让B0/B1/B2/B3从相同状态接续。检查点包含积分状态、ctrl、限速历史、S、相位/材料标架、局部参数及估计器历史。

仅有历史qpos/qvel不等于完整接续状态。接续成功与全程成功分别报告；不能把U03前半段和另一控制器后半段的视频拼成同一版本端到端成功。

## 8. 代码落点与下一阶段交付

保留U03实验冻结文件原状。建议新增小型独立入口实现本轮，调用现有几何工具，避免直接在历史大控制器中启用几十个旧分支：
