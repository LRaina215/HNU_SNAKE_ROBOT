# 局部负载主动探测与急弯跨越：执行方案

日期：2026-10-03。交给另一模型执行。本轮仅核对文献、代码和模型参数，未实现新控制器、未运行运动实验。以下次数、阈值和参数范围均为建议，训练后冻结，不能当成已验证结论。

## 1. 研究判断与任务边界

研究目标：在管外螺旋运动接近轴线突变的L/T接头时，利用关节角、逐关节负载及小幅主动试探，判断可转入的局部方向，再用局部转弯和顺应反馈完成目标管接触、包绕和整身转移。

这是有依据但尚未验证的假设。三个问题要分别回答：

1. 已知目标管方向和接头位置时，20关节身体能否完成这类转移？
2. 只给关节反馈时，能否区分可进入方向、自由空间和阻挡？
3. 将识别接入控制后，能否保持支撑并完成整身通过？

接触力方向、管轴方向和任务希望前往的方向是三种不同量。接触法线不能直接当作管轴；对称T型两路都可行时，负载不能决定任务应选左还是右。实验给定高层任务“转入支管”，或允许任一可行出口并记录实际出口，不能把任意选择称为识别出唯一正确方向。

当前只研究轴线突变、实体仍连接的管外L/T接头；不同时扩展到任意障碍、断开的空隙或任意空间分支。

## 2. 已确认的反馈与模型条件

### MuJoCo反馈

| 量 | 含义 | 本实验用途 |
| --- | --- | --- |
| `qpos`、`qvel`中按关节地址提取的部分 | 关节角、速度 | 控制输入；不传浮动基座真值位姿 |
| `ctrl`、实际应用的目标编号 | 真正执行的目标角 | 控制输入，与实测角同一时刻记录 |
| `qfrc_actuator[jnt_dofadr]` | 驱动器作用于该关节的力矩 | 模拟逐关节力矩反馈 |
| `actuator_force` | 执行器空间的输出力 | 当前单铰链、gear=1时与对应驱动力矩一致；换传动后重核对 |
| `qfrc_constraint` | 全部约束产生的广义力 | 仅诊断，含接触、限位等，不能直接当舵机读数 |
| `data.contact`、`mj_contactForce` | 真实接触位置、法向、接触坐标系内六维力/力矩 | 仅评分、诊断及明确标记的真值辅助组 |

依据：[MuJoCo 3.3.0数据结构](https://mujoco.readthedocs.io/en/3.3.0/APIreference/APItypes.html)、[执行器力传感](https://mujoco.readthedocs.io/en/3.3.0/XMLreference.html#sensor-actuatorfrc)、[接触力接口](https://mujoco.readthedocs.io/en/3.3.0/APIreference/APIfunctions.html#mj-contactforce)。提取接触力用于评分时，要核对接触坐标系变换和作用于哪一个物体的符号。

本次在MuJoCo 3.3.0静态加载 `Snake_Robot_o20_Pipe_elbow90_horizontal.xml`：20执行器、1 ms步长、gear=1、kp=127、输出范围±2.355 N·m，无显式sensor。读取上述动力学数组不要求先添加XML传感器。关节阻尼为模型被动力，不在该比例执行器的输出公式内。

当前执行器实质为：

\[
\tau_i=\operatorname{clip}(127(q_i^{cmd}-q_i),-2.355,2.355).
\]

角度单位rad，误差约1.062°即开始饱和。因此在这个模型中，力矩是角度误差的确定性变换，不能宣称它提供了独立的新观测。必须保留“角度/目标/速度/相位”和“再加力矩”的对照；加力矩后效果变化可能来自特征表达，而非信息增加。不要仅为得到优势而换执行器。

## 3. 为什么需要主动试探

外部接触引起的广义力可写成 \(\tau_{ext}=\sum_c J_c(q)^T f_c\)。多个接触点和接触力都未知时，通常不存在从一组关节力矩到唯一障碍方向的逆映射。驱动力矩还承担重力、运动和摩擦负担，更不能直接代替 \(\tau_{ext}\)。

先尝试辨别几个局部转弯候选方向，而不是重建完整三维管网。保持同一滚动相位，分别进行小幅正反向弯曲，比较实测角变化、跟踪误差和负载变化。跨几个姿态观察到可重复的接触约束，才考虑推断可进入的方向。

低负载可能表示朝向空中；高负载可能表示有用的承重接触。不得采用“选负载最低方向”作为唯一策略。输出至少包含：候选方向、置信度、无法判断。不能仅因为负载高就把该处标成障碍碰撞。

相关先例：[Directional Compliance in Obstacle-Aided Navigation for Snake Robots, ACC 2020](https://arxiv.org/abs/2003.01774)使用关节力反馈处理未知环境，验证对象是桩阵与岩石，不能当作管外急弯成功的证据。2016年CMU管内论文的局部弯曲由操作者初始化，本方案增加的自主方向判断不是该论文已经解决的部分。

## 5. 阶段0：反馈和稳定支撑检查

1. 按joint ID核对角度、力矩、轴方向、关节间距映射；确认自由基座的6个自由度没有混入20关节数组。记录同一物理时刻的数据，区分控制计算时刻和实际应用时刻。
2. 在直管完成共同抱管初始化，固定相位保持10 s，再做小幅正反试探。保存是否滑移、触地、饱和和能否回到试探前附近姿态。
3. 检查 \(\tau_i\) 与上述比例控制公式的一致性，饱和单列，不用截断力矩反推无限大的接触力。
4. 每种入管朝向先3个初始滚动相位（0、2π/3、4π/3）。所有比较方法从同一合格状态开始。建议准入：无触地或额外支撑，10 s沿原管净滑移≤20 mm；保持失败则先修正共同初始化或记录该工况不能用于当前实验。

只调共同初始化不能悄悄改变某一方法的摩擦/力矩。最多两轮明确记录的初始化修订仍不能获得共同稳定状态，就提交阻塞报告，不开展大批量跨越。

## 6. 阶段1：已知方向时，局部转弯是否可行

这里允许接头位置、目标管方向用于控制，明确标为“真值辅助的运动可行性试验”，不计自主识别成功。

### 6.1 局部形状

保留Yamada关节积分的输出路线。在统一的运动标架中表示两分量弯曲场，采用2016论文启发的结构：基础螺旋弯曲在局部减弱，同时加入平面弯曲。概念式为

\[
\mathbf b_d(s,t)=[1-h_{2w}(s-\mu)]\mathbf b_{helix}(s,t)
 +h_w(s-\mu)\mathbf b_{turn}(s,t).
\]

两项必须表达在同一个标架，长度统一用mm或m；`μ`为沿身体弧长的位置，`w`为宽度。此式是待实现的形状参数化，不是已验证的过弯定理。连续目标曲线和关节积分从同一弯曲场生成，正确处理初始标架和滚动相位；不能显示一条拼接曲线却输出另一套关节角。Bishop标架可避免弯曲为零处的Frenet奇异，已有几何模块可参考，但不能直接假设其变螺距公式就是任意局部转弯公式。

先验证：零转弯退化为原Yamada目标；宽度/幅度/位置变化无角度跳变；实际FK确实朝指定方向转弯；关节不越限、无非相邻自穿透；弯曲位置向尾部推进后，前部能恢复螺旋形状。逐帧硬裁剪角度不能作为几何检查通过的手段。

先用固定名义螺旋参数验证局部转弯的运动能力。然后接入顺应规则，并另列“固定形状/顺应形状”结果。2023的全身直轴重建在急弯处可能失效：若支持段采用分区重建，必须报告每区长度、估计有效率和失效处理；若改用2016式弯曲参数顺应，应明确算法变更，不能仍称为原2023控制器。用上一帧目标反复变形也不能代替实测反馈。

### 6.2 运动过程与门槛

前部先转向、接触目标管，确认能开始包绕后再把转弯区域向尾部推进。不能仅按时间把`μ`扫过全身，同时任由后部支撑消失。初始只探索前部4/6关节、弯曲宽度约1/2个64.5 mm连杆长度；目标总弯曲从小到大渐变。具体范围经几何检查后固定，不能直接给单个关节90°指令。

先允许暂停rolling完成试探/接触，再恢复rolling。记录每次暂停及持续时间，结果名称写“含停顿和局部重构的rolling转管”。连续rolling必须另做试验，不用该结果替代。

训练最多12次不同参数组合，保留所有尝试；每种场景冻结一组后，以5个不同初始相位/位置复核。进入自主识别阶段前，至少在水平L上完成4/5次整身转移。该门槛只用于项目推进，不代表统计证明。达不到就报告几何、接触或支撑失效，暂不投入方向识别批量试验；T和竖直逐场景放行。

## 7. 阶段2：负载反馈能否辨别方向

### 7.1 最小试探流程

在接头附近暂停滚动相位，保持其余支撑段的目标。以试探开始时由FK定义的局部参考标架给出两个正交弯曲方向，依次正/反试探。不能把奇偶关节的力矩符号直接解释为世界左右。

初值建议：控制20 Hz，单次目标增量不超过0.25°/关节；试探峰值相对开始目标0.5°，仅在负载余量足够时扩展到1°或2°。每次用约0.5 s渐变、0.25 s观察、0.5 s回退。试探顺序在不同重复中轮换。回退靠真实控制执行，不恢复 `qpos`；记录残余姿态和接触滞回。

力矩超过上限90%持续0.2 s时停止继续增加试探，尝试渐进回退；若原保持状态已超过该门槛，则标记“无试探余量”。无法恢复支撑、出现触地或明显脱离管道时结束该次。门槛是仿真试验建议，不套用为实机保护参数。

记录：实测角变化、实际应用目标与跟踪误差、逐关节带符号力矩及其相对试探前的变化、持续时间、回退后残差。既看前部，也记录后部负载，防止把整体失稳误判成前部可进入。

先用可解释的特征规则或小型线性分类器；不引入大模型/RL。分类目标是“左/右/上/下候选弯曲、未探测到接触、无法判断”，不是完整管轴三维重建。若后续输出连续轴方向，必须增加误差指标与可辨识条件，不能把离散分类改名成轴估计。

### 7.2 数据与对照

至少包含6类布置：左、右、上、下分支候选，直管无分支，只有阻挡而没有可转入管段。四个方向可从已有场景派生独立旋转/镜像模型，生成时确认重力方向和手性；不覆盖原XML。另保留“头部伸到空中、负载下降”的负样本。

每类先3个训练状态、5个保留测试状态；变化初始滚动相位和接头相对位置，整段试验划分训练/测试。无随机噪声时仅改变seed不算重复。每个状态从同一初态分别运行：

- P：不试探，只观察同样时长的关节反馈。
- A：执行上述主动试探。

用相同记录另外比较角度/速度/目标/相位特征与增加力矩特征；当前比例舵机下不能把这一比较解释为新的传感信息。接触点/法向只供评分。阶段2允许评分器指定“开始试探”的时机，因此该阶段仍没有验证自主触发。

“左右上下”均在试探开始的局部参考标架定义；评分器将真实候选方向转入该标架后打标签，不直接沿用XML的世界方向名称。简单分类特征先用每个关节在每次正反试探中的误差/负载峰值、均值、变化量与回退残差，参数只在训练状态选择。

必须报告方向混淆矩阵、拒绝判断比例、空中误判为可接管的比例、试探导致支撑丢失的比例，以及主动相对被动的逐状态差异。建议推进门槛：四类有分支的20个保留状态中，已作出方向判断的精度≥80%、覆盖率≥70%；其余无分支/阻挡和附加空中样本误判可接管≤10%。将分支方向分类和可支撑性判断分别计分，不能以分类正确证明稳定可攀爬。样本少时给出原始计数，不能宣称已达到可靠应用水平。

至少保留一对“可接触区域相同、未探到的后方结构不同”的诊断布置。若试探轨迹产生相同反馈，算法应报告无法区分，不能靠场景标签区分。这用于明确探测范围：未接触、未被动作影响到的管段不能凭空恢复。

若不同方向反馈不可分、或大量触发力矩饱和/自由空间误判，则结论是当前观测和试探不足。先报告，不在同一轮自动增加摄像头、触觉阵列或深度学习；这些是另一个研究分支。

## 8. 阶段3：完整闭环，逐个场景推进

控制流程：正常rolling → 检测持续异常并暂停 → 小幅试探 → 有把握时局部转弯并尝试新接触 → 包绕和转弯区域后移 → 恢复整身rolling。置信度不足时回退/停止，不默认选某个方向。

异常触发需用相位匹配的直管正常负载/误差分布，不用单一“最大关节负载”。建议训练阶段取正常分布高分位阈值并要求持续至少0.2 s；同时在无分支直管验证误触发。具体阈值冻结后再评测，不能读接头坐标或接触geom名称触发。

第一轮冻结四组：O=当前2023控制器；K=局部转弯+已知方向/接头的辅助组；P=同一转弯控制器+被动识别；A=同一转弯控制器+主动识别。K是运动可行性参考，不是可部署基线。P/A只有感知动作不同，转弯与顺应规则一致。

先在已放行的水平L场景，每组5个匹配测试状态，共20次。结果支持继续才扩展水平T，再到竖直上行接水平，总上限60次。固定训练和测试状态，后续调参须另开版本，不能覆盖测试。主动A不优于被动P时，如实报告主动试探没有收益；K成功而A失败时定位感知/触发问题；K也失败时不能归咎于方向识别。

### 成功判据

评分器可以看真实管道几何，控制器P/A不能。一次成功必须同时满足：所有机器人段已进入指定目标管区域、脱离原管接头区；目标管上多个不同身体段保持接触和实际包绕；继续沿目标管推进至少0.2 m；随后固定相位保持10 s，沿目标管回退≤20 mm，无地面/额外支撑、无数值发散。训练时将目标区域边界和接触判据写成固定代码并检查视频，不能只看头部越线或平均高度。

另外报告头部首次进入、建立目标管接触、第一次有效包绕、尾部通过四个里程碑。接触本身不是承重证明，10 s保持只是本轮操作性稳定检验。低电流/低力矩、伸出头或第一圈解旋均不单独算通过。

报告时间、停顿占比、包绕形态、原管/目标管接触分布、沿管回退、关节误差、力矩RMS/饱和时间和失败原因。积分Στ²只是负担代理，不是实机耗电量。

## 9. 信息边界与后续泛化

P/A控制函数只能接收有时间戳的允许观测和任务意图；不能持有仿真对象或读取XML管轴、`pipe_centerline`、目标geom名称、接触法线、全局位置以及目标标签。初态和观测若含场景名要剔除，防止方向由文件名泄露。

当前模型无IMU。短暂停顿试探先用机器人相对局部标架；这不能保证长时间滚动后的世界方向稳定。若使用合成IMU，必须单列“需要IMU”的方法，加入噪声/延迟，并说明实机是否具备；不能将MuJoCo完整姿态悄悄当作现有实机传感。

最小闭环通过后，再做反馈延迟0/50/100 ms、量化和负载噪声、摩擦±20%的小规模配对压力试验。先验证失败是否来自信号不足还是运动支撑。连续不停顿rolling作为最后单独对照：保持相同路线、初始化和负载限制，记录滑移和转弯方向误差；暂停版通过不能替代它。
