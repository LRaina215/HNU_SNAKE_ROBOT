# 第二轮结果与螺旋成形方向复核（2026-10-07）

## 用户指出的方向问题

用户要求检查 20:29 交付是否把成形方向搞反。复核的是该次交付连续视频末段 A12 及其保存源码。

**已确认：** A12 在后部已脱离源管后，从自由尾端开始收卷。`activation=(t-2*(19-j))/8` 使 J20 最先激活，再向 J19、J18……推进。螺旋相位只由前部关节角拟合；这段关节角覆盖没有把新收卷部分的位置和轴线约束在目标管周围。视频中的结果是管外收卷，最终落地。

这不是从目标管上已有的包绕开始、把同轴螺旋向身体后方连续延伸。首轮常规动作有前部滚动，但也没有完成这种延伸；不能说所有阶段的前后编号都颠倒。审阅此前集中在解折与后部支撑，遗漏了末段成形方向与原设想不一致的问题。

用户提出的方向应优先实现。仍需区分：前部形成螺旋，不会自动证明后部能转上目标管；必须让这段包绕实际变长，过渡身体持续加入，同时后部送身。下一版不能只把尾部 activation 反过来。

## 第二轮实际结果

源码及小文本已提交为 `68701abf`。B01/B02 从 A07 同一保存状态分别启动，各运行 90.05 秒，已用完该轮 2/2 次。

- 原始轨迹确认，两轮 M10–M20 的目标侧接触力最大值为 0。B01 前部固定 M0–M7 平均后退 18.297 mm，B02 后退 78.236 mm，没有新身体接管。
- B02 释放 M12 后保留了更后方支撑，两轮未落地；视频关键帧和逐模块接触记录与报告一致。J10/J13 退回一些，J8/J9 却变为约 86.06/-88.06°。
- B02 的候选目标点跟随前部后退：Y 从 139.73 mm 移至 105 mm。距离缩短到约 53 mm，不能证明身体向前跨管。
- 控制器已取消整段关节归零覆盖，后部支撑允许重获；但仍主要靠局部模块追踪一个由前部末端外推的螺旋目标点，没有实现目标管螺旋覆盖更多身体的连续形状过程。
- 当前前部滚动的名义轴向速度在起末状态均指向目标管前方，因此没有证据把本轮后退简单归咎于滚动正负号写反。实际后退说明当前配合没有实现所请求的运动，原因未被唯一确定。

本次只读取保存轨迹、源码与视频抽帧，并用保存姿态核对速度方向，没有新动力学、静止保持或接触参数修改。接受失败结果；完整跨管仍未完成。
