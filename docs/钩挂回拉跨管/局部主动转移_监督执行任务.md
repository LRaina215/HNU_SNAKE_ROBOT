## 要取得的成果

先在已搭管、方向已知的直角接头上，得到一小段可重复的主动转移，并明确哪项反馈改变了什么动作、改善了哪种失败。钩挂回拉是对照起点，不是必须坚持的最终搭管姿态。

统一方法从局部动作开始设计：前部承接、后部适度释放和送身、过渡部分迁移应共同维持支撑。支撑区域可以沿身体变化；不预设永久固定的前中后三段，也不要求所有接触始终不滑。局部滑移若存在必须说明和测量，不能把整机滑落计作主动推进。

## 当前续派：零运动不卸夹紧，检查一个已有滚动路径的短前缀

本次仍不步进物理，不解除旧 B 禁用。交付沿用新实验目录，另存 `entry_prefix_report.md` 和必要小型数值记录，不改写已验收修复报告。

1. **定义并实现一个明确的接入候选。** 可优先检验 `q_desired(s) = q_hold + q_shape(s) - q_shape(0)`：q_hold 是 CLOSE1B 已执行且保存的夹紧目标，q_shape(0) 是同一保存状态的实测初形。位移为零时应逐项返回 q_hold；每次相对同一冻结起点计算，不把跟踪误差反复累加。这个式子只解决命令接入，不能据此声称运动中夹紧力恒定、接触可行或统一顺应控制已实现。如实际接口不适用，说明依据，不另造多套控制律。
2. **优先复用已有有滚动约束的短动作。** 检查 `hook_pull_step4_rolling.py` 从 CLOSE1B 出发的首段资料；若没有保存关节序列，可用原求解器生成一个截短前缀，不重跑完整 25/25 mm 验收。非零幅度在求解前登记，限于几毫米的小步；只选一个接触假设、一个节奏，单候选累计求解最多 20 分钟。不用 A′/B 的纯节点螺旋拟合替代滚动，也不能只切换到备用 solve_pulse 就宣称物理关系正确。
3. **只做决定是否值得短仿真的必要检查。** 核对零输入不改目标、保存状态不变、命令绝对限位和时标后的 10°/s、有限外壳/过渡部分情况、连杆实际自转与预期前后运动方向。根位姿只作私有运动学求解和诊断，不能施加到物理根。说明旧双边点接触模型不能证明摩擦力、承载或真实主动转移。
4. **区分形状和夹紧目标。** 夹紧目标本来就不同于实际关节角；不能把带预载目标的无接触 FK 当成实际身体形状。碰撞检查应说明检查的预测/保存实态及原有容差，不能悄悄裁剪目标或放宽容差来过关。
5. **不重复已有保持实验。** 零运动命令若逐条与 CLOSE1B 后的 EXTHOLD_1B 等价，可复用其原保持证据；该证据不证明非零动作后的保持。若无法证明等价，记录下一轮需要的匹配保持，不在本次运行。
6. **交付后由审阅会话决定下一步。** 输出唯一候选的关系式、冻结参数、短路径及检查结果，明确是否值得一次短动力学；准入失败就交代具体冲突，不追加扫描、重搭管或整身优化。不修全套 B 评分框架，不把离线通过写成已过接头。后续实际动作需完整轨迹、模块迁移/持续接触与危险立即停止，届时单独限定次数。

## 后续方向（本轮不自动铺开）

恢复可信依据后，由审阅会话择取一个有依据的局部配合动作：前部增加承接、后部适度释放并送身、过渡部分迁移、停下还能保持，再尝试下一小步。抓持与运动余量共同设计，改变钩形、过渡段或局部滑移都只是候选，不预认某项必然有效。

反馈从该局部动作开始参与。先解决一个可观测的问题，不同时实现所有失败分类。编码器形状不能直接观察整机相对管道的刚体滑动；qfrc_actuator 也不能未经映射就等同实机可用负载。先说明已有信号能分辨什么，缺少什么；不得将世界位姿、精确管轴、接触真值包装为实机可用闭环。真值用于离线诊断、准入、记录、评分与危险停止；使用真值的诊断分支单列，不算正式成功。

候选动作完成基本几何与指令检查后，尽早准备由用户现场操作的短程实机验证，不等待仿真完成整身跨越。现阶段不连接实机、不使能扭矩。可重复局部转移成立后，再延长至整身，最后在同一控制原则下检查其他管型；强化学习暂不加入。
